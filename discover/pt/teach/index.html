01

Prepare uma atividade reproduzível

Teste os seus ficheiros MARS, entradas e saídas esperadas. O objetivo é a compatibilidade prática com MARS 4.5; consulte as limitações publicadas para casos particulares.

02

Partilhe a atividade exata

Use o link permanente de um exemplo ou uma revisão fixa de um projeto público. Cada aluno abre uma cópia local independente.

03

Mantenha o seu fluxo de ensino

Use o LMS para enunciados e entregas. Os exercícios públicos são projetos partilháveis; o webMARS ainda não disponibiliza correção automática nem um painel de progresso da turma.
