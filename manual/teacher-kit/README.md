# Kit para docentes do webMARS

Documentos editáveis que acompanham o Manual v0.2 para webMARS 0.6.3. Substitua todos os campos entre parênteses retos e conserve sempre o URL completo da instalação.

- `migration.md`: migração de atividades MARS.
- `first-class.md`: preparação e condução da primeira aula.
- `lms-copy.txt`: textos prontos para Moodle, Canvas ou email.
- `publishing-stable-links.md`: política de nomes e revisões.
- `self-hosting-privacy.md`: checklist do operador.

Uma conta, um nome público e uma revisão pertencem ao BackMars da instalação indicada pelo hostname; não são globais entre universidades.
