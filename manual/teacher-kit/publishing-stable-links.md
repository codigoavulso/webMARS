# Publicação e ligações estáveis

## Contrato

- `/e/<id>` identifica um exemplo incorporado.
- `/p/<nome>` aponta para a revisão mais recente.
- `/p/<nome>@<n>` aponta para uma revisão imutável.
- O nome é atribuído ao primeiro utilizador naquela instalação.
- Maiúsculas e minúsculas não criam nomes diferentes.
- Arquivar nunca liberta o nome.
- Outra instalação pode ter o mesmo nome; partilhar sempre o URL completo.

## Procedimento docente

1. Testar e guardar o projeto local.
2. Iniciar sessão e verificar o email.
3. Publicar com nome, descrição, tipo, dificuldade, tags e licença.
4. Copiar o URL mais recente e o URL fixo.
5. Usar o URL fixo em avaliações.
6. Publicar uma nova revisão para corrigir, sem alterar as antigas.
7. Arquivar quando o material não deve continuar listado.
