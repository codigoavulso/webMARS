# Checklist da primeira aula

## Antes

- [ ] Abrir o URL exato num browser sem sessão.
- [ ] Confirmar hostname, HTTPS e versão webMARS.
- [ ] Testar o exemplo/exercício e o input previsto.
- [ ] Guardar fonte local, enunciado e output esperado.
- [ ] Definir se Cloud é permitido, opcional ou desativado.
- [ ] Confirmar contacto de suporte da instalação.

## Demonstração

- [ ] Abrir ficheiro/projeto.
- [ ] Montar (F3) e interpretar erros.
- [ ] Executar (F5), passo (F7), backstep (F8) e reset.
- [ ] Mostrar registos, Text Segment, Data Segment e Run I/O.
- [ ] Guardar localmente e descarregar.
- [ ] Explicar que uma publicação abre como cópia local independente.

## Final

- [ ] Alunos conseguem reabrir o próprio ficheiro.
- [ ] Entrega e dados obrigatórios estão claros.
- [ ] Revisão fixa está registada quando a atividade é avaliada.
- [ ] Alternativa sem rede está publicada no LMS.
