Workspace & files

A project is the unit webMARS saves, compiles and assembles. It may contain one or more .asm/.s assembly files and Mini-C .c files.

File menu

Editor and project navigation

  • Use source tabs to switch the active file. Closing a file does not close the entire project.
  • Assembly errors and Mini-C diagnostics identify the source file and line whenever available.
  • Label highlighting, syntax highlighting, font size and line spacing are controlled in Settings → Interface.
  • Generated Mini-C assembly can open automatically in its own window when that preference is enabled.

Build model

Assemble builds the selected assembly sources into a program image. Compile C0 translates the C project to MIPS assembly; the generated assembly is then assembled before execution. Multi-file C projects are linked as one translation unit by the teaching compiler.

Local recovery and cloud projects

webMARS maintains recovery data in browser storage so a reload can restore the working session. The five explicit local project slots are separate from that recovery session.

The Cloud menu is optional. Login, project open/save, synchronization and refresh communicate with the configured cloud server. Cloud use is never required for local editing, compiling or running.

Browser storage is not a permanent backup. Private browsing, quota pressure, browser cleanup or the Clear localStorage command can remove it. Download work that must be retained.
