webMARS __WEBMARS_APP_VERSION__

A browser-native MIPS32 learning environment with an assembler, JavaScript simulator, debugger, Mini-C compiler, examples and interactive devices.

No installation

Run the app in a modern browser. Java and WebAssembly are not required.

Local-first

Edit, compile, run, save to browser storage and download without signing in.

Teaching-focused

Use MARS-style MIPS syntax, syscalls, memory maps, tools and structured Mini-C profiles.

Current capabilities

  • MIPS32 integer, memory, branch, exception, LL/SC and COP1 execution.
  • Basic and pseudo-instruction reference, macros and configurable assembler compatibility.
  • Breakpoints, step, backstep, pause, stop, reset and runtime-state snapshots.
  • C0-S0 through C0-S4 and C1-NATIVE Mini-C compilation targeting o32.
  • Eighteen runtime tools, curated examples in ten languages and optional cloud projects.
  • Local Compile, Assemble and Run benchmarks with estimated JavaScript utilization.

Privacy

webMARS has no advertising. Source files, preferences, virtual files, recovery data, benchmarks and runtime state stay on the device by default. Benchmark samples are volatile and are not transmitted.

Cloud features are optional. When you sign in or synchronize, account/session and project data are sent to the cloud server configured in Settings. Review the operator's terms before using a third-party or custom server. Downloads and files opened from disk use normal browser file controls.
