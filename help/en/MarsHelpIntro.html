Getting started

webMARS is a browser-based MIPS32 assembler, simulator, debugger, Mini-C compiler and teaching workspace. The runtime is implemented entirely in JavaScript; no Java installation, native executable or WASM backend is required.

  1. Open or create a source file. Use File → Examples for a guided starting point, New Project for a blank project, or Open from Disk for local files.
  2. Build it. Assembly files use Run → Assemble (F3). C files use Run → Compile C0 (F4), then assemble the generated assembly.
  3. Execute it. Select Go (F5) or advance one instruction at a time with Step (F7).
  4. Inspect the result. Registers, Coprocessor 1, memory, messages, Run I/O and connected tools update as the program runs.

What is included

MIPS32 runtime

Integer, branch, memory, exception, LL/SC and COP1 execution, including delayed branching and self-modifying code options.

Mini-C compiler

C0 teaching subsets and the C1-NATIVE profile, targeting the MIPS o32 calling convention.

Debugger

Breakpoints, stepping, backstepping, reset, pause/stop controls and configurable execution speed.

Devices and tools

MMIO devices, cache and branch simulators, visual displays, statistics, ANSI terminal and more.

Recommended first run

Open File → Examples, choose an English Learn example, read its description, and open it. Assembly examples can be assembled and run directly. C examples declare their minimum compiler subset and may contain several project files.

Your files stay in your browser by default. Local projects and recovery data are not uploaded unless you explicitly use the Cloud menu. Download important work periodically because browser storage can be cleared by the browser or by Settings → Clear localStorage.
