Mini-C

The built-in teaching compiler translates a deliberately defined C subset to MIPS32 assembly using the o32 calling convention. It is not a general-purpose ISO C compiler.

Profiles

ProfilePurpose
C0-S0 to C0-S4Cumulative teaching subsets, progressing from expressions and control flow to functions, arrays, pointers, structures, typedefs, contracts and libraries.
C1-NATIVEThe default, most capable profile: byte-addressed char/char *, native strings, argc/argv, function pointers and void *.

If a source requires a higher profile, compilation emits one focused MC_SUBSET_MISMATCH diagnostic rather than a cascade of secondary errors.

Compile a project

  1. Select the desired profile and output options in Settings → Mini-C preferences.
  2. Open one or more .c files in the same project.
  3. Select Run → Compile C0 or press F4.
  4. Review diagnostics and generated MIPS assembly. Assemble and run the generated program normally.

Calling convention and entry point

  • Arguments use $a0–$a3, additional arguments use the stack, and return values use $v0 (and $v1 where appropriate).
  • Callee-saved registers and stack frames follow MIPS o32 expectations.
  • main(void) and, in C1-NATIVE, main(int argc, char **argv) are supported.
  • For webMARS program arguments, argv[0] is the first token supplied by the user; there is no automatic executable-name entry.

These headers are webMARS compatibility libraries built around MIPS syscalls and devices. They implement their documented subset, not the full host C standard library.
