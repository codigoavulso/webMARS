Support

Report webMARS defects and documentation gaps in the project repository, or contact the maintainer directly.

A useful bug report includes

  • The smallest assembly or C project that reproduces the problem.
  • The exact compile/assemble/run sequence and the result you expected.
  • The complete Messages and Run I/O text; File → Dump Run I/O can export the transcript.
  • Relevant settings: compiler profile, memory map, delayed branching, pseudo-instructions and self-modifying code.
  • Browser name/version and whether the problem also occurs after a reload in a clean local project.

Before submitting

  1. Try the closest bundled example and compare its settings.
  2. Reassemble after changing runtime or memory preferences.
  3. Do not include passwords, cloud session data or private source that cannot be shared.
