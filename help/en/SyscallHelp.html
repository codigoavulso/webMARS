Syscalls

Place the service number in $v0, place arguments in the registers shown below, and execute syscall. Unless a row says otherwise, registers other than documented results are preserved.

Descriptors 0, 1 and 2 are stdin, stdout and stderr. User descriptors start at 3 and are backed by the browser virtual file system; they do not grant unrestricted host-file access.

Input status follows MARS conventions: 0 success, −1 invalid input, −2 cancel, and −3 empty input; string input also uses −4 when truncated.
