Tools

Open tools from the Tools menu. Each tool has an independent window and may connect to the current MIPS runtime to observe instruction, memory or MMIO activity.

Connect before running. A connected tool receives complete runtime snapshots and trace events even when maximum-speed execution suppresses editor highlighting. Disconnect or reset the tool when starting an unrelated experiment.

Bitmap configuration from MIPS

A program may configure either Bitmap tool by writing this versioned control block relative to the active MMIO base (normally 0xffff0000). Write all fields first and write 1 to the command last; the tool changes only after that atomic commit.

OffsetValue
+0x20Signature 0x57424d50 (WBMP)
+0x24Protocol version 1
+0x28Target: 1 Display, 2 Terminal, 3 both
+0x2c … +0x38Display width, display height, unit width and unit height
+0x3cFramebuffer base address
+0x40Command: 1 apply, 2 clear program configuration

Invalid or incomplete blocks are ignored. Backstep, runtime export and session restore preserve the committed configuration. This is an optional webMARS extension: MARS 4.5 ignores these unused MMIO words, while the same framebuffer code continues to work with manual tool settings.

MMIO safety

MMIO devices are mapped near 0xffff0000. Device tools and the runtime share those addresses; polling programs should honor ready bits, and interrupt-driven programs should install a valid exception handler. Resetting a tool clears its visualization or device state, not necessarily the assembled program.
