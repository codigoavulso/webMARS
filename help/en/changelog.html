Changelog

Release 0.5.0 hardens the MIPS runtime, replaces full snapshots with compact backstep deltas, and completes the mobile and tool workflows.

0.5.0 — mature runtime, delta backstep, mobile workflows

  • Corrected high-impact runtime behavior across memory limits, atomic stores, COP1 doubles and rounding, delayed branches, exceptions, LL/SC reservations and breakpoints.
  • Replaced full per-instruction snapshots with bounded inverse deltas while retaining an exact backstep window and synchronized tool state.
  • Reduced execution overhead through compact runtime event batches, coalesced tool rendering and lighter UI synchronization.
  • Added dynamic Bitmap MMIO configuration and updated the Bitmap examples and libraries to use it while remaining compatible with MARS 4.5.
  • Expanded the TTY examples with a practical MIPS shell and improved the Assembly and Mini-C lesson catalog in all three languages.
  • Integrated tools, dialogs, Cloud and Settings into the mobile window system, including Android keyboard-aware sizing, semantic virtual keyboards and contained scrolling.
  • Added comprehensive runtime, tool, example, documentation, mobile UI and release regression coverage.

0.4.13 — mobile single-panel layout, localized diagnostics

  • Mobile shows one full-screen panel at a time, chosen from a new icon tab bar listing Main, Messages/Run I/O, Registers and any open tool.
  • Pinned the mobile viewport so the page no longer scrolls, removing the nested-scroll conflict between the document and the window bodies.
  • Mobile toolbar is icon-only across two compact rows, keeping the execution controls and the run-speed picker on screen; the file actions are hidden there and remain in the File and Edit menus.
  • Hid the minimize and maximize buttons on mobile, where one panel fills the screen and the tab bar does the switching.
  • Localized every assembler and Mini-C diagnostic, converting 114 template literals into named placeholders and adding 277 keys across the three languages.
  • Added a release test that fails when a translatable message has no catalog entry.
  • Desktop layout, window positions and control sizes are unchanged.

0.4.12 — dark theme, font-size fix, dead-code cleanup

  • Added opt-in dark theme selectable via Settings > Interface..., applied to the editor, tool windows, and help pages.
  • Fixed editor font size and line height applying immediately after changing them in Interface preferences without requiring a page reload.
  • Wired the Close All Files action into File > Close > All files.
  • Removed the machine-session autosave pipeline (~400 lines) that was gated behind an experimental flag never set in any release.
  • Removed ~15 dead functions across five modules, unused registry exports, dead CSS selectors, and 113 unused i18n keys.
  • Excluded unreachable root-level help files from the release package.

0.4.11 — persistent cloud login restoration

  • Checked the configured cloud server silently during application startup and restored an existing authenticated user.
  • Refreshed cloud project metadata after successful session restoration without blocking the local workspace.
  • Documented the authentication cookie's one-year maximum lifetime and immediate removal on logout.
  • Added regression coverage for credentialed requests and automatic startup restoration.

0.4.10 — batched tool history and lighter UI updates

  • Retained tool deltas only for instructions still covered by the engine's exact 100-step backstep window.
  • Kept every runtime event available to tool models while batching visual updates and avoiding obsolete history allocation.
  • Reduced per-instruction DOM work in BHT and redundant state copies in the cache simulator.
  • Stopped idle Mars Bot rendering and removed a redundant full runtime snapshot from UI synchronization.
  • Corrected a Firefox-only window-title separator repaint artifact.
  • Reduced idle terminal polling in the Monty Hall lab without compromising input responsiveness or backsteps.

0.4.9 — runtime parity and dependable backsteps

  • Kept the most recent 100 backsteps available while bounding sparse journal memory.
  • Corrected synchronous Keyboard/Display, TTY and tool-event behavior in long browser runs.
  • Updated the Monty Hall lab and interactive examples to cooperate with browser input without busy polling.
  • Matched random syscalls 40–44 to the seeded sequences and sampling rules of java.util.Random used by MARS.
  • Hardened runtime-state import, long instruction counters, assembler ranges and numeric directive validation.
  • Completed backstep coverage for image metadata and corrected zero-length InputDialogString buffers.
  • Expanded regression coverage across the runtime, localized examples and connected tools.

0.4.8 — delta backsteps and synchronous devices

  • Replaced full per-instruction backstep snapshots with bounded inverse deltas.
  • Separated synchronous MMIO devices, compact runtime-event batches and periodic tool snapshots.
  • Corrected Keyboard/Display and TTY input/output causality, backsteps and hidden-tool overhead.
  • Fixed batch rendering in cache, instruction, memory-reference and bitmap tools.
  • Moved Mini-C example framebuffers away from compiler globals and synchronized Bitmap Display with live memory.
  • Made the local benchmark strip optional in Interface Preferences and hidden by default.

0.4.7 — JavaScript runtime hardening and complete documentation

  • Standardized the runtime on the pure JavaScript engine and removed the experimental WASM/hybrid backend.
  • Added Compile, Assemble and Run timing plus estimated JavaScript utilization to the in-app benchmark strip.
  • Kept full runtime snapshots available to connected devices while reducing editor work at maximum run speed.
  • Corrected COP1 doubleword ordering, FCSR-based conversion rounding and complete numeric-input validation.
  • Hardened heap limits, atomic stores, instruction alignment, strict partial loads and LL/SC reservations.
  • Corrected delayed-branch link addresses, delay-slot exception state and parity between direct engine Go and browser-driven execution.
  • Made Stop terminate the engine and cancel a pending Sleep, while Pause remains resumable.
  • Expanded runtime snapshots to preserve breakpoints, random streams, virtual files/cursors, stdin, program arguments and image handles.
  • Expanded and rationalized the English, Spanish and Portuguese example catalogue, including C1-NATIVE and multi-file C projects.
  • Updated all English, Spanish and Portuguese in-app help to match the current browser application, runtime, Mini-C compiler, tools, storage and privacy behavior.
  • Added release-readiness checks for version consistency, manifests, transient files and localized UI contracts.

0.4.6 — reproducible browser workspace

  • Established reproducible install, serve, build, test and validation commands.
  • Added broad regression coverage for assembler/runtime behavior, browser integration, tools and examples.
  • Introduced configurable runtime memory and backstep limits with stronger state persistence.
  • Expanded Mini-C profiles, o32 behavior, libraries, examples and multilingual interface coverage.

Earlier webMARS milestones

  • Ported the MARS-style editor, assembler and runtime workflow to the browser.
  • Added local projects, session recovery, optional cloud synchronization and browser virtual files.
  • Ported and adapted core educational tools and MMIO devices.
  • Added the Mini-C teaching compiler and progressively richer subset profiles.

Historical note

Some earlier releases experimented with WebAssembly acceleration and backend selection. Those entries describe their release accurately, but that subsystem is no longer present. The current runtime is JavaScript-only.
