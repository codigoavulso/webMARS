Acknowledgements

webMARS stands on the teaching model, instruction documentation, tools and community experience established by the original MARS project.

Original MARS

Created by Pete Sanderson and Kenneth Vollmar, with contributions from educators, students and tool authors. Their work established the approachable MIPS assembler/simulator workflow that webMARS continues in the browser.

Notable original contributions include the macro system, instruction statistics and counter tools, branch prediction simulator, keyboard/display MMIO work, Digital Lab Sim, MIPS X-Ray, MIDI improvements and the many corrections collected through classroom use.

webMARS

Browser implementation and ongoing maintenance by Nelson Ferreira. The current app includes an independent JavaScript MIPS engine, a Mini-C compiler and libraries, local/cloud project workflows, runtime tools, multilingual examples and automated regression coverage.

Community and standards

Thanks to everyone who reports reproducible failures, contributes teaching examples, checks translations and compares architectural behavior with MIPS32 documentation. Those reports directly improve compatibility and runtime correctness.

The original MARS License and the MIPS Instruction Set Song are preserved as historical help items with their original attribution. Their presence does not imply that the current browser implementation uses the original Java source.
