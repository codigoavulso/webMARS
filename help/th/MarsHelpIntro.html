เริ่มต้นใช้งาน

webMARS เป็น MIPS32 ที่ใช้เบราว์เซอร์ แอสเซมเบลอร์ โปรแกรมจำลอง ดีบักเกอร์ Mini-C คอมไพเลอร์ และพื้นที่ทำงานการสอน รันไทม์ถูกนำมาใช้ทั้งหมดใน JavaScript; ไม่จำเป็นต้องติดตั้ง Java, ปฏิบัติการแบบเนทิฟหรือ WASM แบ็กเอนด์

  1. เปิดหรือสร้างไฟล์ต้นฉบับ ใช้ ไฟล์ → ตัวอย่าง สำหรับจุดเริ่มต้นที่แนะนำ โครงการใหม่ สำหรับโครงการเปล่าหรือ เปิดจากดิสก์ สำหรับไฟล์ในเครื่อง
  2. สร้างมันขึ้นมา การใช้ไฟล์ประกอบ วิ่ง → ประกอบ (F3). การใช้ไฟล์ C เรียกใช้ → คอมไพล์ C0 (F4) จากนั้นประกอบชุดประกอบที่สร้างขึ้น
  3. ดำเนินการมัน เลือก ไป (F5) หรือเลื่อนทีละคำสั่งด้วย ขั้นตอน (F7).
  4. ตรวจสอบผลลัพธ์ รีจิสเตอร์, โปรเซสเซอร์ร่วม 1, หน่วยความจำ, ข้อความ, รัน I/O และอัพเดตเครื่องมือที่เชื่อมต่อในขณะที่โปรแกรมรัน

สิ่งที่รวมอยู่ด้วย

MIPS32 รันไทม์

จำนวนเต็ม สาขา หน่วยความจำ ข้อยกเว้น การดำเนินการ LL/SC และ COP1 รวมถึงตัวเลือกการแตกสาขาล่าช้าและการแก้ไขโค้ดด้วยตนเอง

Mini-C คอมไพเลอร์

ชุดย่อยการสอน C0 และโปรไฟล์ C1-NATIVE โดยกำหนดเป้าหมายไปที่รูปแบบการเรียก MIPS o32

ดีบักเกอร์

เบรกพอยต์ การก้าว การถอยหลัง การรีเซ็ต การหยุดชั่วคราว/หยุดการควบคุม และความเร็วในการดำเนินการที่กำหนดค่าได้

อุปกรณ์และเครื่องมือ

อุปกรณ์ MMIO ตัวจำลองแคชและสาขา การแสดงภาพ สถิติ เทอร์มินัล ANSI และอื่นๆ

แนะนำให้วิ่งครั้งแรก

เปิด ไฟล์ → ตัวอย่าง, เลือกภาษาอังกฤษ เรียนรู้ เช่น อ่านคำอธิบายแล้วเปิดขึ้นมา ตัวอย่างการประกอบสามารถประกอบและดำเนินการได้โดยตรง ตัวอย่างภาษา C ประกาศชุดย่อยของคอมไพเลอร์ขั้นต่ำและอาจประกอบด้วยไฟล์โครงการหลายไฟล์

ไฟล์ของคุณจะอยู่ในเบราว์เซอร์ของคุณตามค่าเริ่มต้น โครงการในพื้นที่และข้อมูลการกู้คืนจะไม่ถูกอัปโหลด เว้นแต่คุณจะใช้เมนูคลาวด์อย่างชัดเจน ดาวน์โหลดงานที่สำคัญเป็นระยะๆ เนื่องจากเบราว์เซอร์หรือเบราว์เซอร์สามารถล้างพื้นที่เก็บข้อมูลเบราว์เซอร์ได้ การตั้งค่า → ล้างที่เก็บข้อมูลในตัวเครื่อง.
