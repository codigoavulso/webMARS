ประวัติศาสตร์

webMARS เริ่มต้นเป็นพอร์ตเบราว์เซอร์ของตัวจำลอง MARS 4.5 MIPS ขณะนี้ได้รวมรันไทม์ JavaScript อิสระ ตัวแก้ไข ดีบักเกอร์ Mini-C คอมไพเลอร์ เวิร์กโฟลว์โปรเจ็กต์โลคัล/คลาวด์ และเครื่องมือที่ใช้เบราว์เซอร์เป็นหลัก

สายการพัฒนาในปัจจุบัน

  • JavaScript-รันไทม์เท่านั้น เส้นทางไฮบริด/WASM รุ่นทดลองถูกลบออกหลังจากการวัดพบว่าได้เพิ่มความซับซ้อนโดยไม่มีการปรับปรุงที่คุ้มค่าสำหรับปริมาณงานนี้
  • ความถูกต้องรันไทม์ งานล่าสุดทำให้การเรียงลำดับ doubleword COP1 ดีขึ้น, การจัดเก็บหน่วยความจำอะตอม, การจองฮีป, LL/SC, การกำหนดแอดเดรสที่เข้มงวด, ลิงก์สาขาล่าช้า, การปัดเศษ FCSR, การดำเนินการต่อข้อยกเว้น และพฤติกรรมการหยุด
  • สแนปชอตสถานะที่สมบูรณ์ ขณะนี้การส่งออก/นำเข้าและย้อนกลับคำนึงถึงสตรีมแบบสุ่ม ไฟล์เสมือนและเคอร์เซอร์ stdin อาร์กิวเมนต์ของโปรแกรม ตัวจัดการรูปภาพ และเบรกพอยต์
  • ความสามารถในการสังเกตประสิทธิภาพ แอปรายงานการคอมไพล์ แอสเซมบลี และรันไทม์มิ่งในเครื่อง รวมถึงการใช้งาน JavaScript โดยประมาณ ในขณะที่การดำเนินการด้วยความเร็วสูงสุดจะช่วยลดค่าใช้จ่ายในการนำเสนอโดยไม่ต้องใช้เครื่องมือในสถานะรันไทม์
  • Mini-C วิวัฒนาการ ชุดย่อยการสอน C0 ยังคงพร้อมใช้งานควบคู่ไปกับ C1-NATIVE, การเรียก o32, สตริงไบต์, อาร์กิวเมนต์, พอยน์เตอร์ฟังก์ชัน, โปรเจ็กต์หลายไฟล์ และไลบรารีที่เข้ากันได้
  • ตัวอย่างเป็นหลักสูตร ตัวอย่าง Assembly และ C ได้รับการจัดทำรายการตามวัตถุประสงค์ ภาษา และโปรไฟล์คอมไพเลอร์ขั้นต่ำ พร้อมตัวแปรหลายภาษาและโปรเจ็กต์หลายไฟล์

เชื้อสายที่เข้ากันได้

คำศัพท์การสอน ระบบเรียกทั่วไป แนวคิดส่วนติดต่อผู้ใช้ และรูปแบบการสอนมาจากต้นฉบับ MARS โครงการโดย Pete Sanderson และ Kenneth Vollmar webMARS รักษาเชื้อสายนั้นไว้ในขณะที่แทนที่การรวมเดสก์ท็อป Java ด้วย API ของเบราว์เซอร์และกลไกการดำเนินการของตัวเอง

บันทึกเวอร์ชัน

ที่ webMARS → บันทึกการเปลี่ยนแปลง หน้าความช่วยเหลือมีบันทึกโครงการโดยละเอียดรุ่นต่อรุ่น รายการในอดีตจะอธิบายสถานะของการเผยแพร่ พวกเขาไม่ได้สัญญาว่าระบบย่อยทดลองจะยังคงอยู่ในรุ่นปัจจุบัน

เมื่อเอกสารประกอบและรายการบันทึกการเปลี่ยนแปลงในอดีตแตกต่างกัน หน้าหัวข้อปัจจุบันและพฤติกรรมรันไทม์ปัจจุบันจะมีความสำคัญเหนือกว่า
