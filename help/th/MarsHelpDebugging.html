เมนู Run จะควบคุมกลไก JavaScript MIPS หนึ่งรายการที่ใช้ร่วมกันโดยรีจิสเตอร์ มุมมองหน่วยความจำ ดีบักเกอร์ และเครื่องมือที่เชื่อมต่อ

การควบคุมการดำเนินการ

การควบคุมความหมาย
ไปรันจนกว่าจะเสร็จสิ้นตามปกติ, เบรกพอยต์, syscall กำลังรออินพุต, ข้อยกเว้นที่ไม่สามารถจัดการได้, ขีดจำกัด, หยุดชั่วคราวหรือหยุด
หยุดชั่วคราวระงับการทำงานที่ใช้งานอยู่ในขณะที่รักษาเครื่องเพื่อให้สามารถดำเนินการต่อได้
หยุดยุติการดำเนินการและยกเลิกงานอะซิงโครนัสที่ค้างอยู่ เช่น Sleep syscall ที่ยาว โปรแกรมที่หยุดไว้ไม่กลับมาทำงานต่อ
ขั้นตอนดำเนินการหนึ่งคำสั่ง หลังจากที่เบรกพอยต์หยุด Go หรือ Step ถัดไปจะข้ามเบรกพอยต์นั้นหนึ่งครั้ง ดังนั้นจึงไม่หยุดที่ที่อยู่เดิมอีกครั้งในทันที
ถอยหลังกู้คืนสแนปชอตรันไทม์ที่บันทึกไว้ก่อนหน้า จนถึงความลึกของประวัติที่กำหนดค่าไว้
รีเซ็ตคืนโปรแกรมที่ประกอบขึ้นสู่สถานะเครื่องเริ่มต้น

เบรกพอยต์และการติดตามแหล่งที่มา

สลับเบรกพอยต์ในตัวแก้ไขรางน้ำข้างบรรทัดต้นทางที่ปฏิบัติการได้ เบรกพอยต์จะถูกจัดเก็บไว้ในสถานะรันไทม์และคงอยู่ในระหว่างการส่งออก/นำเข้าแบบไปกลับตามปกติ คำแนะนำหลอกอาจขยายออกไปเป็นคำสั่งพื้นฐานหลายประการ การก้าวปฏิบัติตามคำสั่งเครื่องที่สร้างขึ้นในขณะที่การเน้นแหล่งที่มายังคงเชื่อมโยงกับบรรทัดเริ่มต้น

แถบความเร็วและประสิทธิภาพ

การควบคุมความเร็วในการวิ่งมีตั้งแต่อัตราการก้าวแบบโต้ตอบไปจนถึงความเร็วสูงสุด ที่ความเร็วสูงสุด webMARS ลดการเน้นตัวแก้ไขที่มีราคาแพงและการทำงานแบบเลื่อนอัตโนมัติ แต่เครื่องมือยังคงได้รับสแนปช็อตรันไทม์และข้อมูลการติดตามที่สมบูรณ์

แถบการวัดประสิทธิภาพขนาดกะทัดรัดรายงานระยะเวลาการคอมไพล์ ประกอบ และรันล่าสุดพร้อมกับเปอร์เซ็นต์การใช้งานโดยประมาณ JavaScript CPU การวัดเป็นแบบท้องถิ่นและผันผวน: มีไว้สำหรับการเปรียบเทียบปริมาณงานและการเปลี่ยนแปลงอัลกอริทึม ไม่ใช่เป็นเครื่องวัดกระบวนการของระบบปฏิบัติการ

สาขาล่าช้าและข้อยกเว้น

เมื่อเปิดใช้งานการแตกแขนงแบบหน่วงเวลา คำสั่งที่ตามหลังการแบรนช์หรือการข้ามจะเป็นที่เก็บคำสั่งสล็อตดีเลย์และคำแนะนำลิงค์ PC + 8. ข้อยกเว้นที่เกิดขึ้นในช่องหน่วงเวลาจะตั้งค่า COP0 ทำให้เกิดบิต BD และบันทึกที่อยู่สาขาใน EPC

หากมีตัวจัดการข้อยกเว้นที่ถูกต้องอยู่ที่ที่อยู่ตัวจัดการที่กำหนดค่าไว้ การดำเนินการจะถ่ายโอนไปยังตัวจัดการนั้นและอาจส่งคืนด้วย eret. มิฉะนั้นการรันจะหยุดลงด้วยเหตุผลและการวินิจฉัยที่ชัดเจน

ขอบเขตถอยหลัง สแน็ปช็อตประกอบด้วยรีจิสเตอร์ หน่วยความจำ เบรกพอยต์ สตรีมแบบสุ่ม ตำแหน่งไฟล์ อินพุตที่รอดำเนินการ อาร์กิวเมนต์ของโปรแกรม และตัวจัดการรูปภาพของอุปกรณ์ ประวัติศาสตร์อันยาวนานต้องใช้ความทรงจำ ดังนั้นควรจำกัดขอบเขตของแบบฝึกหัด
