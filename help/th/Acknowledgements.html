รับทราบ

webMARS ตั้งอยู่บนรูปแบบการสอน เอกสารประกอบการสอน เครื่องมือ และประสบการณ์ของชุมชนที่ก่อตั้งโดยโครงการ MARS ดั้งเดิม

ต้นฉบับ MARS

สร้างโดย Pete Sanderson และ Kenneth Vollmar โดยได้รับการสนับสนุนจากนักการศึกษา นักเรียน และผู้เขียนเครื่องมือ งานของพวกเขาได้สร้างเวิร์กโฟลว์แอสเซมเบลอร์/จำลอง MIPS ที่เข้าถึงได้ง่าย ซึ่ง webMARS ดำเนินต่อไปในเบราว์เซอร์

ผลงานดั้งเดิมที่โดดเด่น ได้แก่ ระบบมาโคร สถิติการสอนและเครื่องมือนับ ตัวจำลองการทำนายสาขา แป้นพิมพ์/จอแสดงผล งาน MMIO ซิมห้องปฏิบัติการดิจิทัล MIPS เอ็กซ์เรย์ การปรับปรุง MIDI และการแก้ไขมากมายที่รวบรวมผ่านการใช้งานในชั้นเรียน

webMARS

การใช้งานเบราว์เซอร์และการบำรุงรักษาอย่างต่อเนื่องโดย Nelson Ferreira แอปปัจจุบันประกอบด้วยกลไก JavaScript MIPS อิสระ คอมไพเลอร์และไลบรารี Mini-C เวิร์กโฟลว์โปรเจ็กต์โลคัล/คลาวด์ เครื่องมือรันไทม์ ตัวอย่างหลายภาษา และการครอบคลุมการถดถอยอัตโนมัติ

ชุมชนและมาตรฐาน

ขอขอบคุณทุกคนที่รายงานความล้มเหลวที่ทำซ้ำได้ สนับสนุนตัวอย่างการสอน ตรวจสอบการแปล และเปรียบเทียบพฤติกรรมทางสถาปัตยกรรมด้วยเอกสารประกอบ MIPS32 รายงานเหล่านั้นปรับปรุงความเข้ากันได้และความถูกต้องของรันไทม์โดยตรง

ต้นฉบับ MARS ใบอนุญาต และ MIPS ชุดคำสั่งเพลง จะถูกเก็บรักษาไว้เป็นรายการช่วยเหลือทางประวัติศาสตร์โดยมีที่มาดั้งเดิม การมีอยู่ของพวกเขาไม่ได้หมายความว่าการใช้งานเบราว์เซอร์ปัจจุบันใช้ซอร์ส Java ดั้งเดิม
