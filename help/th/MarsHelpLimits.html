จำกัดความเข้ากันได้ของ &

webMARS มีจุดมุ่งหมายเพื่อความเข้ากันได้ของแหล่งข้อมูล MARS 4.5 ที่ใช้งานได้จริงในขณะที่ใช้งานทั้งหมดในเบราว์เซอร์สมัยใหม่ กฎความปลอดภัย พื้นที่เก็บข้อมูล และเสียงของเบราว์เซอร์ยังคงมีผลอยู่

ขีดจำกัดรันไทม์

พื้นที่ขีดจำกัดหรือพฤติกรรม
หน่วยความจำ0.25–2 GiB ที่ผู้ใช้เลือกได้ โดยมีเพดานแข็งทางสถาปัตยกรรมด้านล่าง 0x80000000. การจัดสรรแบบกระจัดกระจายหมายถึงพื้นที่ที่อยู่ที่ไม่ถูกแตะต้องไม่ได้ถูกกำหนดแบบไบต์ต่อไบต์
กองsbrk ตรวจสอบการจองที่ไม่ได้ลงนามทั้งหมดก่อนที่จะเปลี่ยนตัวชี้ฮีป คำขอไม่สามารถตัดหรือข้ามเพดานหน่วยความจำที่กำหนดค่าไว้ได้
สตริงรันไทม์สตริงที่สิ้นสุดด้วยค่า Null สามารถมีได้สูงสุด 1 MiB ตัวยุติที่ขาดหายไปหรือสตริงที่ยาวกว่าทำให้เกิดข้อผิดพลาด syscall ที่ชัดเจนแทนที่จะส่งคืนข้อความที่ถูกตัดทอน
ถอยหลังเดลต้าผกผัน 0–1,000,000 ประวัติถูกจำกัดด้วยงบประมาณที่กำหนดค่าไว้ ในขณะที่ยังคงรักษาขั้นตอนที่เสร็จสมบูรณ์ล่าสุด 100 ขั้นตอนไว้เสมอเมื่อเปิดใช้งาน Backstep
ที่เก็บไฟล์เบราว์เซอร์ข้อมูลโปรเจ็กต์/เซสชันขึ้นอยู่กับโควต้าเบราว์เซอร์ แอปจำกัดเพย์โหลดพื้นที่เก็บข้อมูลเบราว์เซอร์ของผู้ใช้ไว้ที่ 1 MiB ตามความเหมาะสม และกลับไปใช้เพย์โหลดการกู้คืนที่มีขนาดเล็กลง หากจำเป็น
วิ่งจับเวลาโหมดสลีป MIDI และกำหนดเวลาของ UI ถูกกำหนดโดยเบราว์เซอร์และไม่แม่นยำตามรอบ
การกระจายสินค้าwebMARS 0.5.5 เป็นเว็บแอปพลิเคชั่นแบบคงที่ ไม่ใช่ PWA ที่สามารถติดตั้งได้/ออฟไลน์ จะต้องให้บริการผ่าน HTTP โดยเซิร์ฟเวอร์ภายในเครื่องที่รวมอยู่หรือโฮสต์แบบคงที่อื่น

MIPS พฤติกรรม

  • หน่วยความจำมีน้อย การดำเนินการ Word และ Doubleword ใช้ MIPS การลงทะเบียน/การจัดลำดับหน่วยความจำ
  • การดึงคำสั่งที่ไม่ตรงแนวและที่อยู่โหลด/ร้านค้าที่ไม่ถูกต้องทำให้เกิดข้อยกเว้นที่อยู่
  • ร้านค้าจะตรวจสอบความถูกต้องของปลายทางทั้งหมดก่อนที่จะเขียน ดังนั้นร้านค้าที่ล้มเหลวจะไม่ทิ้งค่าบางส่วนไว้ข้างหลัง
  • LL/SC ใช้การจองที่ร้านค้าที่ขัดแย้งกันทำให้เป็นโมฆะ
  • การแปลง COP1 เป็นไปตามโหมดการปัดเศษของ FCSR อินพุตจุดลอยตัวปฏิเสธข้อความที่ไม่ใช่ตัวเลขต่อท้าย
  • ด้วยความเข้ากันได้อย่างเข้มงวด MARS การทำงานของหน่วยความจำ รวมถึงการโหลดคำบางส่วน จะต้องอยู่ภายในเซ็กเมนต์ที่ได้รับอนุญาต

ขอบเขตการพกพาที่เป็นที่รู้จัก

  • ระบบไฟล์เสมือนของเบราว์เซอร์ไม่ใช่ระบบไฟล์ที่ไม่จำกัดของระบบปฏิบัติการโฮสต์
  • การอนุญาตเสียงบนเว็บและนโยบายการเล่นอัตโนมัติอาจส่งผลต่อการโทรระบบของ MIDI
  • ตัวบล็อกป๊อปอัปและนโยบายการดาวน์โหลดอาจส่งผลต่อไฟล์ที่ส่งออก
  • Mini-C ยอมรับเฉพาะโปรไฟล์ที่บันทึกไว้เท่านั้น รหัสที่ใช้เต็ม ISO C, libc ของโฮสต์หรือลักษณะการทำงานที่ไม่ได้กำหนดไม่สามารถพกพาไปได้
  • ส่วนขยายประวัติ MARS ที่ขึ้นอยู่กับคลาส Java หรือปลั๊กอินเดสก์ท็อปจะไม่พร้อมใช้งาน
