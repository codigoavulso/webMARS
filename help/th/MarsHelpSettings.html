การตั้งค่า

การตั้งค่าครอบคลุมการนำเสนอแหล่งที่มา ความเข้ากันได้ของแอสเซมเบลอร์ เอาต์พุต Mini-C การคงอยู่ การเข้าถึงระบบคลาวด์ และขีดจำกัดรันไทม์

การตั้งค่าด่วน

การตั้งค่าเอฟเฟกต์
แสดงป้ายกำกับแสดงป้ายกำกับข้างที่อยู่ในมุมมองรันไทม์ หากมี
อาร์กิวเมนต์ของโปรแกรมพร้อมต์สำหรับการโต้แย้งก่อนดำเนินการ $a0 รับ argc และ $a1 รับ argv; Mini-C C1-NATIVE เปิดเผยข้อมูลเดียวกันกับ main(int argc, char **argv).
syscalls อินพุตป๊อปอัปใช้กล่องโต้ตอบแบบฟอร์มสำหรับบริการอินพุตคอนโซล 5, 6, 7, 8 และ 12 แทนบานหน้าต่าง Run I/O
แยกข้อความ / รัน I/Oแสดงข้อความบิลด์และโปรแกรม I/O ในเวลาเดียวกัน
ที่อยู่ / ค่าฐานสิบหกสลับตารางรันไทม์ระหว่างการนำเสนอแบบเลขฐานสิบหกและเลขฐานสิบ มันไม่เปลี่ยนบิตที่เก็บไว้

ความเข้ากันได้ของแอสเซมบลีและการดำเนินการ

  • ประกอบเมื่อเปิด และ ประกอบไฟล์ทั้งหมด ทำให้ขอบเขตบิลด์ที่เลือกเป็นแบบอัตโนมัติ
  • ถือว่าคำเตือนเป็นข้อผิดพลาด ทำให้คำเตือนล้มเหลวในการประกอบ
  • เริ่มที่หลัก เริ่มต้นที่ระดับโลก main ป้ายเมื่อมีอยู่
  • คำแนะนำเพิ่มเติม (หลอก) เปิดใช้งานแค็ตตาล็อกคำสั่งหลอกที่แสดงในวิธีใช้
  • การแตกแขนงล่าช้า เปิดใช้งานพฤติกรรมสล็อตดีเลย์ทางสถาปัตยกรรม
  • รหัสแก้ไขด้วยตนเอง อนุญาตให้เขียนไปยังหน่วยความจำที่ปฏิบัติการได้ เปิดใช้งานเฉพาะกับโปรแกรมที่ตั้งใจต้องการเท่านั้น

อินเทอร์เฟซ

เลือกธีมอินเทอร์เฟซ (สว่างหรือมืด) ภาษา UI เค้าโครงเมนูด้านบนหรือด้านข้าง ขนาดแบบอักษรของตัวแก้ไข ระยะห่างระหว่างบรรทัด และลักษณะการไฮไลต์ มีอินเทอร์เฟซภาษาอังกฤษ สเปน โปรตุเกส จีนกลาง ฮินดี อารบิก ฝรั่งเศส เบงกาลี รัสเซีย อินโดนีเซีย เยอรมัน ญี่ปุ่น เกาหลี ตุรกี เวียดนาม อูรดู อิตาลี โปแลนด์ เปอร์เซีย และไทย ความช่วยเหลือเป็นไปตามภาษา UI ที่ใช้งานอยู่ ภาษาอาหรับ ภาษาอูรดู และเปอร์เซียจะสลับอินเทอร์เฟซเป็นแบบขวาไปซ้ายโดยอัตโนมัติ ในการเข้าชมครั้งแรก webMARS ใช้ภาษาของเบราว์เซอร์ที่รองรับหรือถอยกลับไปเป็นภาษาอังกฤษ การเลือกที่ชัดเจนจะถูกบันทึกและจะมีลำดับความสำคัญ ธีมที่เลือกจะถูกจัดเก็บตามการตั้งค่าของคุณและนำไปใช้กับอินเทอร์เฟซทั้งหมด รวมถึงหน้าต่างเครื่องมือและวิธีใช้

หน่วยความจำรันไทม์ &

การตั้งค่าช่วง / ทางเลือก
การกำหนดค่าหน่วยความจำค่าเริ่มต้น กระชับข้อมูลที่ที่อยู่ 0 หรือข้อความกระชับที่ที่อยู่ 0
หน่วยความจำสูงสุด0.25–2 GiB ขึ้นอยู่กับขีดจำกัดหน่วยความจำในทางปฏิบัติของเบราว์เซอร์
ย้อนรอยประวัติศาสตร์0–1,000,000 ก้าวที่บันทึกไว้; ค่าเริ่มต้น 100
ตัวจัดการข้อยกเว้นที่อยู่ MIPS ที่ถูกต้องสมบูรณ์ เป็นค่าเริ่มต้น 0x80000180.

ความคงอยู่และเมฆ

สถานะร้านค้า และ สถานะโหลด จัดการสแนปชอตรันไทม์ในเครื่องให้สมบูรณ์ ล้างพื้นที่เก็บข้อมูลในตัวเครื่อง ลบการตั้งค่า webMARS โปรเจ็กต์ที่บันทึกไว้ สถานะการกู้คืน และตำแหน่งเครื่องมือหลังจากการยืนยัน

คลาวด์เซิร์ฟเวอร์ เปลี่ยนจุดสิ้นสุดที่ใช้โดยเมนูเสริม Cloud ข้อมูลประจำตัวและข้อมูลโครงการจะถูกส่งเมื่อคุณเรียกใช้คุณสมบัติระบบคลาวด์เท่านั้น

การเปลี่ยนตัวเลือกการแมปหน่วยความจำหรือความเข้ากันได้ของแอสเซมเบลอร์จะทำให้สมมติฐานที่ทำโดยโปรแกรมที่ประกอบไว้แล้วเป็นโมฆะ ประกอบกลับหลังจากเปลี่ยนแล้ว
