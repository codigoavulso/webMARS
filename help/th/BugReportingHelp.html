สนับสนุน

รายงานข้อบกพร่อง webMARS และช่องว่างด้านเอกสารในพื้นที่เก็บข้อมูลโปรเจ็กต์ หรือติดต่อผู้ดูแลโดยตรง

รายงานข้อผิดพลาดที่เป็นประโยชน์ประกอบด้วย

  • แอสเซมบลีที่เล็กที่สุดหรือโครงการ C ที่สร้างปัญหาซ้ำ
  • ลำดับการคอมไพล์/แอสเซมบลี/รันที่แน่นอน และผลลัพธ์ที่คุณคาดหวัง
  • ข้อความที่สมบูรณ์และข้อความ Run I/O ไฟล์ → ดัมพ์รัน I/O สามารถส่งออกทรานสคริปต์ได้
  • การตั้งค่าที่เกี่ยวข้อง: โปรไฟล์คอมไพเลอร์ แผนที่หน่วยความจำ การแตกสาขาล่าช้า คำแนะนำหลอก และโค้ดที่แก้ไขตัวเอง
  • ชื่อ/เวอร์ชันของเบราว์เซอร์ และปัญหาเกิดขึ้นหลังจากการโหลดซ้ำในโปรเจ็กต์ภายในเครื่องที่ปลอดภัยหรือไม่

ก่อนยื่น

  1. ลองใช้ตัวอย่างการรวมกลุ่มที่ใกล้เคียงที่สุดแล้วเปรียบเทียบการตั้งค่า
  2. ประกอบใหม่หลังจากเปลี่ยนการตั้งค่ารันไทม์หรือหน่วยความจำ
  3. อย่ารวมรหัสผ่าน ข้อมูลเซสชันคลาวด์ หรือแหล่งที่มาส่วนตัวที่ไม่สามารถแชร์ได้
