Mini-C

คอมไพลเลอร์การสอนในตัวจะแปลเซ็ตย่อย C ที่จงใจกำหนดเป็นแอสเซมบลี MIPS32 โดยใช้หลักการเรียก o32 ไม่ใช่คอมไพเลอร์ C ISO สำหรับการใช้งานทั่วไป

โปรไฟล์

โปรไฟล์วัตถุประสงค์
C0-S0 ถึง C0-S4ชุดย่อยการสอนแบบสะสม พัฒนาจากนิพจน์และโฟลว์การควบคุมไปยังฟังก์ชัน อาร์เรย์ พอยน์เตอร์ โครงสร้าง typedefs สัญญา และไลบรารี
C1-NATIVEโปรไฟล์เริ่มต้นที่มีความสามารถมากที่สุด: ระบุที่อยู่แบบไบต์ char/char *, สตริงดั้งเดิม argc/argv, พอยน์เตอร์ฟังก์ชัน และ void *.

หากแหล่งที่มาต้องการโปรไฟล์ที่สูงกว่า การคอมไพล์จะส่งเสียงที่โฟกัสหนึ่งรายการ MC_SUBSET_MISMATCH การวินิจฉัยมากกว่าการเกิดข้อผิดพลาดรอง

รวบรวมโครงการ

  1. เลือกโปรไฟล์ที่ต้องการและตัวเลือกเอาต์พุตใน การตั้งค่า → การตั้งค่า Mini-C.
  2. เปิดอย่างน้อยหนึ่งรายการ .c ไฟล์ในโครงการเดียวกัน
  3. เลือก เรียกใช้ → คอมไพล์ C0 หรือกด F4.
  4. ตรวจสอบการวินิจฉัยและสร้างชุดประกอบ MIPS ประกอบและรันโปรแกรมที่สร้างขึ้นตามปกติ

การโทรแบบแผนและจุดเริ่มต้น

  • อาร์กิวเมนต์ใช้ $a0–$a3อาร์กิวเมนต์เพิ่มเติมใช้สแต็ก และใช้ค่าส่งคืน $v0 (และ $v1 ตามความเหมาะสม)
  • รีจิสเตอร์ที่บันทึกไว้ของผู้ถูกเรียกและเฟรมสแต็กเป็นไปตามความคาดหวังของ MIPS o32
  • main(void) และใน C1-NATIVE main(int argc, char **argv) ได้รับการสนับสนุน
  • สำหรับอาร์กิวเมนต์ของโปรแกรม webMARS argv[0] เป็นโทเค็นแรกที่จัดทำโดยผู้ใช้ ไม่มีการป้อนชื่อปฏิบัติการอัตโนมัติ

ส่วนหัวและไลบรารีที่แถมมา

สตูดิโอโคนิโอไฟล์ หาเรื่องเชือกstring_native แยกวิเคราะห์รูปภาพยูทิลิตี้ แรนด์ประเภทstdlib stdboolมาตรฐานบิตแมป_rect bitmap_asciiทีตี้

ส่วนหัวเหล่านี้คือ webMARS ไลบรารีความเข้ากันได้ที่สร้างขึ้นจากการโทรและอุปกรณ์ MIPS พวกเขาใช้ชุดย่อยที่มีเอกสารประกอบ ไม่ใช่ไลบรารีมาตรฐาน C โฮสต์แบบเต็ม

#use <bitmap_rect> นอกจากนี้ยังมี bitmap_configure_display, bitmap_configure_terminal และ bitmap_configure_allอนุญาตให้โปรแกรม C0 ส่งขนาดการแสดงผล ขนาดหน่วย และที่อยู่บัฟเฟอร์เฟรมไปยังเครื่องมือบิตแมป

ตัวอย่างการเริ่มต้นที่ดี

  • สวัสดีชาวโลก (ซี) เพื่อโปรแกรมที่สมบูรณ์น้อยที่สุด
  • Mini-C C1 เนทีฟ สำหรับสตริงดั้งเดิมและลักษณะการทำงานของโปรไฟล์ปัจจุบัน
  • การสาธิตไลบรารีอาร์กิวเมนต์ สำหรับ argc/argv.
  • สถิติหลายไฟล์ สำหรับการคอมไพล์ทั่วทั้งโปรเจ็กต์และการเรียกใช้ฟังก์ชันข้ามไฟล์
  • ข้อมูลพื้นฐานเกี่ยวกับคอนโซล stdio และ ไฟล์ stdio ไป-กลับ สำหรับไลบรารีความเข้ากันได้
คู่มือคอมไพเลอร์ในพื้นที่เก็บข้อมูลยังคงเป็นการอ้างอิงภาษาเชิงบรรทัดฐานและมีรายละเอียด หน้าในแอปสรุปพฤติกรรมที่จำเป็นในการเลือกโปรไฟล์และเรียกใช้ตัวอย่างอย่างถูกต้อง
