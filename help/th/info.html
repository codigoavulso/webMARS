webMARS __เว็บมาร์ส_APP_VERSION__

สภาพแวดล้อมการเรียนรู้ MIPS32 แบบเนทีฟของเบราว์เซอร์พร้อมแอสเซมเบลอร์, ตัวจำลอง JavaScript, ดีบักเกอร์, คอมไพเลอร์ Mini-C ตัวอย่าง และอุปกรณ์โต้ตอบ

ไม่มีการติดตั้ง

เรียกใช้แอปในเบราว์เซอร์ที่ทันสมัย ไม่จำเป็นต้องใช้ Java และ WebAssembly

ท้องถิ่นเป็นอันดับแรก

แก้ไข คอมไพล์ รัน บันทึกลงพื้นที่เก็บข้อมูลของเบราว์เซอร์ และดาวน์โหลดโดยไม่ต้องลงชื่อเข้าใช้

เน้นการสอน

ใช้ไวยากรณ์ MARS-style MIPS, syscalls, แมปหน่วยความจำ, เครื่องมือ และโปรไฟล์ Mini-C ที่มีโครงสร้าง

ความสามารถในปัจจุบัน

  • การดำเนินการ MIPS32 จำนวนเต็ม หน่วยความจำ สาขา ข้อยกเว้น LL/SC และ COP1
  • การอ้างอิงคำสั่งพื้นฐานและคำสั่งหลอก มาโคร และความเข้ากันได้ของแอสเซมเบลอร์ที่กำหนดค่าได้
  • เบรกพอยต์ ขั้นตอน ถอยหลัง หยุด หยุด รีเซ็ต และสแนปช็อตสถานะรันไทม์
  • C0-S0 ถึง C0-S4 และ C1-NATIVE Mini-C ที่กำหนดเป้าหมาย o32
  • เครื่องมือรันไทม์สิบแปดเครื่องมือ ตัวอย่างที่รวบรวมไว้ในยี่สิบภาษาและโปรเจ็กต์ระบบคลาวด์เสริม
  • การคอมไพล์ รวบรวม และรันการวัดประสิทธิภาพภายในเครื่องพร้อมการใช้งาน JavaScript โดยประมาณ

ความเป็นส่วนตัว

webMARS ไม่มีโฆษณา ไฟล์ต้นฉบับ การกำหนดค่าตามความชอบ ไฟล์เสมือน ข้อมูลการกู้คืน การวัดประสิทธิภาพ และสถานะรันไทม์จะยังคงอยู่ในอุปกรณ์ตามค่าเริ่มต้น ตัวอย่างเกณฑ์มาตรฐานมีความผันผวนและไม่มีการส่งต่อ

คุณสมบัติคลาวด์เป็นทางเลือก เมื่อคุณลงชื่อเข้าใช้หรือซิงโครไนซ์ ข้อมูลบัญชี/เซสชันและโปรเจ็กต์จะถูกส่งไปยังเซิร์ฟเวอร์คลาวด์ที่กำหนดค่าในการตั้งค่า ตรวจสอบข้อกำหนดของผู้ให้บริการก่อนที่จะใช้เซิร์ฟเวอร์ของบุคคลที่สามหรือเซิร์ฟเวอร์ที่กำหนดเอง การดาวน์โหลดและไฟล์ที่เปิดจากดิสก์จะใช้การควบคุมไฟล์ของเบราว์เซอร์ปกติ
