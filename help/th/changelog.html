บันทึกการเปลี่ยนแปลง

รีลีส 0.6.4 ปรับปรุงการวิเคราะห์การรับส่งข้อมูล เพิ่มตัวเลือกการลงชื่อเข้าใช้โซเชียล และอัปเดตคู่มืออิสระ

0.6.4 — การวิเคราะห์การรับส่งข้อมูลและการลงชื่อเข้าใช้โซเชียล

  • เพิ่มตัวเลือกการลงชื่อเข้าใช้ Google และ Facebook ผ่าน BackMars รวมถึงการเชื่อมโยงไปยังบัญชี Cloud ที่มีอยู่อย่างชัดเจน
  • แยกการรับส่งข้อมูลสาธารณะ ภายใน ทดสอบ และอัตโนมัติ พร้อมสัญญาณการโต้ตอบของมนุษย์ที่เป็นไปได้ และการเปรียบเทียบเว็บ/แอปโดยรวม
  • เพิ่มบัญชีรวมและสถิติกิจกรรม Cloud ตัวกรองผู้ชม และแผนภูมิการใช้งานที่ชัดเจนยิ่งขึ้น
  • อัปเดตคู่มืออิสระเป็น 0.2.0 และลบเนื้อหาดั้งเดิมที่ไม่ได้ใช้ออกในขณะที่ยังคงรักษาการอ้างอิง MARS

0.6.3 — สถิติสาธารณะและการค้นพบโครงการ

  • เพิ่มหน้าต่างสถิติการใช้งานแบบผสานรวมกับแผนภูมิในช่วง 60 นาที 24 ชั่วโมง และ 30 วันที่ผ่านมา ตัวกรองที่ปรับแต่งได้ และตารางค่าที่แน่นอน
  • เผยแพร่ข้อมูลการใช้งานแบบรวมเท่านั้นโดยไม่มีตัวระบุเซสชัน โดยแยกเวลาโต้ตอบออกจากการแสดงตนที่มองเห็นได้
  • ทำให้ห้องสมุดสาธารณะสามารถค้นหาและแบ่งหน้าได้ โดยมีรายการโครงการโดยละเอียดแทนกล่องโต้ตอบการเลือก
  • ขยายการวัดการใช้งานอัตโนมัติและตัวอย่างการเต้นของหัวใจที่เชื่อมโยงไปยังเซสชันชั่วคราวเดียวกันกับกิจกรรมอื่นๆ

0.6.2 — หน้าการเรียนรู้สาธารณะและตัวชี้วัดระยะเวลา

  • เพิ่มหน้าการค้นพบภาษาอังกฤษและโปรตุเกสสาธารณะสำหรับภาพรวมผลิตภัณฑ์ เส้นทางการเรียนรู้ การสอน สแต็ก ไปป์ไลน์ Mini-C และความเป็นส่วนตัว
  • เพิ่มการเต้นของหัวใจพื้นหลังเฉพาะระยะเวลาที่รายงานวินาทีที่ใช้งานสะสมโดยไม่มีตัวระบุ คุกกี้ หรือข้อมูลเซสชันที่เก็บไว้
  • เพิ่มตัวรวบรวม Raspberry Pi และการกำหนดค่าการใช้งานสำหรับฮาร์ทบีท โดยปิดใช้งานการบันทึกการเข้าถึงสำหรับปลายทาง
  • จัดทำเอกสารหน้าสาธารณะ การตีความตัวชี้วัด การเก็บรักษา และลำดับการใช้งาน ในขณะที่ปิดใช้งานตัวชี้วัดเหตุการณ์ที่สมบูรณ์ยิ่งขึ้นโดยค่าเริ่มต้น
  • ขยายการตรวจสอบการเผยแพร่และบรรจุภัณฑ์เพื่อให้ครอบคลุมหน้าใหม่ การทดสอบฮาร์ทบีท และตัวรวบรวม

0.6.1 — แพ็คเกจที่สมบูรณ์และลิงค์ที่เสถียรยิ่งขึ้น

  • รวม Manual และ Teacher Kit เวอร์ชันอิสระในการปรับใช้ ZIP กำจัดลิงก์ /manual/ ที่ไม่ทำงานในการติดตั้งใหม่
  • ทำให้รีจิสทรี example-ID ที่เชื่อถือได้ถาวร: การเปลี่ยนเส้นทางที่ถูกต้องยังคงแก้ไขได้ ในขณะที่หลุมฝังศพ รหัสที่ไม่รู้จัก และลูปการเปลี่ยนเส้นทางล้มเหลวในการปิด
  • ทำให้การแบ่งหน้าห้องสมุดสาธารณะเป็นไปตามผลลัพธ์ BackMars ที่ชัดเจนของ hasMore ในขณะที่ยังคงความเข้ากันได้กับการติดตั้งรุ่นเก่า
  • แก้ไขคอนทราสต์ของธีมสว่างและมืดในแอปพลิเคชันและกำหนดเอง และตั้งชื่อข้อความโต้ตอบให้สามารถเข้าถึงได้
  • ขยายการตรวจสอบการเผยแพร่สำหรับคู่มือที่ให้มา, แฮชการล็อคผลิตภัณฑ์, โมดูล JavaScript และลิงก์ภายใน
  • แก้ไขข้อมูลผลิตภัณฑ์เป็นภาษาท้องถิ่นเพื่อรายงานเครื่องมือ 20 ชิ้นที่จัดส่งจริง

0.6.0 — ห้องเรียนที่มั่นคงและห้องสมุดสาธารณะ

  • เพิ่มลิงก์โดยตรงแบบถาวรสำหรับทุกตัวอย่างในตัว รหัสที่เสถียรจะอยู่ในรีจิสทรีเฉพาะและจะไม่ถูกลบหรือนำมาใช้ซ้ำ รายการที่เลิกใช้แล้วยังคงเป็นป้ายหลุมศพหรือการเปลี่ยนเส้นทางที่ชัดเจน
  • เพิ่มการเผยแพร่โครงการสาธารณะผ่าน BackMars สิ่งพิมพ์ทุกชิ้นจะได้รับชื่อสาธารณะที่ไม่ซ้ำกันทั่วโลกในการใช้งานนั้น ตามลำดับก่อนหลัง และเปิดผ่านลิงก์ /p/name สั้นๆ
  • ทำให้การแก้ไขที่เผยแพร่ไม่เปลี่ยนรูป ลิงก์ที่ไม่ได้ปักหมุดจะเป็นไปตามเวอร์ชันแก้ไขล่าสุดที่ใช้งานอยู่ ในขณะที่ /p/name@N ยังคงเปิดสแนปชอตในอดีตที่แน่นอนแม้ว่าจะเป็นไฟล์เก็บถาวรแบบธรรมดาก็ตาม
  • เพิ่มเบราว์เซอร์ห้องสมุดสาธารณะพร้อมการค้นหา การเพจ และการแสดงตัวอย่างแบบอ่านอย่างเดียว การเปิดสิ่งพิมพ์จะสร้างสำเนาในเครื่องที่ชัดเจน ดังนั้นสื่อสาธารณะจะไม่เปลี่ยนแปลงโครงการของผู้เขียนหรือเข้าสู่พื้นที่เก็บข้อมูล Cloud
  • จัดทำเวอร์ชันและฆ่าเชื้อรูปแบบการแลกเปลี่ยนสาธารณะ สิ่งพิมพ์ประกอบด้วยเฉพาะไฟล์โครงการและข้อมูลเมตาการสอนที่ปลอดภัย โดยมีข้อจำกัดที่เข้มงวดบังคับใช้โดยเบราว์เซอร์และ BackMars
  • เพิ่มการกู้คืนรหัสผ่านทางอีเมลโดยใช้รหัสแบบใช้ครั้งเดียวที่หมดอายุ การรีเซ็ตสำเร็จจะทำให้เซสชันที่มีอยู่เป็นโมฆะ และคำขอจะไม่เปิดเผยว่ามีการลงทะเบียนที่อยู่หรือไม่
  • เพิ่มการยืนยันอีเมลและส่งขั้นตอนอีกครั้ง การปรับใช้อาจต้องมีที่อยู่ที่ได้รับการยืนยันก่อนที่จะเผยแพร่ ในขณะเดียวกันก็รักษาการแก้ไข ตัวอย่าง และการจำลองในเครื่องไว้ได้โดยไม่ต้องใช้บัญชี
  • ย้ายชื่อการติดตั้ง เส้นทางพื้นฐาน สาธารณะ URL, BackMars จุดสิ้นสุด คู่มือ และลิงก์สนับสนุนไปยัง webmars-config.js เพื่อให้มหาวิทยาลัยสามารถปรับใช้อินสแตนซ์อิสระโดยไม่ต้องแก้ไขโค้ดแอปพลิเคชัน
  • แทนที่หน้าต่างเกี่ยวกับที่รันครั้งแรกโดยอัตโนมัติด้วยหน้าต่างต้อนรับที่แนะนำ ในขณะที่ยังคงรักษาเกี่ยวกับไว้ภายใต้วิธีใช้และให้ความสำคัญกับตัวอย่างโดยตรงหรือลิงก์สิ่งพิมพ์
  • เพิ่มชุดอุปกรณ์สำหรับครูที่ครอบคลุมการโยกย้ายจาก MARS คลาสแรก ข้อความ LMS การเผยแพร่ลิงก์ที่เสถียร โซลูชัน และการตัดสินใจโฮสต์ด้วยตนเอง/ความเป็นส่วนตัว
  • เริ่มคู่มือ webMARS เวอร์ชันอิสระที่เวอร์ชัน 0.1 พร้อมด้วยบทที่มีรายละเอียด ภาพหน้าจอธีมสว่าง และการตรวจสอบอย่างชัดเจนกับเวอร์ชัน webMARS
  • เพิ่มคำแนะนำในการใช้งานจริงและการกำหนดค่าเส้นทางสำหรับ URL ที่เสถียร พื้นที่จัดเก็บฐานข้อมูลส่วนตัว การสำรองข้อมูล การย้าย Gmail SMTP และการทดสอบควันหลังการปรับใช้งาน

0.5.6 — ไปป์ไลน์เป็นไปตามโปรแกรม

  • เพิ่มสตรีมการดำเนินการที่บันทึกไว้ไปยัง Pipeline Lab แทนที่จะสมมติว่าสาขาแก้ไขได้อย่างไร โมเดลจะเล่นซ้ำลำดับ webMARS ที่ดำเนินการจริง ดังนั้นกิ่งที่นำมา การคาดเดาที่ผิด และคำสั่งที่ถูกละทิ้งจึงเป็นข้อเท็จจริงมากกว่าการสันนิษฐาน
  • เพิ่มมุมมองรีจิสเตอร์: ค่าของทุกรีจิสเตอร์ที่รอบปัจจุบัน ค่าที่ยังคงอยู่ในการบินในระยะก่อนหน้า และตารางของทุกรีจิสเตอร์เทียบกับรอบที่เปลี่ยนแปลง ค่าจะปรากฏเฉพาะเมื่อรันไทม์ระบุไว้เท่านั้น กระแสคงที่จงใจไม่แสดงเลย
  • เชื่อมโยงการขนส่งทั้งสอง คำสั่งหนึ่งที่ดำเนินการใน webMARS คือคำสั่งหนึ่งคำสั่งที่เข้าสู่ไปป์ไลน์ในทั้งสองทิศทาง: Step และ Backstep ในหน้าต่างหลักจะย้ายไปป์ไลน์ และตัวควบคุมขั้นตอนของเครื่องมือเองจะรันหรือเลิกรันโปรแกรมเมื่อขั้นตอนการดึงข้อมูลไม่มีอะไรเหลือให้อ่าน
  • เพิ่ม F8 สำหรับ Backstep ซึ่งไม่มีทางลัดในขณะที่ Step มี F7
  • สร้าง Pipeline Lab ใหม่เป็นไปป์ไลน์แนวตั้งโดยมีการลงทะเบียนไปป์ไลน์ระหว่างแต่ละคู่ของสเตจ ข้างไทม์ไลน์แทนที่จะอยู่ด้านบน เพื่อให้สเตจสามารถแสดงคำสั่ง บรรทัดแหล่งที่มา และค่าที่ใช้
  • ทำให้ Pipeline Lab วางตัวชิดหน้าต่างของตัวเองแทนที่จะเป็นหน้าจอ หน้าต่างแคบๆ บนจอแสดงผลขนาดใหญ่จึงพับในลักษณะเดียวกับที่โทรศัพท์ทำ และทุกกลุ่มควบคุมสามารถเปิดและปิดได้ด้วยมือ
  • เพิ่มตัวอัปเดตสถานที่เป้าหมายที่แปลเฉพาะสตริงที่แค็ตตาล็อกยังคงตอบเป็นภาษาอังกฤษ โดยไม่ต้องเขียนรายการใหม่ซึ่งแก้ไขด้วยมือแล้ว จะปฏิเสธการแปลใดๆ ที่เปลี่ยนตัวยึดตำแหน่ง
  • แปลสตริงอินเทอร์เฟซ 872 ซึ่งยังคงแสดงเป็นภาษาอังกฤษในสิบเจ็ดภาษา และเพิ่มการทดสอบที่ล้มเหลวเมื่อภาษาตอบอินเทอร์เฟซเป็นภาษาอังกฤษมากกว่าที่เคยเป็นมา
  • แก้ไข Pipeline Lab โดยไม่สนใจ Backstep ในหน้าต่างหลัก: รันไทม์ส่งมันในช่องที่เครื่องมือไม่ได้ฟัง ดังนั้นเครื่องมือจึงเล่นซ้ำคำแนะนำที่ยังไม่ได้ดำเนินการ
  • แก้ไขการก้าวในโหมดมือถือแทนที่แผงใดก็ตามที่ผู้อ่านเลือก โฟกัสที่เกิดจากการรันโปรแกรมจะไม่เปลี่ยนแผงที่มองเห็นอีกต่อไป การเปิดหน้าต่างใหม่หรือเปิดไว้แล้วก็ยังคงเป็นเช่นนั้น
  • แก้ไข Pipeline Lab แสดงเฉพาะขั้นตอนสุดท้ายในขณะที่ปฏิบัติตามโปรแกรม Stepping ซึ่งทำให้ไปป์ไลน์ระบายและเติมในทุกขั้นตอนแทนที่จะเติมให้เต็ม
  • แก้ไขโทเค็นสีอินเทอร์เฟซสามรายการที่ไม่เคยกำหนด ซึ่งปิดเสียงเครื่องหมายแผงในไทม์ไลน์ และเปิดเสียงข้อความที่ปิดเสียงในทั้งสองธีม
  • แก้ไขการเล่นซ้ำที่หยุดเล่นจนกว่าจะหมดรอบเมื่อการบันทึกกระโดดไปที่ไหนสักแห่งที่ไม่มีสาขาที่คาดการณ์ไว้ เช่น การรีเซ็ตโปรแกรมหรือตัวจัดการข้อยกเว้น
  • เพิ่ม npm run version:set ซึ่งเขียนเวอร์ชันลงในตำแหน่งทั้งสิบเอ็ดแห่งที่ประกาศเวอร์ชันนั้น และย้ายเวอร์ชันออกจากหน้าวิธีใช้ที่ระบุเวอร์ชันลงในโทเค็นรันไทม์
  • สร้างแบบจำลองการกำหนดเวลาของ Pipeline Lab ขึ้นมาใหม่: อันตรายจากการควบคุม ช่องหน่วงเวลาที่สามารถกำหนดค่าได้ การทำนายสาขาแบบคงที่และไดนามิก เวลาแฝงของหน่วยความจำที่กำหนดค่าได้ กับดักแบบอนุกรม และโปรไฟล์สถาปัตยกรรมเวอร์ชันแยกกันเจ็ดโปรไฟล์ที่สามารถเปรียบเทียบแบบเคียงข้างกันได้
  • เพิ่มมุมมองสถาปัตยกรรม การวาดดาต้าพาธด้วยรีจิสเตอร์ไปป์ไลน์ สายควบคุมตามคำสั่ง มัลติเพล็กเซอร์ เส้นทางการส่งต่อแบบสด และการตรวจจับอันตราย พร้อมกลุ่มสัญญาณที่สามารถซ่อนแยกกันได้
  • เพิ่มตารางประวัติสาขาที่แชร์กับเครื่องจำลอง BHT ดังนั้นเครื่องมือทั้งสองจะทำนายเหมือนกัน การทดสอบการถดถอยจะขับเคลื่อนตัวทำนายทั้งสองผ่านลำดับผลลัพธ์เดียวกันและล้มเหลวหากมีความแตกต่างกัน
  • เพิ่มการส่งออก JSON และ CSV ที่ทำซ้ำได้ซึ่งมีเวอร์ชันโมเดล เวอร์ชันโปรไฟล์ การกำหนดค่าแบบเต็ม และแฮชของโปรแกรม โดยไม่มีการประทับเวลา ดังนั้นงานเดียวกันจึงสร้างไฟล์ที่มีไบต์เหมือนกัน
  • เพิ่มห้องปฏิบัติการแนะนำเจ็ดแห่งโดยมีวัตถุประสงค์ ข้อกำหนดเบื้องต้น ขั้นตอนการคาดการณ์ก่อนดำเนินการ และคำถามสะท้อนกลับ รวมถึงเอกสารวิธีแก้ปัญหาแยกต่างหาก คู่มือการรับเลี้ยงบุตรบุญธรรมของครู และการนำเสนอสั้นๆ ทุกหมายเลขของใบเสนอราคาในเวิร์กชีตจะถูกวัดอีกครั้งโดยชุดทดสอบ
  • เพิ่มชุดดิฟเฟอเรนเชียลเทียบกับ Checksum ที่ปักหมุด MARS 4.5 การเปรียบเทียบรหัสเครื่อง ส่วนข้อมูล เอาต์พุตคอนโซล และรีจิสเตอร์ทั้งหมด 32 รายการ แปดในสิบเอ็ดโปรแกรมมีไบต์เหมือนกัน ความแตกต่างที่เหลืออีกสามประการได้รับการประกาศพร้อมเหตุผลและกรณีการผลิตซ้ำน้อยที่สุด
  • เพิ่มรายงานหลักฐานที่สร้างขึ้นสำหรับความเข้ากันได้ ความสอดคล้องของ MARS ความครอบคลุม คะแนนการกลายพันธุ์ เกณฑ์มาตรฐาน และความสามารถในการเข้าถึง แต่ละรายการสร้างขึ้นใหม่ด้วยคำสั่งเดียวและตรวจสอบโดยชุดทดสอบ
  • เพิ่มเกณฑ์มาตรฐานเกณฑ์มาตรฐานที่เผยแพร่พร้อมการประกาศวอร์มอัพ จำนวนการทำซ้ำ และกฎค่าผิดปกติ การรายงานค่ามัธยฐานที่มีช่วงระหว่างควอไทล์ และการบันทึกผลลัพธ์แต่ละผลลัพธ์จากเครื่อง
  • เพิ่มการทดสอบการกลายพันธุ์และการคลุมเครือที่กำหนดขอบเขตของแอสเซมเบลอร์ รันไทม์ และผู้นำเข้าสถานะ
  • แก้ไข Pipeline Lab ไม่ได้รับการอัปเดตรันไทม์หลังจากแอสเซมบลีแรก ซึ่งเกิดจากเครื่องมือรายงานว่าถูกตัดการเชื่อมต่อ
  • แก้ไขเป้าหมายสาขาเชิงสัญลักษณ์ที่ไม่เคยได้รับการแก้ไขในแบบจำลองกำหนดเวลา ซึ่งทำให้ทุกการทำนายสาขารายงานการคาดการณ์ที่ผิดเป็นศูนย์
  • แก้ไขข้อขัดข้องเมื่อนำเข้าสถานะรันไทม์ที่เสียหายหรือขาดหายไป ซึ่งเข้าถึงผู้ใช้เป็นหน้าจอว่างเปล่า
  • แก้ไขตัวแก้ไขและบานหน้าต่าง Mars Messages ไม่มีชื่อที่สามารถเข้าถึงได้ และสีข้อความด้านล่างค่าคอนทราสต์ขั้นต่ำ WCAG ในธีมสีอ่อน
  • แก้ไขคอลัมน์ไทม์ไลน์ที่ปักหมุดแยกออกในภาษาจากขวาไปซ้าย และเก็บไดอะแกรมไปป์ไลน์จากซ้ายไปขวาเพื่อให้ลำดับขั้นยังคงอ่านไปข้างหน้า
  • เพิ่มตัวเลือกสีที่ปลอดภัยในการมองเห็นสีสำหรับขั้นตอนไปป์ไลน์
  • เพิ่มเอกสารประกอบสำหรับนักพัฒนา: ขอบเขตของสถาปัตยกรรม, คู่มือการสนับสนุนครั้งแรก, คำแนะนำสำหรับการเพิ่มคำแนะนำ, syscalls และอุปกรณ์, ค่าคงที่รันไทม์, เครื่องมือที่มีเวอร์ชัน API พร้อมตัวอย่างการทำงานและตัวสร้างโครงร่าง และกระบวนการเผยแพร่

0.5.5 — Pipeline Lab และยี่สิบภาษา

  • เพิ่ม Pipeline Lab ห้าขั้นตอนที่กำหนดด้วยอันตราย RAW การส่งต่อ แผงลอย วงจรที่พลิกกลับได้ ตัวชี้วัด และไทม์ไลน์ที่ปรับขนาดได้
  • ขยายอินเทอร์เฟซ ตัวอย่าง เอกสาร และความช่วยเหลือจากสิบเป็นยี่สิบภาษา
  • ขยายพฤติกรรมของเครื่องมือที่ตอบสนอง การแปลเป็นภาษาท้องถิ่น และการถดถอยให้ครอบคลุมทั่วทั้งรีลีส

0.5.4 — MARS-OS เดสก์ท็อป จอแสดงผลเสมือน และธีมระบบ

  • เติมเต็มประสบการณ์ระบบปฏิบัติการ Windows 95 MARS ด้วยเมนู Start ตัวเรียกใช้งานแอปพลิเคชัน และหน้าต่างแบบเคลื่อนย้ายได้และปรับขนาดได้
  • ปรับปรุงเทอร์มินัล TTY ANSI การป้อนข้อมูลด้วยเมาส์ พฤติกรรมมือถือที่ตอบสนอง และแอปพลิเคชัน MARS-OS
  • เปิดใช้งานหน้าต่าง Fit ให้แสดงตามค่าเริ่มต้นใน TTY ANSI การแสดงบิตแมป และเทอร์มินัลบิตแมป
  • การตั้งค่าการแสดงผลเสมือนแบบยุบตามค่าเริ่มต้นทั้งบนเดสก์ท็อปและมือถือ
  • เพิ่มธีมระบบที่เป็นไปตามโทนสีของเบราว์เซอร์โดยอัตโนมัติ พร้อมการแทนที่แสงและความมืดอย่างชัดเจน

0.5.3 — แก้ไขการบูตสแตรปภาษาเบราว์เซอร์

  • รักษาภาษาที่ตรวจพบจากเบราว์เซอร์เมื่อแอปพลิเคชันสร้างการตั้งค่า UI เริ่มต้นเป็นครั้งแรก
  • เก็บค่ากำหนดภาษาที่บันทึกไว้อย่างชัดเจนไว้ก่อนการตรวจจับอัตโนมัติ และคงภาษาอังกฤษไว้เป็นทางเลือกสำหรับภาษาที่ไม่รองรับ
  • เพิ่มการครอบคลุมการถดถอยสำหรับภาษาเบราว์เซอร์ในภูมิภาคและบูตสแตรปการตั้งค่าเซสชันใหม่ทั้งหมด

0.5.2 — สิบภาษา, การเลือกอัตโนมัติ, MARS-OS เดสก์ท็อป

  • ขยายอินเทอร์เฟซที่สมบูรณ์ แค็ตตาล็อกตัวอย่าง เอกสาร และความช่วยเหลือจากภาษาอังกฤษ สเปน และโปรตุเกสเป็นสิบภาษา เพิ่มภาษาจีนกลาง ฮินดี อารบิก ฝรั่งเศส เบงกาลี รัสเซีย และอินโดนีเซีย
  • เพิ่มการตรวจจับภาษาเบราว์เซอร์สำหรับการเข้าชมครั้งแรกด้วยการปรับรหัสภูมิภาคให้เป็นมาตรฐานและทางเลือกภาษาอังกฤษ ในขณะที่ยังคงรักษาการตั้งค่าที่บันทึกไว้อย่างชัดเจน
  • เพิ่มรูปแบบภาษาอาหรับจากขวาไปซ้ายในขณะที่ยังคงรักษาซอร์สโค้ด เอาต์พุตรันไทม์ และสัญกรณ์ทางเทคนิคจากซ้ายไปขวา
  • ปรับปรุงระบบปฏิบัติการ MARS-OS ให้เป็นเดสก์ท็อปที่ขับเคลื่อนด้วยเมาส์ ซึ่งเปิดโดยตรงใน Program Manager และรันคำสั่งเชลล์ภายในแอป Terminal
  • ปรับปรุงปริมาณงาน TTY ขนาดอุปกรณ์พกพาที่รับรู้ด้วยแป้นพิมพ์ Android และระยะห่างแนวตั้งของเดสก์ท็อป
  • เพิ่มการสร้างการแปลเป็นภาษาท้องถิ่นที่ทำซ้ำได้ คำศัพท์ทางเทคนิคที่ได้รับการคุ้มครอง และการครอบคลุมการถดถอยสิบภาษาเต็มรูปแบบ

0.5.1 — การขัดจังหวะอุปกรณ์, เครื่องมือรันไทม์, MARS - นาฬิการะบบปฏิบัติการ

  • ใช้งานการขัดจังหวะภายนอกพร้อมกันสำหรับตัวจับเวลา คีย์บอร์ด จอแสดงผล และแผงปุ่มกดเลขฐานสิบหกของ Digital Lab โดยมีการมาสก์ด้านข้าง CPU และการส่งมอบสถานะที่รอดำเนินการ
  • เพิ่มเครื่องมือ System Clock และ Stack Visualizer รวมถึง delta แบบกระจายแบบรวมศูนย์ที่เข้ากันได้กับ backsteps ที่แน่นอน
  • ลดค่าใช้จ่ายของเครื่องมือที่เชื่อมต่อผ่านชุดคำสั่งที่ถอดรหัส การเรนเดอร์แบบรวม และประวัติเหตุการณ์รันไทม์แบบมีขอบเขต
  • เพิ่มตัวอย่างการขัดจังหวะตัวจับเวลาที่แปลแล้วและขยาย MARS-OS ด้วยการทำงาน clock และเรียลไทม์ bench คำสั่ง
  • ป้องกันสแนปชอตรันไทม์แบบกะทัดรัดจากการล้างส่วนข้อความที่ประกอบใน UI การดำเนินการเป็นการชั่วคราว
  • รวมตัวจัดการไฟล์และสัญญาระบบคลาวด์เข้าด้วยกันด้วยการบันทึกที่ปลอดภัยต่อข้อขัดแย้ง การเปลี่ยนชื่อ/ลบระยะไกล ข้อมูลประจำตัวของโปรเจ็กต์ที่ไม่คำนึงถึงตัวพิมพ์เล็กและใหญ่ และสถานะการซิงค์แบบแบตช์

0.5.0 — รันไทม์ที่สมบูรณ์, delta backstep, เวิร์กโฟลว์แบบเคลื่อนที่

  • แก้ไขพฤติกรรมรันไทม์ที่มีผลกระทบสูงข้ามขีดจำกัดหน่วยความจำ, ร้านค้าอะตอมมิก, COP1 เพิ่มเป็นสองเท่าและการปัดเศษ, สาขาล่าช้า, ข้อยกเว้น, การจอง LL/SC และจุดพัก
  • แทนที่สแน็ปช็อตตามคำสั่งแบบเต็มด้วยเดลต้าผกผันที่มีขอบเขต ในขณะที่ยังคงรักษาหน้าต่างแบ็คสเต็ปที่แน่นอนและสถานะของเครื่องมือที่ซิงโครไนซ์
  • ลดค่าใช้จ่ายในการดำเนินการผ่านแบตช์เหตุการณ์รันไทม์ขนาดกะทัดรัด การเรนเดอร์เครื่องมือที่รวมเข้าด้วยกัน และการซิงโครไนซ์ UI ที่เบากว่า
  • เพิ่มการกำหนดค่าบิตแมปแบบไดนามิก MMIO และอัปเดตตัวอย่างบิตแมปและไลบรารีเพื่อใช้งานในขณะที่ยังคงเข้ากันได้กับ MARS 4.5
  • ขยายตัวอย่าง TTY ด้วยเชลล์ MIPS ที่ใช้งานได้จริง และปรับปรุง Assembly และ Mini-C แค็ตตาล็อกบทเรียนในทั้งสามภาษา
  • เครื่องมือ กล่องโต้ตอบ คลาวด์ และการตั้งค่าที่ผสานรวมเข้ากับระบบหน้าต่างมือถือ รวมถึงการปรับขนาดแป้นพิมพ์ของ Android แป้นพิมพ์เสมือนจริงเชิงความหมาย และการเลื่อนที่มี
  • เพิ่มรันไทม์ เครื่องมือ ตัวอย่าง เอกสาร UI มือถือ และการครอบคลุมการถดถอยของรุ่นที่ครอบคลุม

0.4.13 — โครงร่างแผงเดียวแบบเคลื่อนที่, การวินิจฉัยแบบท้องถิ่น

  • อุปกรณ์เคลื่อนที่จะแสดงแผงแบบเต็มหน้าจอครั้งละหนึ่งแผง โดยเลือกจากแถบแท็บไอคอนใหม่ซึ่งแสดงรายการหลัก ข้อความ/รัน I/O รีจิสเตอร์ และเครื่องมือที่เปิดอยู่
  • ปักหมุดวิวพอร์ตบนมือถือเพื่อไม่ให้หน้าเลื่อนอีกต่อไป โดยลบข้อขัดแย้งของการเลื่อนแบบซ้อนระหว่างเอกสารและเนื้อหาของหน้าต่าง
  • แถบเครื่องมือบนมือถือจะแสดงเฉพาะไอคอนบนสองแถวขนาดกะทัดรัด โดยคงการควบคุมการดำเนินการและตัวเลือกความเร็วในการทำงานไว้บนหน้าจอ การทำงานของไฟล์จะถูกซ่อนอยู่ที่นั่นและยังคงอยู่ในเมนูไฟล์และแก้ไข
  • ซ่อนปุ่มย่อและขยายใหญ่สุดบนมือถือ โดยที่แผงหนึ่งเต็มหน้าจอ และแถบแท็บทำหน้าที่สลับ
  • แปลแอสเซมเบลอร์ทุกตัวและการวินิจฉัย Mini-C โดยแปลงตัวอักษรเทมเพลต 114 ตัวเป็นตัวยึดตำแหน่งที่มีชื่อ และเพิ่ม 277 คีย์ในสามภาษา
  • เพิ่มการทดสอบการเผยแพร่ที่ล้มเหลวเมื่อข้อความที่แปลได้ไม่มีรายการแค็ตตาล็อก
  • เค้าโครงเดสก์ท็อป ตำแหน่งหน้าต่าง และขนาดการควบคุมไม่เปลี่ยนแปลง

0.4.12 — ธีมสีเข้ม, การแก้ไขขนาดตัวอักษร, การล้างโค้ดที่ไม่ทำงาน

  • เพิ่มการเลือกใช้ธีมสีเข้มที่สามารถเลือกได้ผ่านทาง Settings > Interface...ใช้กับตัวแก้ไข หน้าต่างเครื่องมือ และหน้าวิธีใช้
  • แก้ไขขนาดตัวอักษรของตัวแก้ไขและความสูงของบรรทัดทันทีหลังจากเปลี่ยนในการตั้งค่าอินเทอร์เฟซโดยไม่ต้องโหลดหน้าซ้ำ
  • แบบมีสาย ปิดไฟล์ทั้งหมด การกระทำเข้าไป File > Close > All files.
  • ลบไปป์ไลน์บันทึกอัตโนมัติของเซสชันเครื่อง (~400 บรรทัด) ที่ถูกกั้นไว้ด้านหลังแฟล็กทดลองที่ไม่เคยตั้งค่าไว้ในรีลีสใดๆ
  • ลบฟังก์ชันที่ไม่ทำงานประมาณ 15 รายการในห้าโมดูล การส่งออกรีจิสทรีที่ไม่ได้ใช้ ตัวเลือก CSS ที่ไม่ทำงาน และคีย์ i18n ที่ไม่ได้ใช้ 113 รายการ
  • แยกไฟล์วิธีใช้ระดับรูทที่ไม่สามารถเข้าถึงได้ออกจากแพ็คเกจที่วางจำหน่าย

0.4.11 — การกู้คืนการเข้าสู่ระบบคลาวด์แบบถาวร

  • ตรวจสอบเซิร์ฟเวอร์คลาวด์ที่กำหนดค่าโดยไม่โต้ตอบระหว่างการเริ่มต้นแอปพลิเคชัน และกู้คืนผู้ใช้ที่ได้รับการรับรองความถูกต้องที่มีอยู่
  • รีเฟรชข้อมูลเมตาโปรเจ็กต์บนคลาวด์หลังจากการกู้คืนเซสชันสำเร็จโดยไม่ปิดกั้นพื้นที่ทำงานในพื้นที่
  • บันทึกอายุการใช้งานสูงสุดของคุกกี้การรับรองความถูกต้องหนึ่งปีและการลบออกทันทีเมื่อออกจากระบบ
  • เพิ่มการครอบคลุมการถดถอยสำหรับคำขอข้อมูลประจำตัวและการกู้คืนการเริ่มต้นอัตโนมัติ

0.4.10 — ประวัติเครื่องมือเป็นชุดและการอัปเดต UI ที่เบากว่า

  • สันดอนเครื่องมือที่เก็บรักษาไว้สำหรับคำแนะนำเท่านั้นที่ยังคงครอบคลุมอยู่ในหน้าต่างถอยหลัง 100 ขั้นที่แน่นอนของเครื่องยนต์
  • ทำให้ทุกเหตุการณ์รันไทม์พร้อมใช้งานสำหรับโมเดลเครื่องมือในขณะที่รวมการอัปเดตภาพและหลีกเลี่ยงการจัดสรรประวัติที่ล้าสมัย
  • ลดการทำงานตามคำสั่ง DOM ใน BHT และสำเนาสถานะซ้ำซ้อนในเครื่องจำลองแคช
  • หยุดการเรนเดอร์ Mars Bot ที่ไม่ได้ใช้งาน และลบสแนปชอตรันไทม์แบบเต็มที่ซ้ำซ้อนออกจากการซิงโครไนซ์ UI
  • แก้ไขอาร์ติแฟกต์การทาสีตัวคั่นชื่อหน้าต่างเฉพาะของ Firefox เท่านั้น
  • ลดการโพลเทอร์มินัลที่ไม่ได้ใช้งานในห้องปฏิบัติการ Monty Hall โดยไม่กระทบต่อการตอบสนองอินพุตหรือการถอยหลัง

0.4.9 — ความเท่าเทียมกันของรันไทม์และแบ็คสเต็ปที่เชื่อถือได้

  • เก็บ backsteps ล่าสุด 100 รายการไว้ในขณะที่จำกัดหน่วยความจำเจอร์นัลแบบกระจัดกระจาย
  • แก้ไขคีย์บอร์ด/จอแสดงผลแบบซิงโครนัส TTY และลักษณะการทำงานของเหตุการณ์เครื่องมือในการเรียกใช้เบราว์เซอร์ที่ยาวนาน
  • อัปเดตห้องปฏิบัติการ Monty Hall และตัวอย่างเชิงโต้ตอบเพื่อให้ความร่วมมือกับการป้อนข้อมูลของเบราว์เซอร์โดยไม่ต้องสำรวจให้วุ่นวาย
  • จับคู่ syscalls แบบสุ่ม 40–44 กับลำดับที่เพาะและกฎการสุ่มตัวอย่างของ java.util.Random ใช้โดย MARS
  • การนำเข้าสถานะรันไทม์ที่แข็งแกร่งยิ่งขึ้น ตัวนับคำสั่งแบบยาว ช่วงแอสเซมเบลอร์ และการตรวจสอบความถูกต้องของคำสั่งเชิงตัวเลข
  • การครอบคลุม backstep ที่สมบูรณ์สำหรับข้อมูลเมตาของรูปภาพและบัฟเฟอร์ InputDialogString ที่มีความยาวเป็นศูนย์ที่แก้ไขแล้ว
  • ขยายความครอบคลุมการถดถอยตลอดรันไทม์ ตัวอย่างที่แปลเป็นภาษาท้องถิ่น และเครื่องมือที่เชื่อมต่อ

0.4.8 — เดลต้าแบ็คสเต็ปและอุปกรณ์ซิงโครนัส

  • แทนที่สแน็ปช็อต backstep ตามคำสั่งแบบเต็มด้วยเดลต้าผกผันที่มีขอบเขต
  • อุปกรณ์ซิงโครนัส MMIO แยกกัน ชุดงานรันไทม์-เหตุการณ์ขนาดกะทัดรัด และสแน็ปช็อตเครื่องมือเป็นระยะ
  • แก้ไขคีย์บอร์ด/จอแสดงผล และ TTY สาเหตุอินพุต/เอาท์พุต การถอยกลับ และโอเวอร์เฮดของเครื่องมือที่ซ่อนอยู่
  • แก้ไขการแสดงผลเป็นชุดในเครื่องมือแคช คำสั่ง การอ้างอิงหน่วยความจำ และบิตแมป
  • ย้าย Mini-C ตัวอย่าง framebuffers ออกจากคอมไพเลอร์โกลบอลและซิงโครไนซ์ Bitmap Display กับหน่วยความจำสด
  • ทำให้แถบวัดประสิทธิภาพท้องถิ่นเป็นตัวเลือกในการตั้งค่าอินเทอร์เฟซและซ่อนไว้ตามค่าเริ่มต้น

0.4.7 — JavaScript การทำให้รันไทม์แข็งแกร่งขึ้นและเอกสารประกอบที่สมบูรณ์

  • สร้างมาตรฐานรันไทม์บนกลไก JavaScript ล้วนๆ และลบ WASM/แบ็กเอนด์ไฮบริดรุ่นทดลองออก
  • เพิ่มการคอมไพล์ แอสเซมบลี และรันไทม์มิ่งบวกการใช้งาน JavaScript โดยประมาณไปยังแถบการวัดประสิทธิภาพในแอป
  • เก็บสแนปชอตรันไทม์แบบเต็มไว้ในอุปกรณ์ที่เชื่อมต่อในขณะที่ลดการทำงานของตัวแก้ไขที่ความเร็วสูงสุด
  • แก้ไขการเรียงลำดับคำสองเท่า COP1 การปัดเศษการแปลงตาม FCSR และการตรวจสอบอินพุตตัวเลขเสร็จสมบูรณ์
  • ขีดจำกัดฮีปที่แข็งขึ้น การจัดเก็บอะตอมมิก การจัดแนวคำสั่ง โหลดบางส่วนที่เข้มงวด และการจอง LL/SC
  • แก้ไขที่อยู่ลิงก์สาขาล่าช้า สถานะข้อยกเว้นสล็อตล่าช้า และความเท่าเทียมกันระหว่างไดเร็กเอ็นจิ้น Go และการดำเนินการที่ขับเคลื่อนด้วยเบราว์เซอร์
  • Made Stop จะหยุดการทำงานของเครื่องยนต์และยกเลิกโหมดสลีปที่ค้างอยู่ ในขณะที่การหยุดชั่วคราวยังคงสามารถกลับมาทำงานต่อได้
  • ขยายสแนปชอตรันไทม์เพื่อรักษาเบรกพอยต์ สตรีมแบบสุ่ม ไฟล์/เคอร์เซอร์เสมือน stdin อาร์กิวเมนต์ของโปรแกรม และตัวจัดการรูปภาพ
  • ขยายและหาเหตุผลเข้าข้างตนเองในแค็ตตาล็อกตัวอย่างภาษาอังกฤษ สเปน และโปรตุเกส รวมถึง C1-NATIVE และโปรเจ็กต์ C แบบหลายไฟล์
  • อัปเดตความช่วยเหลือในแอปภาษาอังกฤษ สเปน และโปรตุเกสทั้งหมดเพื่อให้ตรงกับแอปพลิเคชันเบราว์เซอร์ปัจจุบัน รันไทม์ คอมไพเลอร์ Mini-C เครื่องมือ พื้นที่เก็บข้อมูล และพฤติกรรมความเป็นส่วนตัว
  • เพิ่มการตรวจสอบความพร้อมในการเผยแพร่สำหรับความสอดคล้องของเวอร์ชัน รายการ ไฟล์ชั่วคราว และสัญญา UI ที่แปลเป็นภาษาท้องถิ่น

0.4.6 — พื้นที่ทำงานของเบราว์เซอร์ที่ทำซ้ำได้

  • สร้างคำสั่งการติดตั้ง การให้บริการ การสร้าง การทดสอบ และการตรวจสอบความถูกต้องที่สามารถทำซ้ำได้
  • เพิ่มการครอบคลุมการถดถอยในวงกว้างสำหรับพฤติกรรมแอสเซมเบลอร์/รันไทม์ การรวมเบราว์เซอร์ เครื่องมือ และตัวอย่าง
  • เปิดตัวหน่วยความจำรันไทม์ที่กำหนดค่าได้และขีดจำกัดแบ็คสเต็ปพร้อมสถานะคงอยู่ที่แข็งแกร่งยิ่งขึ้น
  • ขยายโปรไฟล์ Mini-C พฤติกรรม o32 ไลบรารี ตัวอย่าง และความครอบคลุมอินเทอร์เฟซหลายภาษา

เหตุการณ์สำคัญก่อนหน้านี้ webMARS

  • ย้ายเครื่องมือแก้ไขสไตล์ แอสเซมเบลอร์ และรันไทม์เวิร์กโฟลว์ MARS ไปยังเบราว์เซอร์แล้ว
  • เพิ่มโปรเจ็กต์ในเครื่อง การกู้คืนเซสชัน การซิงโครไนซ์ระบบคลาวด์เสริม และไฟล์เสมือนของเบราว์เซอร์
  • ย้ายและดัดแปลงเครื่องมือการศึกษาหลักและอุปกรณ์ MMIO
  • เพิ่ม Mini-C การสอนคอมไพเลอร์และโปรไฟล์เซ็ตย่อยที่สมบูรณ์ยิ่งขึ้นเรื่อยๆ
