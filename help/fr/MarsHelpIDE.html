Espace de travail & fichiers

Un projet est l'unité que webMARS enregistre, compile et assemble. Il peut contenir un ou plusieurs .asm/.s fichiers d'assemblage et Mini-C .c fichiers.

Editeur et navigation dans le projet

  • Utilisez les onglets source pour changer de fichier actif. La fermeture d'un fichier ne ferme pas l'intégralité du projet.
  • Les erreurs d'assemblage et les diagnostics Mini-C identifient le fichier source et la ligne chaque fois qu'ils sont disponibles.
  • La mise en évidence des étiquettes, la coloration syntaxique, la taille de la police et l'espacement des lignes sont contrôlées dans Paramètres → Interface.
  • L'assembly Mini-C généré peut s'ouvrir automatiquement dans sa propre fenêtre lorsque cette préférence est activée.

Construire un modèle

Assembler construit les sources d'assembly sélectionnées dans une image de programme. Compiler C0 traduit le projet C en assembly MIPS ; l'assemblage généré est ensuite assemblé avant exécution. Les projets C multi-fichiers sont liés comme une seule unité de traduction par le compilateur pédagogique.

Projets de restauration locale et cloud

webMARS conserve les données de récupération dans le stockage du navigateur afin qu'un rechargement puisse restaurer la session de travail. Les cinq emplacements de projet local explicites sont distincts de cette session de récupération.

Le Nuage le menu est facultatif. La connexion, l'ouverture/l'enregistrement du projet, la synchronisation et l'actualisation communiquent avec le serveur cloud configuré. L'utilisation du cloud n'est jamais requise pour l'édition, la compilation ou l'exécution locale.

Le stockage du navigateur n'est pas une sauvegarde permanente. La navigation privée, la pression des quotas, le nettoyage du navigateur ou la commande Clear localStorage peuvent le supprimer. Téléchargez le travail qui doit être conservé.
