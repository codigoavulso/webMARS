Assistance

Signalez les webMARS défauts et lacunes dans la documentation dans le référentiel du projet, ou contactez directement le responsable.

Un rapport de bug utile comprend

  • Le plus petit assemblage ou projet C qui reproduit le problème.
  • La séquence exacte de compilation/assemblage/exécution et le résultat que vous attendiez.
  • Le texte complet des messages et des E/S d'exécution ; Fichier → Vider les E/S d'exécution peut exporter la transcription.
  • Paramètres pertinents : profil du compilateur, carte mémoire, branchement retardé, pseudo-instructions et code auto-modifiable.
  • Nom/version du navigateur et si le problème se produit également après un rechargement dans un projet local propre.

Avant de soumettre

  1. Essayez l’exemple groupé le plus proche et comparez ses paramètres.
  2. Réassemblez après avoir modifié les préférences d'exécution ou de mémoire.
  3. N'incluez pas de mots de passe, de données de session cloud ou de sources privées qui ne peuvent pas être partagées.
