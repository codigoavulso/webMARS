Commencer

webMARS est basé sur un navigateur MIPS32 assembleur, simulateur, débogueur, Mini-C compilateur et espace de travail d’enseignement. Le runtime est entièrement implémenté dans JavaScript; aucune installation Java, exécutable natif ou WASM le back-end est requis.

  1. Ouvrez ou créez un fichier source. Utiliser Fichier → Exemples pour un point de départ guidé, Nouveau projet pour un projet vierge, ou Ouvrir à partir du disque pour les fichiers locaux.
  2. Construisez-le. Utilisation des fichiers d'assemblage Exécuter → Assembler (F3). Utilisation des fichiers C Exécuter → Compiler C0 (F4), puis assemblez l'assembly généré.
  3. Exécutez-le. Sélectionnez Allez (F5) ou avancez une instruction à la fois avec Étape (F7).
  4. Inspectez le résultat. Les registres, le coprocesseur 1, la mémoire, les messages, les E/S d'exécution et les outils connectés sont mis à jour au fur et à mesure de l'exécution du programme.

Ce qui est inclus

Exécution MIPS32

Exécution d’entier, de branchement, de mémoire, d’exception, LL/SC et COP1, y compris les options de branchement retardé et de code auto-modifiable.

Compilateur Mini-C

Sous-ensembles d'enseignement C0 et profil C1-NATIVE, ciblant la convention d'appel MIPS o32.

Débogueur

Points d'arrêt, pas à pas, recul, réinitialisation, contrôles de pause/arrêt et vitesse d'exécution configurable.

Appareils et outils

Appareils MMIO, simulateurs de cache et de branche, affichages visuels, statistiques, terminal ANSI et bien plus encore.

Première exécution recommandée

Ouvert Fichier → Exemples, choisissez un anglais Apprendre Par exemple, lisez sa description et ouvrez-le. Des exemples d'assemblage peuvent être assemblés et exécutés directement. Les exemples C déclarent leur sous-ensemble minimum de compilateur et peuvent contenir plusieurs fichiers de projet.

Vos fichiers restent dans votre navigateur par défaut. Les projets locaux et les données de récupération ne sont pas téléchargés sauf si vous utilisez explicitement le menu Cloud. Téléchargez périodiquement des travaux importants car le stockage du navigateur peut être effacé par le navigateur ou par Paramètres → Effacer le stockage local.
