Erste Schritte

webMARS ist ein browserbasierter MIPS32 Assembler, Simulator, Debugger, Mini-C Compiler und Lehrarbeitsbereich. Die Laufzeit ist vollständig in JavaScript implementiert. Es ist keine Java-Installation, keine native ausführbare Datei oder kein WASM-Backend erforderlich.

  1. Öffnen oder erstellen Sie eine Quelldatei. Benutzen Datei → Beispiele für einen geführten Ausgangspunkt, Neues Projekt für ein leeres Projekt, oder Von der Festplatte öffnen für lokale Dateien.
  2. Baue es. Verwendung von Montagedateien Ausführen → Zusammenbauen (F3). C-Dateien verwenden Ausführen → C0 kompilieren (F4), und stellen Sie dann die generierte Baugruppe zusammen.
  3. Führen Sie es aus. Auswählen Geh (F5) oder eine Anweisung nach der anderen vorrücken Schritt (F7).
  4. Überprüfen Sie das Ergebnis. Register, Coprozessor 1, Speicher, Nachrichten, Lauf-E/A und verbundene Tools werden aktualisiert, während das Programm ausgeführt wird.

Was ist enthalten

MIPS32 Laufzeit

Ganzzahl-, Verzweigungs-, Speicher-, Ausnahme-, LL/SC- und COP1-Ausführung, einschließlich verzögerter Verzweigung und selbstmodifizierender Codeoptionen.

Mini-C-Compiler

C0-Lehrteilmengen und das C1-NATIVE-Profil, das auf die MIPS o32-Aufrufkonvention abzielt.

Debugger

Haltepunkte, Stepping, Backstepping, Reset, Pause/Stopp-Steuerung und konfigurierbare Ausführungsgeschwindigkeit.

Geräte und Werkzeuge

MMIO-Geräte, Cache- und Branch-Simulatoren, visuelle Anzeigen, Statistiken, ANSI-Terminal und mehr.

Empfohlener erster Lauf

Offen Datei → Beispiele, wählen Sie ein Englisch Lernen Lesen Sie beispielsweise die Beschreibung und öffnen Sie es. Montagebeispiele können direkt zusammengestellt und ausgeführt werden. C-Beispiele deklarieren ihre minimale Compiler-Teilmenge und können mehrere Projektdateien enthalten.

Ihre Dateien bleiben standardmäßig in Ihrem Browser. Lokale Projekte und Wiederherstellungsdaten werden nicht hochgeladen, es sei denn, Sie verwenden explizit das Cloud-Menü. Laden Sie wichtige Arbeiten regelmäßig herunter, da der Browserspeicher vom Browser oder von gelöscht werden kann Einstellungen → LocalStorage löschen.
