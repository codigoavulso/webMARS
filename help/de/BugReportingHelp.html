Unterstützung

Melden Sie webMARS Fehler und Dokumentationslücken im Projekt-Repository oder wenden Sie sich direkt an den Betreuer.

Ein nützlicher Fehlerbericht enthält

  • Die kleinste Assembly oder das kleinste C-Projekt, das das Problem reproduziert.
  • Die genaue Kompilierungs-/Assembly-/Ausführungssequenz und das erwartete Ergebnis.
  • Der vollständige Nachrichten- und Ausführungs-E/A-Text; Datei → Dump Run I/O kann das Transkript exportieren.
  • Relevante Einstellungen: Compilerprofil, Speicherzuordnung, verzögerte Verzweigung, Pseudoanweisungen und selbstmodifizierender Code.
  • Browsername/-version und ob das Problem auch nach einem Neuladen in einem sauberen lokalen Projekt auftritt.

Vor dem Absenden

  1. Probieren Sie das nächstgelegene gebündelte Beispiel aus und vergleichen Sie seine Einstellungen.
  2. Nach Änderung der Laufzeit- oder Speichereinstellungen erneut zusammensetzen.
  3. Geben Sie keine Passwörter, Cloud-Sitzungsdaten oder private Quellen an, die nicht geteilt werden können.
