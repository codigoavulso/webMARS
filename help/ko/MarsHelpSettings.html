설정

설정에는 소스 프레젠테이션, 어셈블러 호환성, Mini-C 출력, 지속성, 클라우드 액세스 및 런타임 제한이 포함됩니다.

빠른 설정

설정효과
라벨 표시가능한 경우 런타임 보기에서 주소와 함께 레이블을 표시합니다.
프로그램 인수실행 전에 인수에 대한 프롬프트를 표시합니다. $a0 argc를 수신하고 $a1 argv를 수신합니다. Mini-C C1-NATIVE는 동일한 데이터를 다음에 노출합니다. main(int argc, char **argv).
팝업 입력 syscallRun I/O 창 대신 콘솔 입력 서비스 5, 6, 7, 8 및 12에 대한 양식 대화 상자를 사용합니다.
메시지 분할/I/O 실행빌드 메시지와 프로그램 I/O를 동시에 표시합니다.
16진수 주소/값16진수 표시와 10진수 표시 간에 런타임 테이블을 전환합니다. 저장된 비트는 변경되지 않습니다.

어셈블러 및 실행 호환성

  • 오픈 시 조립 그리고 모든 파일을 어셈블 선택한 빌드 범위를 자동화합니다.
  • 경고를 오류로 처리 경고가 조립에 실패하게 만듭니다.
  • 메인에서 시작 글로벌에서 시작된다 main 있을 때 라벨을 붙입니다.
  • 확장(의사) 명령어 도움말에 표시된 의사 명령어 카탈로그를 활성화합니다.
  • 지연된 분기 아키텍처 지연 슬롯 동작을 활성화합니다.
  • 자체 수정 코드 실행 가능한 메모리에 대한 쓰기를 허용합니다. 의도적으로 요구하는 프로그램에 대해서만 활성화하십시오.

인터페이스

인터페이스 테마(밝게 또는 어둡게), UI 언어, 상단 또는 측면 메뉴 레이아웃, 편집기 글꼴 크기, 줄 간격 및 강조 표시 동작을 선택합니다. 영어, 스페인어, 포르투갈어, 중국어(북경어), 힌디어, 아랍어, 프랑스어, 벵골어, 러시아어, 인도네시아어, 독일어, 일본어, 한국어, 터키어, 베트남어, 우르두어, 이탈리아어, 폴란드어, 페르시아어 및 태국어 인터페이스를 사용할 수 있습니다. help는 활성 UI 언어를 따릅니다. 아랍어, 우르두어, 페르시아어는 인터페이스를 자동으로 오른쪽에서 왼쪽으로 전환합니다. 처음 방문할 때 webMARS는 지원되는 브라우저 언어를 사용하거나 영어로 대체됩니다. 명시적인 선택이 저장되고 우선순위를 갖습니다. 선택한 테마는 기본 설정과 함께 저장되며 도구 및 도움말 창을 포함한 전체 인터페이스에 적용됩니다.

런타임 & 메모리

선호도범위 / 선택
메모리 구성기본값은 주소 0의 압축 데이터 또는 주소 0의 압축 텍스트입니다.
최대 메모리0.25–2 GiB(브라우저의 실제 메모리 제한에 따라 다름)
백스텝 기록0~1,000,000개의 기록된 단계; 기본값은 100입니다.
예외 처리기완전히 유효한 MIPS 주소, 기본값 0x80000180.

지속성과 클라우드

매장 상태 그리고 로드 상태 전체 로컬 런타임 스냅샷을 관리합니다. 로컬 저장소 지우기 확인 후 webMARS 기본 설정, 저장된 프로젝트, 복구 상태 및 도구 위치를 제거합니다.

클라우드 서버 선택적 클라우드 메뉴에서 사용되는 엔드포인트를 변경합니다. 자격 증명 및 프로젝트 데이터는 클라우드 기능을 호출할 때만 전송됩니다.

메모리 맵이나 어셈블러 호환성 옵션을 변경하면 이미 어셈블된 프로그램의 가정이 무효화됩니다. 교체 후 재조립하세요.
