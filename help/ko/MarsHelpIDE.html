작업공간 & 파일

프로젝트는 webMARS 저장하고, 컴파일하고, 조합하는 단위입니다. 하나 이상을 포함할 수 있습니다. .asm/.s 어셈블리 파일 및 Mini-C .c 파일.

파일 메뉴

명령현재 행동
새 프로젝트빈 프로젝트를 만듭니다. 프로젝트가 열리면 New 하위 메뉴에서 C 또는 어셈블리 소스 파일을 추가합니다.
디스크에서 열기브라우저를 통해 선택한 파일을 가져옵니다. 다중 파일 선택이 지원됩니다.
브라우저 저장소에서 열기로컬 프로젝트 슬롯 중 하나에 저장된 프로젝트를 복원합니다.
활성 파일 저장/프로젝트 저장활성 소스 또는 전체 프로젝트를 브라우저 저장소에 저장합니다.
다운로드 / 다른 이름으로 다운로드브라우저 다운로드 시스템을 통해 활성 콘텐츠를 내보냅니다.
예언어 및 학습 목표별로 그룹화되어 선별되고 검색 가능한 예제 카탈로그를 엽니다.
덤프 실행 I/O진단 또는 평가를 위해 현재 프로그램 입력/출력 기록을 다운로드합니다.

편집기 및 프로젝트 탐색

  • 소스 탭을 사용하여 활성 파일을 전환하세요. 파일을 닫아도 전체 프로젝트가 닫히지는 않습니다.
  • 어셈블리 오류 및 Mini-C 진단은 가능할 때마다 소스 파일과 라인을 식별합니다.
  • 라벨 강조, 구문 강조, 글꼴 크기 및 줄 간격은 다음에서 제어됩니다. 설정 → 인터페이스.
  • 해당 기본 설정이 활성화되면 생성된 Mini-C 어셈블리가 자체 창에서 자동으로 열릴 수 있습니다.

모델 구축

조립하다 선택한 어셈블리 소스를 프로그램 이미지로 빌드합니다. C0 컴파일 C 프로젝트를 MIPS 어셈블리로 변환합니다. 생성된 어셈블리는 실행 전에 어셈블됩니다. 다중 파일 C 프로젝트는 교육용 컴파일러에 의해 하나의 번역 단위로 연결됩니다.

로컬 복구 및 클라우드 프로젝트

webMARS는 다시 로드하면 작업 세션을 복원할 수 있도록 브라우저 저장소에 복구 데이터를 유지합니다. 5개의 명시적 로컬 프로젝트 슬롯은 해당 복구 세션과 별개입니다.

는 클라우드 메뉴는 선택사항입니다. 로그인, 프로젝트 열기/저장, 동기화, 새로고침은 구성된 클라우드 서버와 통신합니다. 로컬 편집, 컴파일 또는 실행에는 클라우드 사용이 필요하지 않습니다.

브라우저 저장소는 영구 백업이 아닙니다. 개인 정보 보호 브라우징, 할당량 압박, 브라우저 정리 또는 Clear localStorage 명령을 통해 이를 제거할 수 있습니다. 보관해야 하는 작품을 다운로드하세요.
