& 호환성 제한

webMARS 최신 브라우저에서 완전히 실행되면서 실용적인 MARS 4.5 소스 호환성을 목표로 합니다. 브라우저 보안, 저장 및 오디오 규칙은 계속 적용됩니다.

런타임 제한

면적한도 또는 행동
메모리사용자 선택 가능 0.25–2 GiB, 아래에 건축학적으로 단단한 천장 포함 0x80000000. 희소 할당은 영향을 받지 않은 주소 공간이 바이트 단위로 커밋되지 않음을 의미합니다.
힙sbrk 힙 포인터를 변경하기 전에 서명되지 않은 전체 예약의 유효성을 검사합니다. 요청은 구성된 메모리 한도를 래핑하거나 우회할 수 없습니다.
런타임 문자열Null 종료 문자열은 최대 1MiB를 포함할 수 있습니다. 종결자가 없거나 더 긴 문자열은 잘린 텍스트를 반환하는 대신 명시적인 syscall 오류를 발생시킵니다.
백스텝0~1,000,000 역델타. 백스텝이 활성화된 경우 항상 최근 100개의 전체 단계를 유지하면서 기록은 구성된 예산에 따라 제한됩니다.
브라우저 파일 저장프로젝트/세션 데이터에는 브라우저 할당량이 적용됩니다. 앱은 해당되는 경우 사용자 브라우저 스토리지 페이로드를 1MiB로 제한하고 필요한 경우 더 작은 복구 페이로드로 대체합니다.
실행 타이밍절전, MIDI 및 UI 타이밍은 브라우저에 의해 예약되며 주기가 정확하지 않습니다.
유통webMARS 0.5.5는 설치 가능/오프라인 PWA이 아닌 정적 웹 애플리케이션입니다. 포함된 로컬 서버나 다른 정적 호스트에 의해 HTTP를 통해 제공되어야 합니다.

압축 데이터 및 압축 텍스트 사전 설정은 해당 교육 세그먼트를 주소 0으로 이동합니다. 맵을 변경한 후 다시 조립하세요.

MIPS 행동

  • 메모리는 리틀 엔디안입니다. 워드 및 더블워드 연산은 MIPS 레지스터/메모리 순서를 사용합니다.
  • 잘못 정렬된 명령어 가져오기 및 잘못된 로드/저장 주소로 인해 주소 예외가 발생합니다.
  • 저장소는 쓰기 전에 전체 대상의 유효성을 검사하므로 실패한 저장소는 부분 값을 남기지 않습니다.
  • LL/SC 충돌하는 상점이 무효화되는 예약을 사용하십시오.
  • COP1 변환은 FCSR 반올림 모드를 따릅니다. 부동 소수점 입력은 숫자가 아닌 후행 텍스트를 거부합니다.
  • 엄격한 MARS 호환성을 통해 부분 단어 로드를 포함한 메모리 작업은 허용된 세그먼트 내에 유지되어야 합니다.

알려진 이식성 경계

  • 브라우저 가상 파일 시스템은 호스트 운영 체제의 무제한 파일 시스템이 아닙니다.
  • 웹 오디오 권한 및 자동 재생 정책은 MIDI syscall에 영향을 미칠 수 있습니다.
  • 팝업 차단기 및 다운로드 정책은 내보낸 파일에 영향을 미칠 수 있습니다.
  • Mini-C는 문서화된 프로필만 허용합니다. 전체 ISO C에 의존하는 코드, 호스트 libc 또는 정의되지 않은 동작은 이식 ​​가능하지 않습니다.
  • Java 클래스 또는 데스크탑 플러그인에 의존하는 기존 MARS 확장은 사용할 수 없습니다.
