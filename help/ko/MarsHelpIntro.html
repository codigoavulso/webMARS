시작하기

webMARS는 브라우저 기반의 MIPS32 어셈블러, 시뮬레이터, 디버거, Mini-C 컴파일러 및 교육 작업 공간입니다. 런타임은 JavaScript에서 완전히 구현됩니다. Java 설치, 기본 실행 파일 또는 WASM 백엔드가 필요하지 않습니다.

  1. 소스 파일을 열거나 생성합니다. 사용 파일 → 예 안내된 출발점을 위해, 새 프로젝트 빈 프로젝트의 경우 또는 디스크에서 열기 로컬 파일의 경우.
  2. 그것을 구축하십시오. 어셈블리 파일 사용 실행 → 조립 (F3). C 파일 사용 실행 → C0 컴파일 (F4), 생성된 어셈블리를 어셈블합니다.
  3. 실행하세요. 선택 이동 (F5) 또는 다음을 사용하여 한 번에 하나의 지침을 진행합니다. 단계 (F7).
  4. 결과를 검사합니다. 레지스터, 보조 프로세서 1, 메모리, 메시지, 실행 I/O 및 연결된 도구는 프로그램이 실행됨에 따라 업데이트됩니다.

무엇이 포함되어 있나요?

MIPS32 런타임

지연된 분기 및 자체 수정 코드 옵션을 포함한 정수, 분기, 메모리, 예외, LL/SC 및 COP1 실행.

Mini-C 컴파일러

C0 교육 하위 집합 및 C1-NATIVE 프로필은 MIPS o32 호출 규칙을 대상으로 합니다.

디버거

중단점, 스테핑, 백스테핑, 재설정, 일시 중지/중지 제어 및 구성 가능한 실행 속도.

장치 및 도구

MMIO 장치, 캐시 및 분기 시뮬레이터, 시각적 디스플레이, 통계, ANSI 터미널 등.

권장 첫 실행

열기 파일 → 예, 영어를 선택하세요 배우다 예를 들어 설명을 읽고 엽니다. 조립 예제를 직접 조립하고 실행할 수 있습니다. C 예제는 최소 컴파일러 하위 집합을 선언하며 여러 프로젝트 파일을 포함할 수 있습니다.

파일은 기본적으로 브라우저에 유지됩니다. 클라우드 메뉴를 명시적으로 사용하지 않으면 로컬 프로젝트 및 복구 데이터가 업로드되지 않습니다. 브라우저 저장 공간은 브라우저나 다른 장치에 의해 삭제될 수 있으므로 중요한 작업을 주기적으로 다운로드하세요. 설정 → localStorage 지우기.
