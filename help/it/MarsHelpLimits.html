Limita la compatibilità &.

webMARS mira alla compatibilità pratica del codice sorgente MARS 4.5 mentre viene eseguito interamente in un browser moderno. Si applicano ancora le regole relative alla sicurezza del browser, all'archiviazione e all'audio.

Limiti di tempo di esecuzione

ZonaLimite o comportamento
MemoriaSelezionabile dall'utente 0,25–2 GiB, con soffitto rigido architettonico sottostante 0x80000000. L'allocazione sparsa significa che lo spazio degli indirizzi intatto non viene impegnato byte per byte.
Mucchiosbrk convalida l'intera prenotazione non firmata prima di modificare il puntatore dell'heap. Le richieste non possono racchiudere o ignorare il limite massimo di memoria configurato.
Stringhe di esecuzioneLe stringhe con terminazione null possono contenere fino a 1 MiB. Un terminatore mancante o una stringa più lunga generano un errore esplicito di chiamata di sistema invece di restituire testo troncato.
Passo indietro0–1.000.000 delta inversi. La cronologia è limitata dal budget configurato e conserva sempre gli ultimi 100 passaggi completi quando è abilitato il passaggio indietro.
Archiviazione dei file nel browserI dati del progetto/sessione sono soggetti alla quota del browser; l'app limita i payload di archiviazione del browser dell'utente a 1 MiB ove applicabile e, se necessario, ricorre a payload di ripristino più piccoli.
Esegui il cronometraggioLa sospensione, MIDI e i tempi dell'interfaccia utente sono pianificati dal browser e non sono accurati in base al ciclo.
DistribuzionewebMARS 0.5.5 è un'applicazione Web statica, non un PWA installabile/offline. Deve essere servito su HTTP dal server locale incluso o da un altro host statico.

Le preimpostazioni Compact Data e Compact Text spostano i segmenti di apprendimento corrispondenti all'indirizzo zero. Rimontare dopo aver cambiato le mappe.

Comportamento MIPS.

  • La memoria è little-endian. Le operazioni a parola e doppia parola utilizzano l'ordinamento del registro/memoria MIPS.
  • I recuperi di istruzioni disallineati e gli indirizzi di caricamento/memorizzazione non validi generano eccezioni di indirizzo.
  • Gli archivi convalidano la destinazione completa prima della scrittura, quindi un archivio in errore non lascia dietro di sé un valore parziale.
  • LL/SC utilizzare una prenotazione che i negozi in conflitto invalidano.
  • Le conversioni COP1 rispettano le modalità di arrotondamento FCSR; l'input a virgola mobile rifiuta il testo finale non numerico.
  • Con la rigida compatibilità MARS, le operazioni di memoria, inclusi i carichi di parole parziali, devono rimanere all'interno dei segmenti consentiti.

Limiti di portabilità noti

  • Il file system virtuale del browser non è il file system illimitato del sistema operativo host.
  • L'autorizzazione audio Web e i criteri di riproduzione automatica possono influire sulle chiamate di sistema MIDI.
  • I blocchi popup e i criteri di download possono influire sui file esportati.
  • Mini-C accetta solo i suoi profili documentati; il codice che si basa sul ISO C completo, una libc host o un comportamento non definito non è portabile su di esso.
  • Le estensioni storiche MARS che dipendono dalle classi Java o dai plug-in desktop non sono disponibili.
