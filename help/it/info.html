webMARS __WEBMARS_APP_VERSION__

Un ambiente di apprendimento MIPS32 nativo del browser con un assemblatore, un simulatore JavaScript, un debugger, un compilatore Mini-C, esempi e dispositivi interattivi.

Nessuna installazione

Esegui l'app in un browser moderno. Java e WebAssembly non sono richiesti.

Prima il locale

Modifica, compila, esegui, salva nella memoria del browser e scarica senza effettuare l'accesso.

Incentrato sull'insegnamento

Utilizzare MARS-stile MIPS sintassi, chiamate di sistema, mappe di memoria, strumenti e struttura Mini-C profili.

Capacità attuali

  • MIPS32 numero intero, memoria, ramo, eccezione, LL/SC ed esecuzione COP1.
  • Riferimenti di base e pseudo-istruzioni, macro e compatibilità con l'assemblatore configurabile.
  • Punti di interruzione, passaggi, passaggi indietro, pause, arresti, reimpostazioni e istantanee dello stato di runtime.
  • Compilazione da C0-S0 a C0-S4 e C1-NATIVE Mini-C con targeting o32.
  • Diciotto strumenti runtime, esempi curati in venti lingue e progetti cloud opzionali.
  • Benchmark locali di compilazione, assemblaggio ed esecuzione con utilizzo stimato di JavaScript.

Privacy

webMARS non ha pubblicità. I file di origine, le preferenze, i file virtuali, i dati di ripristino, i benchmark e lo stato di runtime rimangono sul dispositivo per impostazione predefinita. I campioni di benchmark sono volatili e non vengono trasmessi.

Le funzionalità cloud sono facoltative. Quando accedi o effettui la sincronizzazione, i dati dell'account/sessione e del progetto vengono inviati al server cloud configurato in Impostazioni. Rivedi i termini dell'operatore prima di utilizzare un server di terze parti o personalizzato. I download e i file aperti dal disco utilizzano i normali controlli dei file del browser.
