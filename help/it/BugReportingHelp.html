Supporto

Segnala webMARS difetti e lacune nella documentazione nel repository del progetto o contatta direttamente il manutentore.

Include un'utile segnalazione di bug

  • Il più piccolo assembly o progetto C che riproduce il problema.
  • L'esatta sequenza di compilazione/assemblaggio/esecuzione e il risultato previsto.
  • I messaggi completi e il testo I/O di esecuzione; File → Dump Esegui I/O può esportare la trascrizione.
  • Impostazioni rilevanti: profilo del compilatore, mappa di memoria, ramificazione ritardata, pseudo-istruzioni e codice automodificante.
  • Nome/versione del browser e se il problema si verifica anche dopo un ricaricamento in un progetto locale pulito.

Prima di inviare

  1. Prova l'esempio in bundle più vicino e confronta le sue impostazioni.
  2. Riassemblare dopo aver modificato le preferenze di runtime o di memoria.
  3. Non includere password, dati di sessioni cloud o fonti private che non possono essere condivise.
