File dell'area di lavoro &.

Un progetto è l'unità che webMARS salva, compila e assembla. Può contenerne uno o più .asm/.s file di assieme e Mini-C .c file.

Editor e navigazione del progetto

  • Utilizza le schede di origine per cambiare il file attivo. La chiusura di un file non chiude l'intero progetto.
  • Gli errori di assemblaggio e la diagnostica Mini-C identificano il file e la riga di origine quando disponibili.
  • Vengono controllate l'evidenziazione dell'etichetta, l'evidenziazione della sintassi, la dimensione del carattere e l'interlinea Impostazioni → Interfaccia.
  • L'assembly Mini-C generato può aprirsi automaticamente nella propria finestra quando tale preferenza è abilitata.

Costruisci modello

Assemblare costruisce le origini dell'assembly selezionato in un'immagine del programma. Compila C0 traduce il progetto C nell'assembly MIPS; l'assembly generato viene quindi assemblato prima dell'esecuzione. I progetti C multifile sono collegati come un'unica unità di traduzione dal compilatore didattico.

Progetti di ripristino locale e cloud

webMARS mantiene i dati di ripristino nella memoria del browser in modo che un ricaricamento possa ripristinare la sessione di lavoro. I cinque slot di progetto locale espliciti sono separati da quella sessione di ripristino.

Il Nuvola il menu è facoltativo. Login, apertura/salvataggio progetto, sincronizzazione e aggiornamento comunicano con il server cloud configurato. L'uso del cloud non è mai richiesto per la modifica, la compilazione o l'esecuzione locale.

L'archiviazione del browser non è un backup permanente. La navigazione privata, la pressione sulle quote, la pulizia del browser o il comando Cancella localStorage possono rimuoverlo. Scaricare il lavoro che deve essere conservato.
