Iniziare

webMARS è un assemblatore MIPS32 basato su browser, un simulatore, un debugger, un compilatore Mini-C e un'area di lavoro per l'insegnamento. Il runtime è implementato interamente in JavaScript; non è richiesta alcuna installazione Java, eseguibile nativo o backend WASM.

  1. Apri o crea un file sorgente. Utilizzare File → Esempi per un punto di partenza guidato, Nuovo progetto per un progetto vuoto, o Apri da disco per i file locali.
  2. Costruiscilo. Utilizzo dei file di assembly Esegui → Assembla (F3). I file C utilizzano Esegui → Compila C0 (F4), quindi assemblare l'assembly generato.
  3. Eseguilo. Seleziona Vai (F5) o avanzare di un'istruzione alla volta con Passo (F7).
  4. Ispeziona il risultato. Registri, coprocessore 1, memoria, messaggi, I/O di esecuzione e strumenti collegati si aggiornano durante l'esecuzione del programma.

Cosa è incluso

MIPS32 tempo di esecuzione

Esecuzione di numeri interi, rami, memoria, eccezioni, LL/SC e COP1, incluse opzioni di ramificazione ritardata e codice automodificante.

Mini-C compilatore

Sottoinsiemi di insegnamento C0 e il profilo C1-NATIVE, mirati alla convenzione di chiamata MIPS o32.

Debug

Punti di interruzione, stepping, backstepping, reset, controlli pausa/stop e velocità di esecuzione configurabile.

Dispositivi e strumenti

Dispositivi MMIO, simulatori di cache e di filiali, display visivi, statistiche, terminale ANSI e altro ancora.

Prima esecuzione consigliata

Aperto File → Esempi, scegli un inglese Impara esempio, leggi la sua descrizione e aprilo. Gli esempi di assemblaggio possono essere assemblati ed eseguiti direttamente. Gli esempi C dichiarano il loro sottoinsieme minimo del compilatore e possono contenere diversi file di progetto.

I tuoi file rimangono nel tuo browser per impostazione predefinita. I progetti locali e i dati di ripristino non vengono caricati a meno che non si utilizzi esplicitamente il menu Cloud. Scarica periodicamente lavori importanti perché la memoria del browser può essere cancellata dal browser o da Impostazioni → Cancella memoria locale.
