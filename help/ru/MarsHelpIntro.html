Начало работы

webMARS — это ассемблер MIPS32 на основе браузера, симулятор, отладчик, компилятор Mini-C и рабочая среда для обучения. Среда выполнения полностью реализована в JavaScript; установка Java, собственный исполняемый файл или WASM не требуются.

  1. Откройте или создайте исходный файл. Использование Файл → Примеры для ориентировочной отправной точки, Новый проект для пустого проекта или Открыть с диска для локальных файлов.
  2. Постройте это. Файлы сборки используют Выполнить → Собрать (F3). Файлы C используют Выполнить → Скомпилировать C0 (F4), затем соберите созданную сборку.
  3. Выполните это. Выбрать Иди (F5) или продвигайте одну инструкцию за раз с помощью Шаг (F7).
  4. Осмотрите результат. Регистры, сопроцессор 1, память, сообщения, ввод-вывод и подключенные инструменты обновляются по мере запуска программы.

Что включено

MIPS32 время выполнения

Целое число, ветвление, память, исключение, LL/SC и выполнение COP1, включая отложенное ветвление и варианты самомодифицирующегося кода.

Mini-C компилятор

Подмножества обучения C0 и профиль C1-NATIVE, ориентированный на соглашение о вызовах MIPS o32.

Отладчик

Точки останова, шаг, возврат, сброс, управление паузой/остановкой и настраиваемая скорость выполнения.

Устройства и инструменты

Устройства MMIO, симуляторы кэша и ветвей, визуальные дисплеи, статистика, терминал ANSI и многое другое.

Рекомендуется первый запуск

Открыть Файл → Примеры, выберите английский Узнать Например, прочитайте его описание и откройте его. Примеры сборки можно собрать и запустить напрямую. Примеры C объявляют минимальное подмножество компилятора и могут содержать несколько файлов проекта.

По умолчанию ваши файлы остаются в вашем браузере. Локальные проекты и данные восстановления не загружаются, если вы явно не используете облачное меню. Периодически загружайте важную работу, поскольку память браузера может быть очищена самим браузером или Настройки → Очистить локальное хранилище.
