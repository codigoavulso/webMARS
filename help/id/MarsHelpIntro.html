Memulai

webMARS adalah MIPS32 assembler, simulator, debugger, kompiler Mini-C dan ruang kerja pengajaran berbasis browser. Runtime diimplementasikan seluruhnya di JavaScript; tidak diperlukan instalasi Java, executable asli, atau backend WASM.

  1. Buka atau buat file sumber. Gunakan File → Contoh untuk titik awal yang dipandu, Proyek Baru untuk proyek kosong, atau Buka dari Disk untuk file lokal.
  2. Bangun itu. File perakitan digunakan Jalankan → Merakit (F3). penggunaan file C Jalankan → Kompilasi C0 (F4), lalu rakit rakitan yang dihasilkan.
  3. Jalankan itu. Pilih Pergi (F5) atau memajukan satu instruksi dalam satu waktu dengan Langkah (F7).
  4. Periksa hasilnya. Register, Koprosesor 1, memori, pesan, Jalankan I/O, dan alat yang terhubung diperbarui saat program berjalan.

Apa yang disertakan

MIPS32 waktu proses

Eksekusi integer, cabang, memori, pengecualian, LL/SC dan COP1, termasuk opsi kode percabangan tertunda dan modifikasi mandiri.

Kompiler Mini-C

Subset pengajaran C0 dan profil C1-NATIVE, menargetkan konvensi panggilan MIPS o32.

debug

Kontrol breakpoint, loncatan, mundur, reset, jeda/hentikan, dan kecepatan eksekusi yang dapat dikonfigurasi.

Perangkat dan alat

Perangkat MMIO, simulator cache dan cabang, tampilan visual, statistik, terminal ANSI dan banyak lagi.

Direkomendasikan untuk dijalankan pertama kali

Buka File → Contoh, pilih bahasa Inggris Belajar Misalnya, baca deskripsinya, lalu buka. Contoh perakitan dapat dirakit dan dijalankan secara langsung. Contoh C mendeklarasikan subset kompiler minimumnya dan mungkin berisi beberapa file proyek.

File Anda tetap berada di browser Anda secara default. Proyek lokal dan data pemulihan tidak diunggah kecuali Anda menggunakan menu Cloud secara eksplisit. Download pekerjaan penting secara berkala karena penyimpanan browser dapat dibersihkan oleh browser atau oleh Pengaturan → Hapus Penyimpanan lokal.
