Mini-C

Kompiler pengajaran bawaan menerjemahkan subset C yang sengaja ditentukan ke rakitan MIPS32 menggunakan konvensi pemanggilan o32. Ini bukan kompiler C ISO untuk tujuan umum.

Profil

ProfilTujuan
C0-S0 untuk C0-S4Subset pengajaran kumulatif, berkembang dari ekspresi dan aliran kontrol ke fungsi, array, pointer, struktur, typedefs, kontrak dan perpustakaan.
C1-NATIVEProfil default dan paling mumpuni: beralamat byte char/char *, string asli, argc/argv, penunjuk fungsi dan void *.

Jika suatu sumber memerlukan profil yang lebih tinggi, kompilasi akan mengeluarkan profil yang terfokus MC_SUBSET_MISMATCH diagnostik daripada serangkaian kesalahan sekunder.

Kompilasi sebuah proyek

  1. Pilih profil yang diinginkan dan opsi keluaran Pengaturan → preferensi Mini-C.
  2. Buka satu atau lebih .c file dalam proyek yang sama.
  3. Pilih Jalankan → Kompilasi C0 atau tekan F4.
  4. Tinjau diagnostik dan rakitan MIPS yang dihasilkan. Rakit dan jalankan program yang dihasilkan secara normal.

Konvensi panggilan dan titik masuk

  • Argumen yang digunakan $a0–$a3, argumen tambahan menggunakan tumpukan, dan mengembalikan nilai menggunakan $v0 (dan $v1 jika perlu).
  • Register dan frame tumpukan yang disimpan Callee mengikuti ekspektasi MIPS o32.
  • main(void) dan, di C1-NATIVE, main(int argc, char **argv) didukung.
  • Untuk argumen program webMARS, argv[0] adalah token pertama yang diberikan oleh pengguna; tidak ada entri nama otomatis yang dapat dieksekusi.

Header dan perpustakaan yang dibundel

Header ini adalah perpustakaan kompatibilitas webMARS yang dibangun di sekitar MIPS syscall dan perangkat. Mereka mengimplementasikan subset yang terdokumentasi, bukan pustaka standar host C lengkap.

#use <bitmap_rect> juga menyediakan bitmap_configure_display, bitmap_configure_terminal dan bitmap_configure_all, memungkinkan program C0 mengirimkan ukuran tampilan, ukuran unit, dan alamat framebuffer ke alat Bitmap.

Contoh awal yang bagus

  • Halo Dunia (C) untuk program lengkap terkecil.
  • Mini-C C1 Asli untuk string asli dan perilaku profil saat ini.
  • Demo Perpustakaan Argumen untuk argc/argv.
  • Statistik Multi-file untuk kompilasi seluruh proyek dan pemanggilan fungsi di seluruh file.
  • Dasar-dasar Konsol stdio dan stdio File Pulang Pergi untuk perpustakaan kompatibilitas.
Panduan kompiler dalam repositori tetap menjadi referensi bahasa yang normatif dan terperinci. Halaman dalam aplikasi merangkum perilaku yang diperlukan untuk memilih profil dan menjalankan contoh dengan benar.
