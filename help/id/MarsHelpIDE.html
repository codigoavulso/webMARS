File ruang kerja &

Sebuah proyek adalah unit yang webMARS simpan, kompilasi, dan rakit. Ini mungkin berisi satu atau lebih .asm/.s file perakitan dan Mini-C .c file.

Editor dan navigasi proyek

  • Gunakan tab sumber untuk mengganti file aktif. Menutup file tidak menutup keseluruhan proyek.
  • Kesalahan perakitan dan diagnostik Mini-C mengidentifikasi file sumber dan baris kapan pun tersedia.
  • Penyorotan label, penyorotan sintaksis, ukuran font, dan spasi baris dikontrol Pengaturan → Antarmuka.
  • Rakitan Mini-C yang dihasilkan dapat terbuka secara otomatis di jendelanya sendiri ketika preferensi tersebut diaktifkan.

Membangun model

Merakit membangun sumber perakitan yang dipilih menjadi gambar program. Kompilasi C0 menerjemahkan proyek C ke perakitan MIPS; perakitan yang dihasilkan kemudian dirakit sebelum dieksekusi. Proyek multi-file C ditautkan sebagai satu unit terjemahan oleh kompiler pengajaran.

Pemulihan lokal dan proyek cloud

webMARS menyimpan data pemulihan di penyimpanan browser sehingga memuat ulang dapat memulihkan sesi kerja. Lima slot proyek lokal eksplisit terpisah dari sesi pemulihan tersebut.

Itu Awan menu adalah opsional. Login, buka/simpan proyek, sinkronisasi dan penyegaran berkomunikasi dengan server cloud yang dikonfigurasi. Penggunaan cloud tidak pernah diperlukan untuk pengeditan, kompilasi, atau pengoperasian lokal.

Penyimpanan browser bukanlah cadangan permanen. Penjelajahan pribadi, tekanan kuota, pembersihan browser, atau perintah Hapus Penyimpanan Lokal dapat menghapusnya. Unduh pekerjaan yang harus disimpan.
