webMARS __WEBMARS_APP_VERSION__

Lingkungan pembelajaran MIPS32 asli browser dengan assembler, simulator JavaScript, debugger, kompiler Mini-C, contoh, dan perangkat interaktif.

Tidak ada instalasi

Jalankan aplikasi di browser modern. Java dan WebAssembly tidak diperlukan.

Lokal-pertama

Edit, kompilasi, jalankan, simpan ke penyimpanan browser dan unduh tanpa masuk.

Berfokus pada pengajaran

Gunakan sintaksis gaya MARS MIPS, panggilan sistem, peta memori, alat, dan profil Mini-C terstruktur.

Kemampuan saat ini

  • MIPS32 integer, memori, cabang, pengecualian, LL/SC dan COP1 eksekusi.
  • Referensi instruksi dasar dan semu, makro dan kompatibilitas assembler yang dapat dikonfigurasi.
  • Snapshot titik henti sementara, langkah, mundur, jeda, berhenti, setel ulang, dan status waktu proses.
  • Kompilasi C0-S0 hingga C0-S4 dan C1-NATIVE Mini-C menargetkan o32.
  • Delapan belas alat runtime, contoh pilihan dalam dua puluh bahasa dan proyek cloud opsional.
  • Tolok ukur Kompilasi, Rakitan, dan Jalankan Lokal dengan perkiraan pemanfaatan JavaScript.

Privasi

webMARS tidak memiliki iklan. File sumber, preferensi, file virtual, data pemulihan, tolok ukur, dan status waktu proses tetap ada di perangkat secara default. Sampel benchmark bersifat fluktuatif dan tidak dikirimkan.

Fitur cloud bersifat opsional. Saat Anda masuk atau melakukan sinkronisasi, akun/sesi dan data proyek dikirim ke server cloud yang dikonfigurasi di Pengaturan. Tinjau persyaratan operator sebelum menggunakan pihak ketiga atau server khusus. Unduhan dan file yang dibuka dari disk menggunakan kontrol file browser normal.
