变更日志

版本 0.6.1 强化了课堂版本：其部署包已完成，稳定链接无法关闭，分页准确，并且两个主题均符合检查的可访问性标准。

0.6.1 — 完整的软件包和硬化的稳定链接

  • 在部署 ZIP 中捆绑独立版本的手册和教师工具包，消除了全新安装中无效的 /manual/ 链接。
  • 使永久 example-ID 注册表具有权威性：有效的重定向仍然可以解析，而逻辑删除、未知 ID 和重定向循环则无法关闭。
  • 使公共图书馆分页遵循 BackMars 的显式 hasMore 结果，同时保留与旧安装的兼容性。
  • 修正了应用程序和手册中的浅色和深色主题对比，并为对话框消息提供了一个易于理解的名称。
  • 对捆绑手册、其产品锁定哈希值、JavaScript 模块和内部链接进行了扩展版本验证。
  • 更正了本地化产品信息以报告实际发货的 20 个工具。

0.6.0 — 稳定的教室和公共图书馆

  • 为每个内置示例添加了永久直接链接。稳定 ID 存在于专用注册表中，永远不会被删除或重复使用；已停用的条目仍保留为墓碑或显式重定向。
  • 通过BackMars添加了公共项目发布。每个发布都会按照先到先得的原则在该部署上收到一个全球唯一的公共名称，并通过一个简短的 /p/name 链接打开。
  • 使已发布的修订不可变。取消固定的链接遵循最新的活动修订版，而 /p/name@N 即使在普通存档之后也会继续打开确切的历史快照。
  • 添加了具有搜索、分页和只读预览功能的公共图书馆浏览器。打开出版物会创建一个干净的本地副本，因此公共材料永远不会默默地更改作者的项目或进入 Cloud 存储。
  • 对公共交换格式进行版本控制和清理。出版物仅包含项目文件和安全教学元数据，由浏览器和 BackMars 独立执行严格限制。
  • 添加了使用过期的一次性代码通过电子邮件恢复密码的功能。成功重置会使现有会话无效，并且请求不会显示地址是否已注册。
  • 添加了电子邮件验证和重新发送流程。部署可能需要在发布之前提供经过验证的地址，同时保持本地编辑、示例和模拟在没有帐户的情况下可用。
  • 将每个安装的名称、基本路径、公共 URL、BackMars 端点、手册和支持链接移至 webmars-config.js，以便大学无需编辑应用程序代码即可部署独立实例。
  • 将自动首次运行的“关于”窗口替换为引导式“欢迎”窗口，同时将“关于”保留在“帮助”下，并优先考虑直接示例或出版物链接。
  • 添加了一个教师工具包，涵盖从 MARS 迁移、一流的 LMS 文本、稳定链接发布、解决方案和自托管/隐私决策。
  • 在 v0.1 开始独立版本的 webMARS 手册，包含详细章节、浅色主题屏幕截图以及针对 webMARS 版本的明确验证。
  • 添加了稳定 URL、私有数据库存储、备份、迁移、Gmail SMTP 和部署后冒烟测试的生产指南和路由配置。

0.5.6 — 管道遵循程序

  • 向管道实验室添加了录制的执行流。该模型没有假设分支如何解析，而是重播实际执行的序列 webMARS，因此分支、错误预测和丢弃的指令都是事实而不是假设。
  • 添加了寄存器视图：当前周期中每个寄存器的值、早期阶段仍在运行的值以及针对更改它的周期的每个寄存器的网格。值仅出现在运行时提供的位置；静态流故意不显示任何内容。
  • 连接两种运输方式。在 webMARS 中执行的一条指令是进入管道的一条指令，在两个方向上：主窗口中的 Step 和 Backstep 移动管道，并且当获取阶段没有剩余内容可读取时，工具自己的步骤控制运行或取消运行程序。
  • 为 Backstep 添加了 F8​​，Backstep 没有快捷方式，而 Step 有 F7。
  • 将 Pipeline Lab 重新绘制为垂直管道，管道寄存器位于每对阶段之间，位于时间线旁边而不是上方，因此阶段可以显示指令、其源代码行及其使用的值。
  • 让 Pipeline Lab 靠着自己的窗口而不是屏幕放置，因此大显示屏上的窄窗口可以像手机一样折叠，并且每个控制组都可以手动打开和关闭。
  • 添加了一个目标区域设置更新程序，该更新程序仅翻译目录仍以英语回答的字符串，而无需重写已手动更正的条目。它拒绝任何更改占位符的翻译。
  • 翻译了 17 种语言中仍以英语显示的 872 个界面字符串，并添加了一项测试，当某种语言以英语回答界面的内容比以前多时，该测试就会失败。
  • 修复了 Pipeline Lab 忽略主窗口中的 Backstep：运行时将其传递到工具未监听的通道上，因此该工具不断重放未执行的指令。
  • 修复了移动模式下的步进替换读者选择的任何面板的问题。运行程序引起的焦点不再改变可见面板；打开一个新的或已经打开的窗口，仍然如此。
  • 修复了管道实验室在遵循步进程序时仅显示最后阶段的问题，这使得管道在每一步中都会排出并重新填充，而不是填充。
  • 修复了三个从未定义的界面颜色标记，这些标记使时间线中的停顿标记静音，并使两个主题中的静音文本保持未静音状态。
  • 修复了当记录跳转到没有预测到的分支的地方（例如程序重置或异常处理程序）时，重播会停止直到循环耗尽的问题。
  • 添加了 npm run version:set，它将版本写入声明它的所有十一个位置，并将版本从声明它的帮助页面移出到运行时令牌中。
  • 重建 Pipeline Lab 时序模型：控制风险、可配置延迟槽、静态和动态分支预测、可配置内存延迟、序列化陷阱以及七个可以并排比较的独立版本架构配置文件。
  • 添加了架构视图，绘制带有流水线寄存器、每指令控制线、多路复用器、实时转发路径和危险检测的数据路径，以及可以单独隐藏的信号组。
  • 添加了与 BHT 模拟器共享的分支历史记录表，因此两个工具的预测相同；回归测试通过相同的结果序列驱动两个预测变量，并在出现任何分歧时失败。
  • 添加了可重现的 JSON 和 CSV 导出，其中包含模型版本、配置文件版本、完整配置和程序哈希，没有时间戳，因此相同的工作会生成字节相同的文件。
  • 添加了七个指导实验室，其中包括目标、先决条件、运行前预测步骤和反思问题，以及单独的解决方案表、教师采用指南和简短演示。工作表引用的每个数字都由测试套件重新测量。
  • 添加了针对校验和固定的 MARS 4.5 的差分套件，比较机器代码、数据段、控制台输出和所有 32 个寄存器。十一个程序中有八个是字节相同的；其余三个差异均以理由和最低限度的复制情况来声明。
  • 添加了生成的兼容性、MARS 一致性、覆盖率、变异分数、基准和可访问性的证据报告，每个报告均由一个命令重新生成并由测试套件检查。
  • 添加了已发布的基准协议，其中包含声明的预热、重复计数和异常值规则，报告具有四分位数范围的中位数并记录每个结果来自的机器。
  • 添加了汇编器、运行时和状态导入器的突变测试和有界确定性模糊测试。
  • 修复了管道实验室在第一次组装后未收到运行时更新的问题，这是由于工具报告自身已断开连接造成的。
  • 修复了符号分支目标永远不会在时序模型中解析的问题，这使得每个分支预测报告零错误预测。
  • 修复了导入损坏或缺失的已保存运行时状态时发生的崩溃，该状态以空白屏幕的形式出现在用户面前。
  • 修复了编辑器和 Mars Messages 窗格没有可访问名称以及浅色主题中 WCAG 对比度最小值下方的文本颜色的问题。
  • 修复了从右到左语言中固定的时间线列分离问题，并保持管道图从左到右，以便其阶段顺序仍然向前读取。
  • 为管道阶段添加了可选的色觉安全调色板。
  • 添加了开发人员文档：架构边界、首次贡献指南、添加指令指南、系统调用和设备、运行时不变量、带有工作示例和脚手架生成器的版本化工具 API 以及发布过程。
