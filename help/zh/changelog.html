变更日志

版本 0.5.2 将 webMARS 扩展到十种语言，添加了自动浏览器语言选择，并引入了鼠标驱动的 MARS-OS 桌面。

0.5.2 —十种语言，自动选择，MARS-OS桌面

  • 将完整的界面、示例目录、文档和帮助从英语、西班牙语和葡萄牙语扩展到十种语言，添加了中文普通话、印地语、阿拉伯语、法语、孟加拉语、俄语和印度尼西亚语。
  • 添加了具有区域代码规范化和英语回退功能的首次访问浏览器语言检测，同时保留显式保存的首选项。
  • 添加了从右到左的阿拉伯语布局，同时保持源代码、运行时输出和技术符号从左到右。
  • 将 MARS-OS 重新设计为鼠标驱动的桌面，可直接在程序管理器中打开并在终端应用程序内运行 shell 命令。
  • 改进了 TTY 吞吐量、Android 键盘感知移动尺寸和桌面垂直间距。
  • 添加了可重复的本地化生成、受保护的技术术语和完整的十种语言回归覆盖。

0.5.1 — 设备中断、运行时工具、MARS-OS 时钟

  • 为定时器、键盘、显示器和数字实验室十六进制键盘实现了同步外部中断，并具有 CPU 侧屏蔽和挂起状态传送。
  • 添加了系统时钟和堆栈可视化工具，包括与精确后步兼容的集中式稀疏增量。
  • 通过解码指令批、合并渲染和有界运行时事件历史记录减少连接工具开销。
  • 添加了本地化定时器中断示例并扩展了 MARS-OS clock 和实时 bench 命令。
  • 防止紧凑运行时快照临时清除执行 UI 中的组装文本段。
  • 将文件管理器和云合同与冲突安全保存、远程重命名/删除、不区分大小写的项目标识和批量同步状态整合在一起。

0.5.0 — 成熟的运行时、增量后退、移动工作流程

  • 更正了跨内存限制、原子存储、COP1 双倍和舍入、延迟分支、异常、LL/SC 保留和断点的高影响运行时行为。
  • 用有界逆增量替换了完整的每指令快照，同时保留了精确的后步窗口和同步工具状态。
  • 通过紧凑的运行时事件批处理、合并工具渲染和更轻量级的 UI 同步，减少了执行开销。
  • 添加了动态位图 MMIO 配置并更新了位图示例和库以使用它，同时保持与 MARS 4.5 兼容。
  • 扩大了 TTY 结合实际的例子 MIPS 壳并改进了装配和 Mini-C 所有三种语言的课程目录。
  • 将工具、对话框、云和设置集成到移动窗口系统中，包括 Android 键盘感知大小、语义虚拟键盘和包含滚动。
  • 添加了全面的运行时、工具、示例、文档、移动 UI 和发布回归覆盖范围。

0.4.13 — 移动单面板布局，本地化诊断

  • 移动设备一次显示一个全屏面板，从列出主、消息/运行 I/O、寄存器和任何打开的工具的新图标选项卡栏中选择。
  • 固定移动视口，使页面不再滚动，从而消除文档和窗口主体之间的嵌套滚动冲突。
  • 移动工具栏只有图标，横跨两排紧凑的行，将执行控件和运行速度选择器保留在屏幕上；文件操作隐藏在那里并保留在“文件”和“编辑”菜单中。
  • 隐藏移动设备上的最小化和最大化按钮，其中一个面板填满屏幕，标签栏进行切换。
  • 本地化了每个汇编器和 Mini-C 诊断，将 114 个模板文字转换为命名占位符，并在三种语言中添加 277 个键。
  • 添加了当可翻译消息没有目录条目时失败的发布测试。
  • 桌面布局、窗口位置和控件大小保持不变。

0.4.12 — 深色主题、字体大小修复、死代码清理

  • 添加了可选择加入的深色主题 Settings > Interface...，应用于编辑器、工具窗口和帮助页面。
  • 修复了在界面首选项中更改编辑器字体大小和行高后立即应用的问题，无需重新加载页面。
  • 有线的 关闭所有文件 行动成 File > Close > All files.
  • 删除了机器会话自动保存管道（约 400 行），该管道被门控在任何版本中从未设置的实验标志后面。
  • 删除了五个模块中约 15 个死函数、未使用的注册表导出、死的 CSS 选择器和 113 个未使用的 i18n 键。
  • 从发行包中排除了无法访问的根级帮助文件。

0.4.11 —持久云登录恢复

  • 在应用程序启动期间静默检查配置的云服务器并恢复现有的经过身份验证的用户。
  • 成功恢复会话后刷新云项目元数据，而不阻塞本地工作区。
  • 记录了身份验证 cookie 的一年最长生命周期并在注销时立即删除。
  • 添加了针对凭据请求和自动启动恢复的回归覆盖范围。

0.4.10 — 批量工具历史记录和更轻量级的 UI 更新

  • 保留的工具增量仅适用于仍由引擎的精确 100 步后退窗口覆盖的指令。
  • 使每个运行时事件可供工具模型使用，同时批量可视化更新并避免过时的历史记录分配。
  • 减少每条指令 DOM 工作于 BHT 以及缓存模拟器中的冗余状态副本。
  • 停止闲置的 Mars Bot 渲染，并从 UI 同步中删除了冗余的完整运行时快照。
  • 更正了仅适用于 Firefox 的窗口标题分隔符重绘问题。
  • 减少 Monty Hall 实验室中的空闲终端轮询，而不影响输入响应或后退。

0.4.9 — 运行时奇偶校验和可靠的后退

  • 保留最近 100 个后退可用，同时限制稀疏日志内存。
  • 更正了浏览器长时间运行时的同步键盘/显示器、TTY 和工具事件行为。
  • 更新了 Monty Hall 实验室和交互式示例，以配合浏览器输入，而无需忙于轮询。
  • 将随机系统调用 40-44 与种子序列和采样规则相匹配 java.util.Random 由 MARS 使用。
  • 强化的运行时状态导入、长指令计数器、汇编器范围和数字指令验证。
  • 完成了图像元数据的后退覆盖并更正了零长度InputDialogString缓冲区。
  • 扩展了运行时、本地化示例和连接工具的回归覆盖范围。

0.4.8 — delta backsteps 和同步设备

  • 用有界逆增量替换了完整的每指令后步快照。
  • 独立的同步 MMIO 设备、紧凑的运行时事件批次和定期工具快照。
  • 更正了键盘/显示器和 TTY 输入/输出因果关系、后退和隐藏工具开销。
  • 修复了缓存、指令、内存引用和位图工具中的批量渲染。
  • 将 Mini-C 示例帧缓冲区移离编译器全局变量，并将位图显示与实时内存同步。
  • 使本地基准测试条在“界面首选项”中可选并默认隐藏。

0.4.7 — JavaScript 运行时强化和完整文档

  • 标准化了纯 JavaScript 引擎上的运行时，并删除了实验性 WASM/混合后端。
  • 添加了编译、汇编和运行计时以及估计的 JavaScript 利用率到应用内基准测试条中。
  • 保持完整的运行时快照可供连接的设备使用，同时以最大运行速度减少编辑器工作。
  • 更正了 COP1 双字排序、基于 FCSR 的转换舍入和完整的数字输入验证。
  • 强化的堆限制、原子存储、指令对齐、严格的部分加载和 LL/SC 保留。
  • 更正了延迟分支链接地址、延迟槽异常状态以及直接引擎 Go 和浏览器驱动执行之间的奇偶校验。
  • Made Stop 会终止引擎并取消挂起的睡眠，而 Pause 仍可恢复。
  • 扩展运行时快照以保留断点、随机流、虚拟文件/游标、标准输入、程序参数和图像句柄。
  • 扩展并合理化了英语、西班牙语和葡萄牙语示例目录，包括 C1-NATIVE 和多文件 C 项目。
  • 更新了所有英语、西班牙语和葡萄牙语应用内帮助，以匹配当前的浏览器应用程序、运行时、Mini-C编译器、工具、存储和隐私行为。
  • 添加了版本一致性、清单、瞬态文件和本地化 UI 合约的发布准备情况检查。

0.4.6 — 可重现的浏览器工作区

  • 建立可重复的安装、服务、构建、测试和验证命令。
  • 添加了对汇编器/运行时行为、浏览器集成、工具和示例的广泛回归覆盖。
  • 引入了可配置的运行时内存和后步限制，具有更强的状态持久性。
  • 扩展了 Mini-C 配置文件、o32 行为、库、示例和多语言界面覆盖范围。

早期 webMARS 里程碑

  • 添加了本地项目、会话恢复、可选的云同步和浏览器虚拟文件。
  • 移植和改编核心教育工具和MMIO设备。
