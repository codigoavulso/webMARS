开始使用

webMARS 是一个基于浏览器的 MIPS32 汇编器、模拟器、调试器、Mini-C 编译器和教学工作区。运行时完全在 JavaScript 中实现；无需安装 Java、本机可执行文件或 WASM 后端。

  1. 打开或创建源文件。 使用 文件 → 示例 作为指导起点， 新项目 对于空白项目，或者 从磁盘打开 对于本地文件。
  2. 建造它。 汇编文件使用 运行 → 组装 (F3）。 C文件使用 运行→编译C0 (F4），然后组装生成的程序集。
  3. 执行它。 选择 去 (F5）或一次推进一项指令 步骤 (F7).
  4. 检查结果。 寄存器、协处理器 1、内存、消息、运行 I/O 和连接的工具随着程序运行而更新。

包含什么

MIPS32 运行时

整数、分支、内存、异常、LL/SC 和 COP1 执行，包括延迟分支和自修改代码选项。

Mini-C 编译器

C0 教学子集和 C1-NATIVE 配置文件，针对 MIPS o32 调用约定。

调试器

断点、步进、后退、重置、暂停/停止控制和可配置的执行速度。

设备和工具

MMIO 设备、缓存和分支模拟器、可视化显示、统计、ANSI 终端等等。

推荐首次运行

打开 文件 → 示例, 选择英语 学习 例如，阅读其说明并打开它。汇编示例可以直接汇编并运行。 C 示例声明其最小编译器子集，并且可能包含多个项目文件。

默认情况下，您的文件保留在浏览器中。 除非您明确使用云菜单，否则不会上传本地项目和恢复数据。定期下载重要的工作，因为浏览器存储可以由浏览器或 设置 → 清除本地存储.
