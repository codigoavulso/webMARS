webMARS __WEBMARS_APP_VERSION__

浏览器本机 MIPS32 学习环境，包含汇编器、JavaScript 模拟器、调试器、Mini-C 编译器、示例和交互式设备。

无需安装

在现代浏览器中运行应用程序。 Java 和 WebAssembly 不是必需的。

本地优先

编辑、编译、运行、保存到浏览器存储并无需登录即可下载。

以教学为中心

使用 MARS 风格的 MIPS 语法、系统调用、内存映射、工具和结构化 Mini-C 配置文件。

目前的能力

  • MIPS32 整数、内存、分支、异常、LL/SC 和 COP1 执行。
  • 基本和伪指令参考、宏和可配置汇编器兼容性。
  • 断点、单步、后退、暂停、停止、重置和运行时状态快照。
  • C0-S0 到 C0-S4 和 C1-NATIVE Mini-C 编译针对 o32。
  • 十八种运行时工具、二十种语言的精选示例和可选的云项目。
  • 本地编译、组装和运行基准测试，估计 JavaScript 利用率。

隐私

webMARS没有广告。默认情况下，源文件、首选项、虚拟文件、恢复数据、基准测试和运行时状态保留在设备上。基准样本是易失性的并且不会被传输。

云功能是可选的。当您登录或同步时，帐户/会话和项目数据将发送到“设置”中配置的云服务器。使用第三方或自定义服务器之前，请查看运营商的条款。下载和从磁盘打开的文件使用普通的浏览器文件控件。
