Mini-C

内置教学编译器使用 o32 调用约定将故意定义的 C 子集转换为 MIPS32 程序集。它不是通用的 ISO C 编译器。

型材

公司简介目的
C0-S0 到 C0-S4累积教学子集，从表达式和控制流进展到函数、数组、指针、结构、typedef、契约和库。
C1-NATIVE默认的、功能最强大的配置文件：字节寻址 char/char *, 原生字符串, argc/argv、函数指针和 void *.

如果源需要更高的配置文件，编译会发出一个集中的 MC_SUBSET_MISMATCH 诊断而不是一连串的次要错误。

编译一个项目

  1. 在中选择所需的配置文件和输出选项 设置 → Mini-C 首选项.
  2. 打开一个或多个 .c 同一项目中的文件。
  3. 选择 运行→编译C0 或按 F4.
  4. 查看诊断并生成 MIPS 程序集。正常编译并运行生成的程序。

调用约定和入口点

  • 参数使用 $a0–$a3，附加参数使用堆栈，返回值使用 $v0 （和 $v1 在适当的情况下）。
  • 被调用者保存的寄存器和堆栈帧遵循 MIPS o32 期望。
  • main(void) 并且，在 C1-NATIVE 中， main(int argc, char **argv) 都支持。
  • 对于 webMARS 程序参数， argv[0] 是用户提供的第一个令牌；没有自动的可执行文件名称条目。

捆绑的标头和库

标准输入输出科尼奥文件 参数字符串字符串本地 解析图像实用程序 兰特类型标准库 标准布尔标准定义位图矩形 位图_ascii终端

这些标头是 webMARS 围绕兼容性库构建 MIPS 系统调用和设备。他们实现了记录的子集，而不是完整的主机 C 标准库。

#use <bitmap_rect> 还提供 bitmap_configure_display, bitmap_configure_terminal 和 bitmap_configure_all，允许 C0 程序将其显示大小、单元大小和帧缓冲区地址发送到位图工具。

良好的起始示例

  • 你好世界（C） 为最小的完整程序。
  • Mini-C C1 本机 用于本机字符串和当前配置文件行为。
  • 参数库演示 为了 argc/argv.
  • 多文件统计 用于项目范围的编译和跨文件的函数调用。
  • stdio 控制台基础知识 和 stdio 文件往返 对于兼容性库。
存储库中的编译器手册仍然是规范的、详细的语言参考。应用程序内页面总结了选择配置文件并正确运行示例所需的行为。
