致谢

webMARS 立足于原始 MARS 项目建立的教学模型、指导文档、工具和社区经验。

原始MARS

由 Pete Sanderson 和 Kenneth Vollmar 创建，并得到了教育工作者、学生和工具作者的贡献。他们的工作建立了平易近人的 MIPS 汇编器/模拟器工作流程，webMARS 在浏览器中继续使用。

值得注意的原创贡献包括宏系统、指令统计和计数器工具、分支预测模拟器、键盘/显示器 MMIO 工作、数字实验室 Sim、MIPS X-Ray、MIDI 改进以及通过课堂使用收集的许多更正。

webMARS

浏览器实施和持续维护由 Nelson Ferreira 负责。当前的应用程序包括独立的 JavaScript MIPS 引擎、Mini-C 编译器和库、本地/云项目工作流程、运行时工具、多语言示例和自动回归覆盖。

社区和标准

感谢所有报告可重现故障、贡献教学示例、检查翻译并将架构行为与 MIPS32 文档进行比较的人。这些报告直接提高了兼容性和运行时正确性。

原来的 MARS 许可证 和 MIPS 指令集歌曲 保留作为历史帮助项目及其原始归属。它们的存在并不意味着当前的浏览器实现使用原始的 Java 源代码。
