限制 & 兼容性

webMARS 旨在实现实际的 MARS 4.5 源兼容性，同时完全在现代浏览器中运行。浏览器安全、存储和音频规则仍然适用。

MIPS 行为

  • 内存是小端的。字和双字操作使用 MIPS 寄存器/内存排序。
  • 未对齐的指令提取和无效的加载/存储地址会引发地址异常。
  • 存储在写入之前验证完整的目标，因此失败的存储不会留下部分值。
  • LL/SC 使用冲突存储无效的保留。
  • COP1 转换遵循 FCSR 舍入模式；浮点输入拒绝尾随非数字文本。
  • 凭借严格的 MARS 兼容性，内存操作（包括部分字加载）必须保留在允许的段内。

已知的可移植性边界

  • 浏览器虚拟文件系统不是主机操作系统的不受限制的文件系统。
  • Web 音频权限和自动播放策略可能会影响 MIDI 系统调用。
  • 弹出窗口阻止程序和下载策略可能会影响导出的文件。
  • Mini-C 仅接受其记录的配置文件；依赖于完整 ISO C 的代码，主机 libc 或未定义的行为不可移植到它。
  • 依赖于 Java 类或桌面插件的历史 MARS 扩展不可用。
