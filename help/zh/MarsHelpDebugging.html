运行 & 调试

Run 菜单控制由寄存器、内存视图、调试器和连接的工具共享的一个 JavaScript MIPS 引擎。

执行控制

控制含义
去运行直到正常完成、断点、等待输入的系统调用、未处理的异常、限制、暂停或停止。
暂停暂停活动运行，同时保留机器，以便其可以继续。
停止终止执行并取消挂起的异步工作，例如长睡眠系统调用。停止的程序不会恢复。
步骤执行一条指令。断点停止后，下一个 Go 或 Step 会跨越该断点一次，因此不会立即再次停止在同一地址处。
后退一步恢复之前记录的运行时快照，直至配置的历史记录深度。
重置将汇编的程序返回到其初始机器状态。

断点和源跟踪

在可执行源代码行旁边的编辑器装订线中切换断点。断点存储在运行时状态中，并在正常的导出/导入往返过程中继续存在。伪指令可以扩展为几个基本指令；步进遵循生成的机器指令，而源突出显示仍然与原始行相关联。

速度和性能带

运行速度控制范围从交互式步进速率到最大速度。以最大速度 webMARS 减少了昂贵的编辑器突出显示和自动滚动工作，但工具继续接收完整的运行时快照和跟踪信息。

紧凑的基准测试条报告最近的编译、汇编和运行时间以及估计的 JavaScript CPU 利用率。测量是本地的且不稳定的：它们旨在比较工作负载和算法变化，而不是作为操作系统进程仪表。

延迟分支和异常

当启用延迟分支时，分支或跳转后的指令是延迟槽指令和链接指令存储 PC + 8。延迟槽中引发的异常设置 COP0 原因 BD 位，并将分支地址记录在 EPC 中。

如果配置的处理程序地址处存在有效的异常处理程序，则执行将转移到该处理程序并可能返回 eret。否则，运行会因明确的原因和诊断而停止。

后退范围。 快照包括寄存器、内存、断点、随机流、文件位置、待处理输入、程序参数和设备图像句柄。大量历史记录会消耗内存，因此请调整练习的限制。
