Historia

webMARS comenzó como un port al navegador del simulador MIPS MARS 4.5. Hoy combina un runtime JavaScript independiente, editor, depurador, compilador Mini-C, proyectos locales/Cloud y herramientas nativas del navegador.

Línea de desarrollo actual

  • Runtime solo JavaScript. Se eliminó la ruta experimental híbrida/WASM porque añadía complejidad sin una mejora suficiente.
  • Corrección del runtime. Se reforzaron COP1 doubleword, stores atómicos, heap, LL/SC, direccionamiento estricto, saltos retardados, FCSR, excepciones y Stop.
  • Instantáneas completas. Exportar/importar y paso atrás incluyen generadores aleatorios, archivos y cursores, stdin, argumentos, imágenes y puntos de ruptura.
  • Observación del rendimiento. La app mide Compilar, Ensamblar y Ejecutar y estima uso JavaScript sin privar a las herramientas del estado completo.
  • Evolución de Mini-C. C0 convive con C1-NATIVE, o32, strings por bytes, argumentos, punteros a función, proyectos multiarchivo y bibliotecas.
  • Ejemplos como currículo. Los ejemplos Assembly y C se clasifican por objetivo, idioma y perfil mínimo.

Origen de compatibilidad

El vocabulario de instrucciones, syscalls comunes, conceptos de interfaz y modelo educativo proceden del MARS original de Pete Sanderson y Kenneth Vollmar. webMARS conserva ese origen sustituyendo la integración Java por APIs del navegador y su propio motor.
