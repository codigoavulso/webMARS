Una ruta práctica de MARS MIPS a webMARS, con enlaces estables, revisiones reproducibles y alternativa sin red.

Migración en 15 minutos

  1. Abra un archivo .s, .asm o .mips existente desde Archivo → Abrir desde disco.
  2. Ensamble con F3, ejecute con F5, avance con F7 y retroceda con F8.
  3. Active la compatibilidad estricta MARS 4.5 cuando el ejercicio dependa del comportamiento histórico.
  4. Pruebe entrada, salida, syscalls, mapa de memoria y herramientas necesarias.

Enlaces estables

  • /e/<id>: ejemplo integrado con identificador estable.
  • /p/<nombre>: última revisión publicada.
  • /p/<nombre>@<revisión>: revisión inmutable recomendada para evaluaciones.

Los nombres se asignan por orden de llegada y son permanentes dentro de cada BackMars. Comparta siempre la URL completa de la instalación.

Publicación

  1. Pruebe el proyecto, inicie sesión y verifique el correo.
  2. Use Online → Proyecto → Publicar proyecto activo.
  3. Comparta una revisión fija para actividades evaluadas.
  4. Publique una revisión nueva para corregir; las anteriores no cambian.

Texto para el LMS

Ejercicio: [URL WEBMARS FIJA]
Versión: webMARS [VERSIÓN], revisión [REVISIÓN]
Entrega: fuente .s/.asm y resultado solicitado.
Sin red: abra desde disco la fuente descargada.

Privacidad y despliegue propio

La edición y ejecución son locales por defecto. Cloud, recuperación de cuenta y biblioteca usan el BackMars de esta instalación. Las credenciales SMTP solo se guardan en el entorno protegido de BackMars, nunca en el cliente web.
