Herramientas

Abre las herramientas desde el menú Herramientas. Cada una tiene una ventana independiente y puede conectarse al runtime MIPS actual para observar instrucciones, memoria o actividad MMIO.

Conecta antes de ejecutar. Una herramienta conectada recibe instantáneas y trazas completas incluso cuando la máxima velocidad reduce el resaltado del editor.

Configuración Bitmap desde MIPS

Un programa puede configurar cualquiera de las herramientas Bitmap escribiendo este bloque versionado relativo a la base MMIO activa (normalmente 0xffff0000). Escribe primero todos los campos y al final 1 en el comando; la herramienta solo cambia tras ese commit atómico.

OffsetValor
+0x20Firma 0x57424d50 (WBMP)
+0x24Versión del protocolo 1
+0x28Destino: 1 Display, 2 Terminal, 3 ambos
+0x2c … +0x38Ancho y alto de pantalla; ancho y alto de unidad
+0x3cDirección base del framebuffer
+0x40Comando: 1 aplicar, 2 borrar la configuración del programa

Los bloques inválidos o incompletos se ignoran. Paso atrás, exportación y restauración conservan la configuración confirmada. Es una extensión opcional de webMARS: MARS 4.5 ignora estas palabras MMIO no utilizadas y el mismo framebuffer sigue funcionando con configuración manual.

Seguridad MMIO

Los dispositivos MMIO se asignan cerca de 0xffff0000. Las herramientas y el runtime comparten esas direcciones; los programas de sondeo deben respetar los bits de disponibilidad y los programas con interrupciones necesitan un handler válido.
