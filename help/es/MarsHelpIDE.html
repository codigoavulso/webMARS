Espacio de trabajo y archivos

Un proyecto es la unidad que webMARS guarda, compila y ensambla. Puede contener uno o más archivos Assembly .asm/.s y archivos Mini-C .c.

Editor y navegación

  • Usa las pestañas de código para cambiar el archivo activo. Cerrar un archivo no cierra el proyecto.
  • Los errores de Assembly y los diagnósticos de Mini-C identifican archivo y línea cuando están disponibles.
  • Las etiquetas, el resaltado, el tamaño de fuente y el interlineado se configuran en Ajustes → Interfaz.
  • El Assembly generado por Mini-C puede abrirse automáticamente en su propia ventana.

Modelo de construcción

Ensamblar genera una imagen ejecutable a partir de las fuentes Assembly seleccionadas. Compilar C0 traduce el proyecto C a Assembly MIPS, que después se ensambla. Los proyectos C con varios archivos se enlazan como una única unidad por el compilador educativo.

Recuperación local y proyectos Cloud

webMARS mantiene datos de recuperación en el navegador para restaurar la sesión tras recargar. Las cinco ranuras locales explícitas son independientes de esa recuperación automática.

El menú Cloud es opcional. Inicio de sesión, apertura/guardado, sincronización y actualización se comunican con el servidor configurado. No se necesita Cloud para editar, compilar o ejecutar localmente.

El almacenamiento del navegador no es una copia de seguridad permanente. La navegación privada, la falta de cuota, la limpieza del navegador o Borrar localStorage pueden eliminarlo.
