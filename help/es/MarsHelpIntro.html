Primeros pasos

webMARS es un ensamblador, simulador, depurador, compilador Mini-C y espacio educativo MIPS32 que funciona en el navegador. El runtime está implementado íntegramente en JavaScript; no requiere Java, ejecutables nativos ni un backend WASM.

  1. Abre o crea un archivo fuente. Usa Archivo → Ejemplos para empezar con una guía, Nuevo proyecto para crear un proyecto vacío o Abrir desde disco para importar archivos locales.
  2. Constrúyelo. Para archivos Assembly usa Ejecutar → Ensamblar (F3). Para archivos C usa Ejecutar → Compilar C0 (F4) y después ensambla el código generado.
  3. Ejecútalo. Selecciona Ejecutar (F5) o avanza una instrucción con Paso (F7).
  4. Inspecciona el resultado. Los registros, el coprocesador 1, la memoria, los mensajes, la E/S y las herramientas conectadas se actualizan durante la ejecución.

Qué incluye

Runtime MIPS32

Ejecución de enteros, saltos, memoria, excepciones, LL/SC y COP1, con opciones de saltos retardados y código automodificable.

Compilador Mini-C

Subconjuntos educativos C0 y el perfil C1-NATIVE, con la convención de llamada MIPS o32.

Depurador

Puntos de ruptura, pasos hacia delante y atrás, reinicio, pausa/parada y velocidad configurable.

Dispositivos y herramientas

Dispositivos MMIO, simuladores de caché y saltos, pantallas, estadísticas, terminal ANSI y más.

Primera ejecución recomendada

Abre Archivo → Ejemplos, selecciona un ejemplo de aprendizaje en español y lee su descripción. Los ejemplos Assembly se pueden ensamblar directamente. Los ejemplos C indican su perfil mínimo y pueden contener varios archivos.

Tus archivos permanecen en el navegador por defecto. Los proyectos locales y la recuperación de sesión no se suben salvo que uses explícitamente el menú Cloud. Descarga periódicamente el trabajo importante.
