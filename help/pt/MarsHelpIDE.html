Área de trabalho e ficheiros

Um projeto é a unidade que o webMARS guarda, compila e monta. Pode conter um ou mais ficheiros Assembly .asm/.s e ficheiros Mini-C .c.

Editor e navegação

  • Use os separadores de código para mudar o ficheiro ativo. Fechar um ficheiro não fecha o projeto.
  • Erros de Assembly e diagnósticos Mini-C identificam o ficheiro e a linha quando disponíveis.
  • Etiquetas, realce, tamanho da letra e espaçamento configuram-se em Definições → Interface.
  • O Assembly gerado pelo Mini-C pode abrir automaticamente na sua própria janela.

Modelo de construção

Montar cria a imagem executável a partir das fontes Assembly selecionadas. Compilar C0 traduz o projeto C para Assembly MIPS, que depois é montado. Projetos C com vários ficheiros são ligados como uma unidade pelo compilador educativo.

Recuperação local e projetos Cloud

O webMARS mantém dados de recuperação no browser para restaurar a sessão após um reload. Os cinco slots de projeto explícitos são independentes dessa recuperação automática.

O menu Cloud é opcional. Login, abertura/gravação, sincronização e atualização comunicam com o servidor configurado. Não é necessário para editar, compilar ou executar localmente.

O armazenamento do browser não é um backup permanente. Navegação privada, pressão de quota, limpeza do browser ou Limpar localStorage podem removê-lo.
