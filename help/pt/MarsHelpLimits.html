Limites e compatibilidade

O webMARS procura compatibilidade prática com fontes MARS 4.5 enquanto funciona integralmente num browser moderno. Aplicam-se as regras de segurança, armazenamento e áudio do browser.

Limites do runtime

ÁreaLimite ou comportamento
Memória0,25–2 GiB configuráveis, com teto arquitetural abaixo de 0x80000000. A alocação esparsa evita reservar cada byte não utilizado.
Heapsbrk valida a reserva completa antes de mover o ponteiro e não pode ultrapassar o limite.
Strings do runtimeAs strings terminadas com null podem conter até 1 MiB. A falta do terminador ou uma string maior gera um erro explícito de syscall em vez de devolver texto truncado.
Passo atrás0–1.000.000 deltas inversos. O histórico é limitado pelo orçamento configurado e conserva sempre os últimos 100 passos completos quando o passo atrás está ativo.
Armazenamento do browserSujeito a quota. A aplicação limita a 1 MiB certos payloads e tenta recuperações menores quando necessário.
TemporizaçãoSleep, MIDI e interface usam o scheduler do browser e não são exatos ao ciclo.
DistribuiçãoO webMARS 0.5.4 é uma aplicação web estática, não uma PWA instalável ou offline. Tem de ser servido por HTTP pelo servidor local incluído ou por outro host estático.

Os presets Dados compactos e Texto compacto movem o segmento educativo correspondente para o endereço zero. Volte a montar após a alteração.

Comportamento MIPS

  • A memória é little-endian. Operações word e doubleword respeitam a ordenação MIPS.
  • Fetches desalinhados e endereços inválidos geram exceções de endereço.
  • Uma store valida todo o destino antes de escrever e nunca deixa um valor parcial.
  • LL/SC usam uma reserva invalidada por stores em conflito.
  • Conversões COP1 respeitam o FCSR e inputs numéricos rejeitam texto adicional.
  • No modo estrito, cargas parciais como LWL e LWR também têm de permanecer em segmentos permitidos.

Limites de portabilidade

  • O sistema virtual de ficheiros não é o sistema de ficheiros irrestrito do host.
  • Permissões de áudio podem afetar syscalls MIDI.
  • Políticas de popups e downloads podem afetar exportações.
  • O Mini-C aceita apenas os perfis documentados, não todo o ISO C nem uma libc completa.
  • Extensões históricas baseadas em classes Java ou plugins desktop não estão disponíveis.
