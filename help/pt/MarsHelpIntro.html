Começar

O webMARS é um assembler, simulador, depurador, compilador Mini-C e ambiente educativo MIPS32 que funciona no browser. O runtime é integralmente JavaScript; não necessita de Java, executáveis nativos nem de um backend WASM.

  1. Abra ou crie um ficheiro fonte. Use Ficheiro → Exemplos para começar com orientação, Novo projeto para criar um projeto vazio ou Abrir do disco para importar ficheiros locais.
  2. Construa o programa. Para Assembly use Executar → Montar (F3). Para C use Executar → Compilar C0 (F4) e monte o Assembly gerado.
  3. Execute. Selecione Correr (F5) ou avance uma instrução com Passo (F7).
  4. Inspecione o resultado. Registos, Coprocessador 1, memória, mensagens, E/S e ferramentas ligadas são atualizados durante a execução.

O que está incluído

Runtime MIPS32

Execução de inteiros, desvios, memória, exceções, LL/SC e COP1, incluindo opções de delayed branching e código automodificável.

Compilador Mini-C

Subconjuntos educativos C0 e o perfil C1-NATIVE, com a convenção de chamada MIPS o32.

Depurador

Breakpoints, passos para a frente e para trás, reset, pausa/paragem e velocidade configurável.

Dispositivos e ferramentas

Dispositivos MMIO, simuladores de cache e desvios, ecrãs, estatísticas, terminal ANSI e mais.

Primeira execução recomendada

Abra Ficheiro → Exemplos, escolha um exemplo de aprendizagem em português e leia a descrição. Os exemplos Assembly podem ser montados diretamente. Os exemplos C indicam o perfil mínimo e podem conter vários ficheiros.

Por omissão, os ficheiros permanecem no browser. Projetos locais e recuperação de sessão não são enviados, salvo se usar explicitamente o menu Cloud. Descarregue periodicamente trabalho importante.
