Mini-C

O compilador educativo integrado traduz um subconjunto C definido para Assembly MIPS32 segundo a convenção o32. Não é um compilador ISO C de uso geral.

Perfis

PerfilObjetivo
C0-S0 a C0-S4Subconjuntos cumulativos que evoluem de expressões e controlo para funções, arrays, ponteiros, estruturas, typedefs, contratos e bibliotecas.
C1-NATIVEPerfil predefinido e mais completo: char/char * por bytes, strings nativas, argc/argv, ponteiros para funções e void *.

Se uma fonte exigir um perfil superior, é emitido um único diagnóstico MC_SUBSET_MISMATCH, evitando uma cascata de erros secundários.

Compilar um projeto

  1. Selecione o perfil e a saída em Definições → Preferências Mini-C.
  2. Abra um ou mais ficheiros .c no mesmo projeto.
  3. Selecione Executar → Compilar C0 ou prima F4.
  4. Reveja os diagnósticos e o Assembly gerado; depois monte e execute normalmente.

Convenção de chamada e entrada

  • Os argumentos usam $a0–$a3, os adicionais usam a stack e os resultados usam $v0 e, quando aplicável, $v1.
  • Registos preservados e stack frames seguem MIPS o32.
  • São suportados main(void) e, em C1-NATIVE, main(int argc, char **argv).
  • argv[0] é o primeiro token introduzido pelo utilizador; não é adicionado automaticamente um nome de executável.

Exemplos recomendados

  • Hello World (C) para o programa completo mais pequeno.
  • Mini-C C1 Native para strings nativas.
  • Arguments Library Demo para argc/argv.
  • Multi-file Statistics para projetos com vários ficheiros.
  • stdio Console Basics e stdio File Roundtrip para bibliotecas de compatibilidade.
