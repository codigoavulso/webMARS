História

O webMARS começou como um port para browser do simulador MIPS MARS 4.5. Hoje combina runtime JavaScript independente, editor, depurador, compilador Mini-C, projetos locais/Cloud e ferramentas nativas do browser.

Linha de desenvolvimento atual

  • Runtime apenas JavaScript. O caminho experimental híbrido/WASM foi removido porque acrescentava complexidade sem melhoria suficiente.
  • Correção do runtime. Foram reforçados COP1 doubleword, stores atómicas, heap, LL/SC, endereçamento estrito, delayed branches, FCSR, exceções e Stop.
  • Snapshots completos. Exportar/importar e backstep incluem streams aleatórios, ficheiros e cursores, stdin, argumentos, imagens e breakpoints.
  • Observação de desempenho. A app mede Compilar, Montar e Executar e estima utilização JavaScript sem retirar estado às ferramentas.
  • Evolução do Mini-C. C0 coexiste com C1-NATIVE, o32, strings por bytes, argumentos, ponteiros para funções, projetos multificheiro e bibliotecas.
  • Exemplos como currículo. Exemplos Assembly e C são classificados por objetivo, idioma e perfil mínimo.

Linhagem de compatibilidade

O vocabulário de instruções, syscalls comuns, conceitos de interface e modelo educativo derivam do MARS original de Pete Sanderson e Kenneth Vollmar. O webMARS preserva essa linhagem substituindo a integração Java por APIs do browser e pelo seu próprio motor.
