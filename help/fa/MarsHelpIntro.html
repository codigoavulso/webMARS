شروع کردن

webMARS یک کامپایلر مبتنی بر مرورگر MIPS32 اسمبلر، شبیه ساز، اشکال زدا، Mini-C کامپایلر و فضای کاری آموزشی است. زمان اجرا به طور کامل در JavaScript پیاده سازی شده است. بدون نصب جاوا، قابل اجرایی بومی یا WASM باطن مورد نیاز است.

  1. فایل منبع را باز یا ایجاد کنید. استفاده کنید فایل → مثالها برای یک نقطه شروع هدایت شده، پروژه جدید برای یک پروژه خالی، یا از دیسک باز کنید برای فایل های محلی
  2. آن را بساز. استفاده از فایل های اسمبلی اجرا → اسمبل کنید (F3). استفاده از فایل های C اجرا → کامپایل C0 (F4، سپس مجموعه تولید شده را مونتاژ کنید.
  3. اجراش کن انتخاب کنید برو (F5) یا یک دستور را در یک زمان با مرحله (F7).
  4. نتیجه را بررسی کنید. ثبات ها، پردازنده مشترک 1، حافظه، پیام ها، اجرای I/O و ابزارهای متصل به هنگام اجرای برنامه به روز می شوند.

آنچه شامل می شود

MIPS32 زمان اجرا

اجرای اعداد صحیح، شاخه، حافظه، استثنا، LL/SC و COP1، شامل انشعاب تاخیری و گزینه‌های کد خودتغییر شونده.

Mini-C کامپایلر

زیرمجموعه های آموزشی C0 و نمایه C1-NATIVE، که کنوانسیون فراخوانی MIPS o32 را هدف قرار می دهد.

اشکال زدا

نقاط انفصال، گام برداشتن، پشت سر گذاشتن، تنظیم مجدد، کنترل های توقف/توقف و سرعت اجرای قابل تنظیم.

دستگاه ها و ابزار

MMIO دستگاه‌ها، شبیه‌سازهای حافظه پنهان و شاخه، نمایشگرهای بصری، آمار، پایانه ANSI و موارد دیگر.

اولین اجرای توصیه شده

باز کنید فایل → مثالها، انگلیسی را انتخاب کنید یاد بگیرید به عنوان مثال، توضیحات آن را بخوانید و آن را باز کنید. نمونه های اسمبلی را می توان به طور مستقیم مونتاژ و اجرا کرد. نمونه های C حداقل زیر مجموعه کامپایلر خود را اعلام می کنند و ممکن است حاوی چندین فایل پروژه باشند.

فایل های شما به طور پیش فرض در مرورگر شما باقی می مانند. پروژه های محلی و داده های بازیابی آپلود نمی شوند مگر اینکه به صراحت از منوی Cloud استفاده کنید. کارهای مهم را به صورت دوره ای بارگیری کنید زیرا حافظه مرورگر را می توان توسط مرورگر یا توسط مرورگر پاک کرد تنظیمات ← پاک کردن حافظه محلی.
