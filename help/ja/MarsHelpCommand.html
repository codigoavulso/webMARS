Mini-C

組み込みの教育コンパイラは、o32 呼び出し規約を使用して、意図的に定義された C サブセットを MIPS32 アセンブリに変換します。これは汎用の ISO C コンパイラではありません。

プロフィール

プロフィール目的
C0-S0 に C0-S4累積的な教育サブセット。式や制御フローから関数、配列、ポインタ、構造体、typedef、コントラクト、ライブラリに進みます。
C1-NATIVEデフォルトの最も機能的なプロファイル: バイトアドレス指定 char/char *、ネイティブ文字列、 argc/argv、関数ポインタ、および void *.

ソースがより高いプロファイルを必要とする場合、コンパイルでは焦点を絞ったプロファイルが出力されます。 MC_SUBSET_MISMATCH 一連の二次エラーではなく、診断に役立ちます。

プロジェクトをコンパイルする

  1. 必要なプロファイルと出力オプションを選択します。 設定 → Mini-C 設定.
  2. 1 つ以上開く .c 同じプロジェクト内のファイル。
  3. 選択 実行 → C0 をコンパイル または を押してください F4.
  4. 診断と生成された MIPS アセンブリを確認します。生成されたプログラムを通常どおりアセンブルして実行します。

呼び出し規約とエントリポイント

  • 引数の使用 $a0–$a3、追加の引数はスタックを使用し、戻り値は使用します。 $v0 (そして $v1 該当する場合）。
  • 呼び出し先で保存されたレジスタとスタック フレームは MIPS o32 の期待に従います。
  • main(void) そして、C1-NATIVE では、 main(int argc, char **argv) サポートされています。
  • webMARS プログラム引数の場合、 argv[0] ユーザーが指定した最初のトークンです。自動実行可能ファイル名のエントリはありません。

バンドルされたヘッダーとライブラリ

これらのヘッダーは、 webMARS 互換性ライブラリを中心に構築 MIPS システムコールとデバイス。これらは、完全なホスト C 標準ライブラリではなく、文書化されたサブセットを実装しています。

#use <bitmap_rect> も提供します bitmap_configure_display, bitmap_configure_terminal そして bitmap_configure_allこれにより、C0 プログラムがその表示サイズ、ユニット サイズ、フレームバッファー アドレスをビットマップ ツールに送信できるようになります。

良い開始例

  • ハローワールド (C) 最小の完全なプログラムの場合。
  • Mini-C C1 ネイティブ ネイティブ文字列と現在のプロファイルの動作について。
  • 引数ライブラリのデモ のために argc/argv.
  • 複数ファイルの統計 プロジェクト全体のコンパイルとファイル全体の関数呼び出し用。
  • 標準出力コンソールの基本 そして stdio ファイルの往復 互換性ライブラリの場合。
リポジトリ内のコンパイラ マニュアルは、引き続き標準的な詳細な言語リファレンスです。アプリ内ページには、プロファイルを選択してサンプルを正しく実行するために必要な動作がまとめられています。
