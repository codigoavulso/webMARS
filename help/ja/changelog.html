変更履歴

リリース 0.5.5 ではパイプライン・ラボを導入し、学習環境全体を20言語に拡張しました。

0.5.5 — パイプライン・ラボと20言語

  • RAWハザード、フォワーディング、ストール、可逆サイクル、メトリクス、拡張可能なタイムラインを備えた決定論的5段パイプラインを追加しました。
  • インターフェース、例、ドキュメント、ヘルプを10言語から20言語に拡張しました。
  • ツールのレスポンシブ動作、ローカライズ、回帰テストを拡充しました。

0.5.4 — MARS-OS デスクトップ、仮想ディスプレイおよびシステム テーマ

  • スタート メニュー、アプリケーション ランチャー、移動可能でサイズ変更可能なウィンドウを備えた、Windows 95 スタイルの MARS-OS エクスペリエンスを完成させました。
  • TTY ANSI ターミナル、マウス入力、応答性の高いモバイル動作、および MARS-OS アプリケーションが改善されました。
  • TTY ANSI、ビットマップ ディスプレイ、ビットマップ ターミナルでデフォルトで表示されるフィット ウィンドウを有効にしました。
  • デスクトップとモバイルの両方のレイアウトで、デフォルトで仮想ディスプレイ設定が折りたたまれました。
  • 明示的なライトとダークのオーバーライドを使用して、ブラウザーの配色に自動的に従うシステム テーマを追加しました。

0.5.3 — ブラウザ言語のブートストラップ修正

  • アプリケーションが初めてデフォルトの UI 設定を作成するときに、ブラウザーから検出された言語を保持します。
  • 自動検出に先立って明示的に保存された言語設定を保持し、サポートされていない言語のフォールバックとして英語を保持しました。
  • 地域のブラウザ言語に対する回帰カバレッジと、完全な新規セッション設定ブートストラップが追加されました。

0.5.2 — 10言語、自動選択、MARS-OSデスクトップ

  • 完全なインターフェイス、サンプル カタログ、ドキュメント、ヘルプを英語、スペイン語、ポルトガル語から 10 か国語に拡張し、中国語、ヒンディー語、アラビア語、フランス語、ベンガル語、ロシア語、インドネシア語を追加しました。
  • 明示的に保存された設定を保持しながら、地域コードの正規化と英語のフォールバックによる初回訪問時のブラウザ言語検出が追加されました。
  • ソース コード、ランタイム出力、および技術表記を左から右に保ちながら、右から左へのアラビア語レイアウトを追加しました。
  • MARS-OS を、プログラム マネージャーで直接開き、ターミナル アプリ内でシェル コマンドを実行するマウス駆動デスクトップに作り直しました。
  • TTY スループット、Android キーボード対応のモバイル サイズおよびデスクトップの垂直方向の間隔が向上しました。
  • 再現可能なローカリゼーション生成、保護された技術用語、および 10 言語の完全な回帰カバレッジが追加されました。

0.5.1 — デバイス割り込み、ランタイム ツール、MARS-OS クロック

  • CPU 側のマスキングと保留状態の配信を使用して、タイマー、キーボード、ディスプレイ、および Digital Lab の 16 進キーパッドに同時外部割り込みを実装しました。
  • 正確なバックステップと互換性のある集中化されたスパース デルタを含む、システム クロック ツールとスタック ビジュアライザー ツールが追加されました。
  • デコードされた命令バッチ、合体レンダリング、および制限されたランタイム イベント履歴により、接続ツールのオーバーヘッドが削減されました。
  • ローカライズされたタイマー割り込みの例を追加し、動作する MARS-OS を拡張しました clock そしてリアルタイム bench コマンド。
  • コンパクトなランタイム スナップショットが、実行 UI で組み立てられたテキスト セグメントを一時的にクリアしないようにしました。
  • ファイル マネージャーとクラウド契約を統合し、競合安全な保存、リモートでの名前変更/削除、大文字と小文字を区別しないプロジェクト ID、バッチ同期ステータスを実現しました。

0.5.0 — 成熟したランタイム、デルタ バックステップ、モバイル ワークフロー

  • メモリ制限、アトミック ストア、COP1 の倍精度と丸め、遅延分岐、例外、LL/SC 予約、ブレークポイントにわたる影響の大きいランタイム動作を修正しました。
  • 正確なバックステップ ウィンドウと同期されたツール状態を維持しながら、完全な命令ごとのスナップショットを有界逆デルタに置き換えました。
  • コンパクトなランタイム イベント バッチ、統合されたツール レンダリング、および軽量な UI 同期により、実行のオーバーヘッドが削減されます。
  • 動的なビットマップ MMIO 構成を追加し、MARS 4.5 との互換性を維持しながら使用できるようにビットマップの例とライブラリを更新しました。
  • TTY のサンプルを実用的な MIPS シェルで拡張し、3 つの言語すべてでアセンブリと Mini-C のレッスン カタログを改善しました。
  • ツール、ダイアログ、クラウド、設定をモバイル ウィンドウ システムに統合します。これには、Android キーボード対応のサイズ設定、セマンティック仮想キーボード、およびスクロールが含まれます。
  • 包括的なランタイム、ツール、サンプル、ドキュメント、モバイル UI、リリース回帰カバレッジを追加しました。

0.4.13 — モバイル単一パネル レイアウト、ローカライズされた診断

  • モバイルでは、メイン、メッセージ/実行 I/O、レジスタ、および開いているツールをリストする新しいアイコン タブ バーから選択された全画面パネルが一度に 1 つ表示されます。
  • モバイル ビューポートを固定し、ページがスクロールしなくなるようにし、ドキュメントとウィンドウ本体の間のネストされたスクロールの競合を解消しました。
  • モバイル ツールバーは 2 つのコンパクトな行にアイコンのみが表示され、実行コントロールと実行速度ピッカーが画面上に表示されます。ファイル アクションはそこで非表示になり、[ファイル] メニューと [編集] メニューに残ります。
  • モバイルでは最小化ボタンと最大化ボタンを非表示にし、1 つのパネルが画面全体に表示され、タブ バーが切り替えを行います。
  • すべてのアセンブラーと Mini-C 診断をローカライズし、114 個のテンプレート リテラルを名前付きプレースホルダーに変換し、3 つの言語にわたって 277 個のキーを追加しました。
  • 翻訳可能なメッセージにカタログ エントリがない場合に失敗するリリース テストを追加しました。
  • デスクトップのレイアウト、ウィンドウの位置、コントロールのサイズは変更されません。

0.4.12 — ダークテーマ、フォントサイズの修正、デッドコードのクリーンアップ

  • から選択できるオプトインダークテーマを追加しました Settings > Interface...、エディタ、ツール ウィンドウ、ヘルプ ページに適用されます。

0.4.11 — 永続的なクラウド ログインの復元

  • アプリケーションの起動中に設定されたクラウド サーバーをサイレント チェックし、既存の認証済みユーザーを復元しました。
  • ローカル ワークスペースをブロックすることなくセッションが正常に復元された後、クラウド プロジェクトのメタデータが更新されました。
  • 認証 Cookie の最大有効期間が 1 年間であることと、ログアウト時に即座に削除されることを文書化しました。
  • 認証情報付きリクエストと自動起動復元に対する回帰カバレッジが追加されました。

0.4.10 — バッチ化されたツール履歴と軽量な UI アップデート

  • エンジンの正確な 100 ステップのバックステップ ウィンドウでカバーされる命令のみのツール デルタが保持されます。
  • 視覚的な更新をバッチ処理し、古い履歴の割り当てを回避しながら、ツール モデルで利用できるすべてのランタイム イベントを維持します。
  • 命令ごとの削減 DOM で働く BHT キャッシュ シミュレータ内の冗長状態コピー。
  • アイドル状態の Mars Bot レンダリングを停止し、UI 同期から冗長な完全なランタイム スナップショットを削除しました。
  • Firefox 専用のウィンドウ タイトル セパレータの再描画アーティファクトを修正しました。
  • 入力応答性やバックステップを損なうことなく、モンティ ホール ラボでのアイドル状態の端末ポーリングを削減しました。

0.4.9 — ランタイムパリティと信頼性の高いバックステップ

  • 疎なジャーナル メモリを境界としながら、最新の 100 件のバックステップを利用可能に保ちます。
  • ブラウザーの長時間実行における同期キーボード/ディスプレイ、TTY、およびツールイベントの動作を修正しました。
  • 忙しいポーリングを行わずにブラウザ入力と連携できるように、Monty Hall ラボとインタラクティブな例を更新しました。
  • ランダム システムコール 40 ～ 44 をシードされたシーケンスとサンプリング ルールに一致させました。 java.util.Random MARS によって使用されます。
  • 強化されたランタイム状態インポート、長い命令カウンター、アセンブラー範囲、および数値ディレクティブ検証。
  • 画像メタデータのバックステップ カバレッジを完了し、長さ 0 の InputDialogString バッファを修正しました。
  • ランタイム、ローカライズされたサンプル、および接続されたツール全体にわたる回帰範囲の拡大。

0.4.8 — デルタバックステップと同期デバイス

  • 完全な命令ごとのバックステップ スナップショットを有界逆デルタに置き換えました。
  • 分離された同期 MMIO デバイス、コンパクトなランタイム イベント バッチ、および定期的なツール スナップショット。
  • キーボード/ディスプレイと TTY 入出力の因果関係、バックステップ、および隠しツールのオーバーヘッドを修正しました。
  • キャッシュ、命令、メモリ参照、およびビットマップ ツールでのバッチ レンダリングを修正しました。
  • Mini-C サンプル フレームバッファをコンパイラ グローバルから移動し、ビットマップ表示をライブ メモリと同期しました。
  • ローカル ベンチマーク ストリップをインターフェイス設定でオプションとし、デフォルトでは非表示にしました。

0.4.7 — JavaScript ランタイム強化と完全なドキュメント

  • 純粋な JavaScript エンジンでのランタイムを標準化し、実験的な WASM/ハイブリッド バックエンドを削除しました。
  • コンパイル、アセンブル、実行のタイミングと推定 JavaScript の使用率をアプリ内ベンチマーク ストリップに追加しました。
  • 最大実行速度でのエディターの作業を軽減しながら、接続されたデバイスで利用可能な完全な実行時スナップショットを維持します。
  • COP1 ダブルワードの順序付け、FCSR ベースの変換丸め、および完全な数値入力検証を修正しました。
  • 強化されたヒープ制限、アトミック ストア、命令アライメント、厳密な部分ロード、および LL/SC 予約。
  • 遅延ブランチ リンク アドレス、遅延スロット例外状態、およびダイレクト エンジン Go とブラウザ駆動実行間のパリティを修正しました。
  • Made Stop はエンジンを終了し、保留中のスリープをキャンセルしますが、一時停止は再開可能なままです。
  • ブレークポイント、ランダム ストリーム、仮想ファイル/カーソル、標準入力、プログラム引数、イメージ ハンドルを保存するために拡張されたランタイム スナップショット。
  • C1-NATIVE およびマルチファイル C プロジェクトを含む、英語、スペイン語、ポルトガル語のサンプル カタログを拡張および合理化しました。
  • 現在のブラウザ アプリケーション、ランタイム、Mini-C コンパイラ、ツール、ストレージ、プライバシーの動作に合わせて、英語、スペイン語、ポルトガル語のすべてのアプリ内ヘルプを更新しました。
  • バージョンの一貫性、マニフェスト、一時ファイル、ローカライズされた UI コントラクトのリリース準備チェックが追加されました。

0.4.6 — 再現可能なブラウザワークスペース

  • アセンブラ/ランタイムの動作、ブラウザの統合、ツール、例に関する広範な回帰カバレッジを追加しました。

歴史的メモ

以前のリリースの一部では、WebAssembly アクセラレーションとバックエンド選択を実験しました。これらのエントリはリリースを正確に説明していますが、そのサブシステムはもう存在しません。現在のランタイムは JavaScript のみです。
