変更履歴

リリース 0.6.6 では、プロジェクトの同期と回復が保護され、パブリック プロジェクトの参照が修正され、各ビルドが識別されます。

0.6.6 — より安全なプロジェクトと確実なリカバリ

  • 競合するローカル プロジェクトと Cloud プロジェクトを並べて比較し、両方を新しい名前で保持するか、どちらのバージョンを保持するかを明示的に選択します。 Cloud の同時変更は引き続き保護されます。
  • Cloud コピーをサイレント削除せずに、削除されたプロジェクトをごみ箱から復元します。ワークスペースを変更する前に、無効なインポートまたはサイズ超過のインポートを拒否してください。
  • パブリッシュされたプロジェクト ファイルの参照を修正し、再起動時に空のワークスペースを保持し、起動が失敗した場合の再試行を提供します。
  • 必要な場合にのみ Mini-C コンパイラをロードし、継続的インテグレーションで MARS 参照を検証し、バージョン情報でリリース ビルド番号を表示します。

0.6.5 — 統合プロジェクトとオンラインワークフロー

  • ローカル ファイル、Cloud プロジェクト、公開パブリケーション、組み込みプロジェクト マネージャーのごみ箱を統合し、コンテキスト メニューとファイル アクションを保持します。
  • Cloud とライブラリをオンライン メニューに統合し、コンテキストを認識したプロジェクトの同期と公開制御を実現しました。
  • 編集可能なエラー状態と一貫したナビゲーションを備えた、アカウント アクセス、Google サインインとリンク、アカウントの統合、パスワード回復、電子メール検証が再設計されました。
  • 統合されたマニュアル、実用的な例と翻訳が拡張され、使用統計とエディターの調整が改善され、廃止されたプロジェクト ファイルが削除されました。

0.6.4 — トラフィック分析とソーシャルサインイン

  • 既存の Cloud アカウントへの明示的なリンクを含む、BackMars を介したオプションの Google および Facebook サインインが追加されました。
  • パブリック、内部、テスト、および自動化されたトラフィックを分離し、人間のインタラクションの可能性のある信号と集約された Web/アプリの比較を行います。
  • Cloud のアカウントとアクティビティの集計統計、視聴者フィルター、およびより明確な使用状況グラフを追加しました。
  • 独立したマニュアルを 0.2.0 に更新し、MARS 参照を保持しながら未使用のレガシー資産を削除しました。

0.6.3 — 公開統計とプロジェクト発見

  • 過去 60 分、24 時間、30 日間のグラフ、カスタマイズ可能なフィルター、正確な値のテーブルを備えた統合された使用状況統計ウィンドウが追加されました。
  • セッション識別子を含まない集計のみの使用状況データを公開し、インタラクション時間を目に見える存在から分離します。
  • 選択ダイアログの代わりに詳細なプロジェクト リストを使用して、公共ライブラリを検索およびページ分割できるようにしました。

  • デフォルトでは無効になっている豊富なイベント メトリックを維持しながら、パブリック ページ、メトリックの解釈、保持およびデプロイの順序を文書化しました。

0.6.0 — 安定した教室と公共図書館

  • すべての組み込みサンプルに永続的な直接リンクを追加しました。安定した ID は専用のレジストリに存在し、削除されたり再利用されたりすることはありません。廃止されたエントリは、廃棄または明示的なリダイレクトとして残ります。
  • BackMars を介した公開プロジェクトの公開を追加しました。すべてのパブリケーションは、その展開上でグローバルに一意のパブリック名を先着順で受け取り、短い /p/name リンクを通じて開きます。
  • 公開されたリビジョンを不変にしました。固定されていないリンクは最新のアクティブなリビジョンに従いますが、/p/name@N は通常のアーカイブ後でも正確な履歴スナップショットを開き続けます。
  • 検索、ページング、読み取り専用プレビューを備えた公共図書館ブラウザを追加しました。出版物を開くとクリーンなローカル コピーが作成されるため、公開マテリアルが作者のプロジェクトを黙って変更したり、Cloud ストレージに入ったりすることはありません。
  • パブリック交換形式をバージョン管理し、サニタイズしました。パブリケーションにはプロジェクト ファイルと安全な教育メタデータのみが含まれており、ブラウザと BackMars によって個別に厳格な制限が適用されます。
  • 期限切れの使い捨てコードを使用した電子メールによるパスワード回復を追加しました。リセットが成功すると既存のセッションが無効になり、アドレスが登録されているかどうかはリクエストによって明らかにされません。
  • 電子メールの検証と再送信のフローを追加しました。デプロイメントでは、ローカルでの編集、サンプル、シミュレーションをアカウントなしで利用できるようにしながら、公開する前に検証済みのアドレスが必要になる場合があります。
  • 各インストールの名前、ベース パス、パブリック URL、BackMars エンドポイント、マニュアルおよびサポート リンクを webmars-config.js に移動したため、大学はアプリケーション コードを編集せずに独立したインスタンスをデプロイできます。
  • 初回実行時の自動の About ウィンドウをガイド付きの Welcome ウィンドウに置き換えました。一方、About はヘルプの下に保持され、サンプルや出版物の直接リンクが優先されます。
  • MARS からの移行、ファーストクラス、LMS テキスト、安定したリンクの公開、ソリューション、セルフホスティング/プライバシーの決定をカバーする教師キットを追加しました。
  • 詳細な章、ライトテーマのスクリーンショット、および webMARS リリースに対する明示的な検証を含む、独立したバージョンの webMARS マニュアルを v0.1 で開始しました。
  • 安定した URL、プライベート データベース ストレージ、バックアップ、移行、Gmail SMTP、および展開後のスモーク テストのための運用ガイダンスとルート構成を追加しました。

0.5.6 — パイプラインはプログラムに従います

  • 記録された実行ストリームをパイプライン ラボに追加しました。モデルは分岐がどのように解決されたかを仮定するのではなく、実際に実行されたシーケンス webMARS を再生するため、選択された分岐、予測ミス、破棄された命令は仮定ではなく事実になります。
  • レジスタ ビューを追加しました。現在のサイクルでのすべてのレジスタの値、初期段階でまだ処理中の値、およびレジスタを変更したサイクルに対するすべてのレジスタのグリッドです。値は、ランタイムが値を指定した場合にのみ表示されます。静的ストリームでは意図的に何も表示されません。
  • 2 つのトランスポートをリンクしました。 webMARS で実行される 1 つの命令は、両方向でパイプラインに入る 1 つの命令です。メイン ウィンドウのステップとバックステップでパイプラインが移動し、フェッチ ステージに読み取るものがなくなったときにツール自体のステップでプログラムの実行または非実行を制御します。
  • バックステップに F8​​ を追加しました。これにはショートカットがありませんでしたが、ステップには F7 がありました。
  • Pipeline Lab を垂直パイプラインとして再描画し、ステージの各ペアの間に、タイムラインの上ではなく横にパイプライン レジスタを配置して、ステージに命令、そのソース ライン、および使用した値を表示できるようにしました。
  • Pipeline Lab を画面ではなく独自のウィンドウに配置するようにしたため、大きなディスプレイ上の狭いウィンドウが電話と同じように折りたたまれ、すべてのコントロール グループを手で開閉できます。
  • 手動で修正済みのエントリを書き換えることなく、カタログがまだ英語で回答している文字列のみを翻訳する、ターゲットを絞ったロケール アップデーターを追加しました。プレースホルダーを変更する翻訳は拒否されます。
  • 17 の言語にわたって依然として英語で表示されていた 872 のインターフェイス文字列を翻訳し、言語が以前よりも多くのインターフェイスを英語で応答した場合に失敗するテストを追加しました。
  • メイン ウィンドウでバックステップを無視するパイプライン ラボを修正しました。ランタイムはツールがリッスンしていないチャネルでバックステップを配信するため、ツールは未実行の命令を再生し続けました。
  • リーダーが選択したパネルを置き換えるモバイル モードでのステップを修正しました。プログラムの実行によるフォーカスによって、表示されるパネルが変更されなくなりました。新しいウィンドウまたはすでに開いているウィンドウを開くと、引き続きウィンドウが開きます。
  • ステッピング プログラムに従っているときに、パイプライン ラボで最後のステージのみが表示され、パイプラインが充填されるのではなく、すべてのステップで排出および補充される問題を修正しました。
  • タイムラインのストール マーカーを沈黙させ、両方のテーマでミュートされたテキストをミュート解除したままにする、未定義の 3 つのインターフェイス カラー トークンを修正しました。
  • プログラムのリセットや例外ハンドラーなど、分岐が予測されない場所に記録がジャンプしたときに、サイクルが終了するまでリプレイが停止する問題を修正しました。
  • npm run version:set を追加しました。これは、バージョンを宣言する 11 か所すべてにバージョンを書き込み、バージョンをランタイム トークンに記載するヘルプ ページから移動しました。
  • Pipeline Lab タイミング モデルを再構築しました。制御ハザード、構成可能な遅延スロット、静的および動的分岐予測、構成可能なメモリ レイテンシ、シリアル化されたトラップ、並べて比較できる 7 つの個別にバージョン管理されたアーキテクチャ プロファイルが含まれます。
  • アーキテクチャ ビューを追加し、パイプライン レジスタ、命令ごとの制御ライン、マルチプレクサ、ライブ フォワーディング パス、ハザード検出を含むデータパスを描画し、個別に非表示にできる信号グループを追加しました。
  • BHT シミュレーターと共有する分岐履歴テーブルを追加したため、両方のツールが同じように予測します。回帰テストは、2 つの予測変数を同じ結果シーケンスで駆動し、相違があれば失敗します。
  • モデル バージョン、プロファイル バージョン、完全な構成、プログラムのハッシュをタイムスタンプなしで保持する、再現可能な JSON および CSV エクスポートを追加しました。そのため、同じ作業でバイト同一のファイルが生成されます。
  • 目的、前提条件、実行前の予測ステップと振り返りの質問を備えた 7 つのガイド付きラボに加え、別個のソリューション シート、教師採用ガイド、短いプレゼンテーションが追加されました。ワークシートで引用されているすべての数値は、テスト スイートによって再測定されます。
  • チェックサム固定 MARS 4.5 に対する差分スイートを追加し、マシンコード、データセグメント、コンソール出力、および 32 個のレジスターすべてを比較しました。 11 個のプログラムのうち 8 個はバイトが同一です。残りの 3 つの相違点は、理由と最小限の再現ケースとともに宣言されます。
  • 互換性、MARS 適合性、カバレッジ、変異スコア、ベンチマーク、およびアクセシビリティに関して生成された証拠レポートを追加しました。それぞれ 1 つのコマンドで再生成され、テスト スイートによってチェックされます。
  • 宣言されたウォームアップ、繰り返し回数、外れ値ルールを含む公開ベンチマーク プロトコルを追加し、四分位範囲の中央値を報告し、各結果の由来となったマシンを記録しました。
  • アセンブラー、ランタイム、および状態インポーターの突然変異テストと有界決定論的ファジングが追加されました。
  • ツール自体が切断されていると報告されることが原因で、最初のアセンブリ後にパイプライン ラボがランタイム アップデートを受け取らない問題を修正しました。
  • シンボリック分岐ターゲットがタイミング モデルで解決されず、すべての分岐予測レポートで予測ミスがゼロになる問題を修正しました。
  • 破損した、または保存されていない実行時状態をインポートするときに、空の画面としてユーザーに届くクラッシュを修正しました。
  • エディターと Mars Messages ペインにアクセス可能な名前がなく、ライト テーマのテキストの色が WCAG コントラストの最小値を下回っている問題を修正しました。
  • 右から左へ記述する言語で固定されたタイムライン列が切り離されるのを修正し、パイプライン図を左から右に維持して、ステージ順序が引き続き前方に読み込まれるようにしました。
  • パイプライン ステージにオプションの色覚安全パレットを追加しました。
  • 開発者ドキュメントを追加しました: アーキテクチャの境界、最初のコントリビューション ガイド、命令、システムコールとデバイスを追加するためのガイド、ランタイム不変条件、動作例とスキャフォールド ジェネレーターを含むバージョン管理されたツール API、およびリリース プロセス。
