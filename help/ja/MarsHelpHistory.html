歴史

webMARS は、MARS 4.5 MIPS シミュレータのブラウザ ポートとして始まりました。独立した JavaScript ランタイム、エディター、デバッガー、Mini-C コンパイラー、ローカル/クラウド プロジェクト ワークフロー、ブラウザー ネイティブ ツールが組み合わされるようになりました。

現在の開発ライン

  • JavaScript のみのランタイム。 実験的なハイブリッド/WASM パスは、このワークロードにとって価値のある改善がなされずに複雑さが増すことが測定で示された後、削除されました。
  • 実行時の正確性。 最近の作業では、ダブルワード COP1 順序付け、アトミック メモリ ストア、ヒープ予約、LL/SC、厳密なアドレス指定、遅延分岐リンク、FCSR 丸め、例外継続、停止動作が強化されました。
  • 完全な状態のスナップショット。 エクスポート/インポートとバックステップでは、ランダム ストリーム、仮想ファイルとカーソル、標準入力、プログラム引数、イメージ ハンドル、ブレークポイントが考慮されるようになりました。
  • パフォーマンスの可観測性。 アプリは、ローカルのコンパイル、アセンブル、実行のタイミングと推定 JavaScript の使用率をレポートしますが、最高速度の実行により、ランタイム状態のツールを枯渇させることなくプレゼンテーションのオーバーヘッドが削減されます。
  • Mini-C の進化。 C0 ティーチング サブセットは、C1-NATIVE、o32 呼び出し、バイト文字列、引数、関数ポインター、マルチファイル プロジェクト、および互換性ライブラリとともに引き続き利用できます。
  • カリキュラムとしての例。 アセンブリと C のサンプルは、目的、言語、最小コンパイラ プロファイルごとにカタログ化されており、多言語バリアントと複数ファイル プロジェクトが含まれています。

互換性の系統

命令の語彙、一般的なシステムコール、ユーザー インターフェイスの概念、および教育モデルはオリジナルから派生しています。 MARS ピート・サンダーソンとケネス・ヴォルマーによるプロジェクト。 webMARS Java デスクトップ統合をブラウザ API と独自の実行エンジンに置き換えながら、その系譜を維持します。

バージョン記録

の webMARS → 変更履歴 ヘルプ ページには、バージョンごとの詳細なプロジェクト レコードが含まれています。歴史的なエントリは、リリースの状態を説明します。これらは、実験的なサブシステムが現在のビルドに残ることを約束するものではありません。

ドキュメントと変更ログの履歴エントリが異なる場合は、現在のトピック ページと現在の実行時の動作が優先されます。
