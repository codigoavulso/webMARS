webMARS __WEBMARS_APP_VERSION__

ブラウザネイティブ MIPS32 アセンブラを使った学習環境、 JavaScript シミュレータ、デバッガ、 Mini-C コンパイラ、サンプル、対話型デバイス。

インストールなし

最新のブラウザーでアプリを実行します。 Java と WebAssembly は必要ありません。

地元第一主義

サインインせずに編集、コンパイル、実行、ブラウザーのストレージに保存、ダウンロードできます。

教育中心

MARS スタイルの MIPS 構文、syscall、メモリ マップ、ツール、および構造化された Mini-C プロファイルを使用します。

現在の機能

  • MIPS32 整数、メモリ、分岐、例外、LL/SC および COP1 の実行。
  • 基本および疑似命令のリファレンス、マクロ、および構成可能なアセンブラの互換性。
  • ブレークポイント、ステップ、バックステップ、一時停止、停止、リセット、および実行時状態のスナップショット。
  • o32 を対象とした C0-S0 から C0-S4 および C1-NATIVE Mini-C のコンパイル。
  • 18 のランタイム ツール、20 の言語で厳選されたサンプル、およびオプションのクラウド プロジェクト。
  • 推定 JavaScript 使用率によるローカルのコンパイル、アセンブル、実行ベンチマーク。

プライバシー

webMARS には広告がありません。ソース ファイル、環境設定、仮想ファイル、リカバリ データ、ベンチマーク、およびランタイム状態は、デフォルトでデバイス上に残ります。ベンチマーク サンプルは揮発性であるため、送信されません。

クラウド機能はオプションです。サインインまたは同期すると、アカウント/セッションおよびプロジェクト データが設定で構成されたクラウド サーバーに送信されます。サードパーティサーバーまたはカスタムサーバーを使用する前に、オペレーターの規約を確認してください。ダウンロードおよびディスクから開かれたファイルには、通常のブラウザ ファイル コントロールが使用されます。
