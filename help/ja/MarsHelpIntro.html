はじめに

webMARS は、ブラウザベースの MIPS32 アセンブラ、シミュレータ、デバッガ、Mini-C コンパイラおよび教育ワークスペースです。ランタイムは完全に JavaScript で実装されます。 Java のインストール、ネイティブ実行可能ファイル、または WASM バックエンドは必要ありません。

  1. ソース ファイルを開くか作成します。 使用する ファイル → 例 ガイド付きの開始点として、 新しいプロジェクト 空のプロジェクトの場合、または ディスクから開く ローカルファイルの場合。
  2. 構築してください。 アセンブリファイルの使用 走行→組み立て (F3）。 C ファイルは使用します 実行 → C0 をコンパイル (F4)、生成されたアセンブリをアセンブルします。
  3. 実行してください。 選択 行く (F5) または、次のようにして一度に 1 つの命令を進めます。 ステップ (F7).
  4. 結果を調べます。 プログラムの実行に応じて、レジスタ、コプロセッサ 1、メモリ、メッセージ、実行 I/O、および接続されたツールが更新されます。

含まれるもの

MIPS32 ランタイム

整数、分岐、メモリ、例外、LL/SC および COP1 の実行 (遅延分岐および自己変更コード オプションを含む)。

Mini-C コンパイラ

C0 ティーチングサブセットと C1-NATIVE プロファイル、ターゲティング MIPS o32 呼び出し規約。

デバッガ

ブレークポイント、ステップ実行、バックステップ実行、リセット、一時停止/停止コントロール、および構成可能な実行速度。

デバイスとツール

MMIO デバイス、キャッシュおよびブランチ シミュレーター、ビジュアル ディスプレイ、統計、ANSI ターミナルなど。

推奨される初回実行

開く ファイル → 例、英語を選択してください 学ぶ たとえば、説明を読んで開きます。アセンブリ例は直接アセンブルして実行できます。 C の例では、最小のコンパイラ サブセットを宣言しており、複数のプロジェクト ファイルが含まれている場合があります。

デフォルトでは、ファイルはブラウザ内に残ります。 明示的にクラウド メニューを使用しない限り、ローカル プロジェクトとリカバリ データはアップロードされません。ブラウザのストレージはブラウザによってクリアされる可能性があるため、重要な作業を定期的にダウンロードしてください。 設定→localStorageをクリア.
