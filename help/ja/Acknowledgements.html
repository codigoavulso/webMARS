謝辞

webMARS は、元の MARS プロジェクトによって確立された教育モデル、指導文書、ツール、コミュニティの経験に基づいています。

オリジナル MARS

Pete Sanderson と Kenneth Vollmar が、教育者、学生、ツール作成者の協力を得て作成しました。彼らの仕事は、親しみやすいものを確立しました。 MIPS アセンブラ/シミュレータのワークフロー webMARS ブラウザで続行します。

注目すべきオリジナルの貢献には、マクロ システム、命令統計とカウンター ツール、分岐予測シミュレーター、キーボード/ディスプレイ MMIO の作業、デジタル ラボ シム、MIPS X 線、MIDI の改善、および教室での使用を通じて収集された多くの修正が含まれます。

webMARS

Nelson Ferreira によるブラウザの実装と継続的なメンテナンス。現在のアプリには、独立した JavaScript MIPS エンジン、Mini-C コンパイラーとライブラリ、ローカル/クラウド プロジェクト ワークフロー、ランタイム ツール、多言語サンプル、自動回帰カバレッジが含まれています。

コミュニティと標準

再現可能な障害を報告し、教育例を提供し、翻訳をチェックし、アーキテクチャの動作を MIPS32 ドキュメントと比較してくださった皆様に感謝します。これらのレポートは、互換性と実行時の正確性を直接的に改善します。

オリジナル MARS ライセンス そして MIPS インストラクションセットソング これらは、元の帰属を持つ履歴ヘルプ アイテムとして保存されます。これらの存在は、現在のブラウザ実装がオリジナルの Java ソースを使用していることを意味するものではありません。
