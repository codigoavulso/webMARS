MIPS の動作

  • メモリはリトルエンディアンです。ワードおよびダブルワードの操作では、MIPS レジスタ/メモリの順序付けが使用されます。
  • 命令フェッチの位置がずれている場合や無効なロード/ストア アドレスがあると、アドレス例外が発生します。
  • ストアは書き込む前に完全な宛先を検証するため、ストアが失敗しても部分的な値が残されることはありません。
  • LL/SC 競合するストアが無効にする予約を使用します。
  • COP1 変換では FCSR 丸めモードが尊重されます。浮動小数点入力は、後続の非数値テキストを拒否します。
  • 厳密な MARS 互換性により、部分ワード ロードを含むメモリ操作は、許可されたセグメント内にとどまる必要があります。

既知の移植性の境界

  • ブラウザ仮想ファイル システムは、ホスト オペレーティング システムの無制限のファイル システムではありません。
  • Web オーディオの許可と自動再生ポリシーは、MIDI のシステムコールに影響を与える可能性があります。
  • ポップアップ ブロッカーとダウンロード ポリシーは、エクスポートされたファイルに影響を与える可能性があります。
  • Mini-C は文書化されたプロファイルのみを受け入れます。完全な ISO C に依存するコード、ホスト libc または未定義の動作は移植できません。
  • Java クラスまたはデスクトップ プラグインに依存する従来の MARS 拡張機能は利用できません。
